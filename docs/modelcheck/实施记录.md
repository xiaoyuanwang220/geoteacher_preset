## 4. M0 能力结论与降级承诺（详见 M0-能力矩阵）

| 能力 | 结论 | 插件承诺 |
|---|---|---|
| 会话面板 + 服务页面 | **可用** | `conversation.view` 页签 + 自有 webServer 路由；已实测 occupant active |
| 向会话投递消息 | **可用** | `sessionController.prompt({requestId,sessionId,mode:'queue'})`；requestId 即幂等键；失败保留草稿可重试 |
| 构建与取证 | **受限** | 需要面板打开并回填才能取得运行时几何证据；否则 `inconclusive`，绝不拿旧产物冒充 |
| 完成拦截 | **可用（有条件）** | `agent/turn-stopping` 里 `prompt(mode:'steer')` 把未认证提醒插回下一步；同一 agent+turn 最多 2 次；用户取消/模型报错/会话关闭时不能拦截 |
| 写入拦截 | **覆盖率不足** | 只承诺"改后检测 + 证据失效"；`pwsh`/`bash` 写盘绕过 `fs/write-intent`，不宣称文件不可改 |
| 执行取消 | **不可用** | 只停止插件自有任务；不宣称宿主任务被取消 |
| 授权/确认存储 | **受限** | 面板点击记录 `confirmedBy:"user"`；无法区分"真人点击"与"已认证浏览器会话"；模型页面被 sandbox 成不透明源，不能直接调用 API 伪造确认 |
| 恢复与隔离 | **部分** | 项目根按 `sessionId` 解析；契约/证据原子写 + 冲突检测；多会话并发的端到端隔离未做长跑验证 |

关键实现选择：

1. **`host.call` 不能用**（对手写/打包 bundle），客户端→宿主统一走同源 `fetch('/modelcheck/api')`。
2. **预览 iframe 不透明源**：`sandbox="allow-scripts allow-forms allow-modals"`（不加 `allow-same-origin`）。模型页读不到父页面、无法伪造用户确认；代价是模型页内的相对 `fetch()` 可能被跨源限制（已写入 README 与面板提示）。
3. **确认边界**：`contract/confirm`、`annotations/accept` 只由面板调用并写 `confirmedBy:"user"`；7 个模型工具的 schema 里没有任何确认字段。
4. **fail-closed**：取证超时、构建/上下文不符、元判据未过、规则异常一律 `inconclusive`，不计入完成。

## 6. 已知限制

- Blender 路线不做（一期范围外）；图像路线只支持已登记可点选区域，未登记区域返回 `inconclusive`。
- 视觉判据（构图/配色/遮挡）不自动判，必须人工确认；包围盒重叠只报候选，不判穿模。
- 运行时几何判据依赖面板打开；面板关闭时的自动验证只能覆盖配置/哈希/文案类判据。
- 交付版剥离：`preview.injectBridge:false` 或 `__VERIFY__=0` 时不注入取证桥接；`.modelcheck/` 与面板不随教师交付物发布。
- 契约削弱（删判据/放宽阈值/降级/减少证据要求）必须用户在面板重新确认；agent 工具不能自行生效。

### 8.1 用户补充反馈：空 `.modelcheck` 目录不算已初始化（2026-10-22 追加）

**反馈**：扫描不能只看 `.modelcheck` 目录是否存在；`16测试\三圈环流尝试` 有目录但没写入任何文件，
应算未完全初始化。

**实现（`inspectModelcheck`）**：状态改为按文件内容判定。

| 状态 | 判定 |
|---|---|
| `none` | 没有 `.modelcheck` 目录 |
| `empty` | 目录存在但没有任何文件（只有 reports/、artifacts/ 子目录也算 empty） |
| `partial` | config.json / components.json 缺失、0 字节、坏 JSON 或结构无效；`missing` 列出缺项，`issues` 给出原因 |
| `ready` | 两个文件都存在且结构有效（components 可为空数组；contract 未建立不算 partial） |

- `discoverCandidates` 每个候选返回 `modelcheck:{state,dirExists,empty,files,missing,componentsCount,contractStatus,issues}`、
  `hasModelcheck`（仅 ready 为 true）、`needsInit`；扫描面板据此显示「未初始化 / 空目录 / 部分初始化（缺 …）/ 已初始化」。
- `applyScaffold` 只写缺失或无效的文件（有效文件不覆盖，`force:true` 才全量覆盖），返回 `before/after/notes`
  （如“检测到空 .modelcheck 目录（没有任何文件），已按初始化处理”）。
- 同时修了两处探测：`isProjectDir` 只按**根目录** HTML 回退，避免把“含子项目的父目录”误判为项目；
  中文目录名的 `projectId` 用短哈希（`mc-xxxxxxxx`）生成，避免所有中文项目都塌缩成 `modelcheck-project`；
  源码扫描增加根目录下的一级源码目录（如 `模型源码/`），不再只认 `src/`。
