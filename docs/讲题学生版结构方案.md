# 讲题学生版结构方案（设问先行六步）

> 适用对象：`.agent-presets/geo-teacher` 讲题能力（`geo_explain`）的**学生对象**
> 状态：**方案（未实施）**——实施需另行批准
> 规范依据：`docs/讲题功能设计.md` §三（设问先行 → 定向读材料）；术语以 `docs/术语表.md` 为唯一权威
> 已定决策：**读图不独立成步**（并入②）；**每步两要素**（做什么／思维锚点），暂不加"本步自检"第三要素

## 一、现状（结构性问题）

1. 学生对象与教师对象共用同一四段式骨架，但段内只给一句"侧重"短语（`audienceEmphasis`），**没有动作序列**。
2. `plugins/core/index.js` 的 `buildStudentPlan()` 保留了 `entryQuestion`（第一步想什么）、`steps`（可执行的思考步骤）、`methodBoundary`（方法边界）三个待填字段，但**没有渲染出口**：`plugins/analysis/index.js` 的学生分支只渲染 `guidance`，教师分支则渲染 `nodeTemplate`（六节点组织模板）。
3. 结果是教师对象有六节点组织模板，学生对象没有对应载体：产出倾向"结论＋依据"的解题报告，而不是"带着学生一步步走"；"第一步想什么、为什么"无落点。
4. `docs/讲题功能设计.md` §三 的六步教学模型（设问先行 → 定向读材料 → …）**未进入学生骨架**。

## 二、目标结构

外层仍是四段式（`docs/术语表.md` 对"讲题稿"的定义不变）；学生对象在**段内**按固定动作序列推进，先拆设问、再看材料。落位：

| 四段式 | 段内步骤 |
| :-- | :-- |
| 一、题目定位 | 前置于流程：这道题要解决什么问题、核心知识与必要联系 |
| 二、审题（设问先行） | ① 拆设问 |
| 三、破题（带着问题读） | ② 带着问题读材料 → ③ 知识选择 → ④ 推理链 → ⑤ 作答与检查 |
| 四、反思与迁移 | ⑥ 方法提炼（本题易错与变式是本段固有内容） |

| 步骤 | 做什么 | 思维锚点（讲给学生听） |
| :-- | :-- | :-- |
| ① 拆设问（先行） | 对象＋行为动词＋限定词（时间/空间/尺度/比较基准）→ 判定设问类型 | 行为动词决定"答到什么程度"，限定词决定"答哪一段、跟谁比" |
| ② 带着问题读材料 | 拿①列出的要素清单进材料，只找用得上的证据，点明哪些信息与本题无关；涉图按图例→坐标→数值→分布→趋势 | 材料不是拿来通读的：设问问什么就去材料里找什么；先定区域与尺度，再取证 |
| ③ 知识选择 | 明确"为什么要用这个知识"：题目哪条线索激活了哪条原理 | 知识不是背出来的，是被题目线索和区域特征选出来的；换一个区域是否仍用同一条 |
| ④ 推理链 | 材料证据×知识×设问 → 地理因果链或逐项排除；每步标注"为什么能推出下一步" | 把前提→结论的因果说显性，不留逻辑缝隙；选择题要讲清每个干扰项错在哪 |
| ⑤ 作答与检查 | 组织要点、规范地理术语与表述，自检是否答到设问要求 | 答案由推理自然引出，不先亮答案再凑理由 |
| ⑥ 方法提炼 | 把这道题升维成这一类题的思考模板，写明适用边界 | 下一次遇到同类问题，第一步该做什么、什么时候要换方法 |

**读图不独立成步**：读图顺序作为②内部的动作写清（涉图题），不单列步骤。
**每步两要素**：只输出"做什么／思维锚点"，不输出"本步自检"。

## 三、工具骨架输出（改动后）

`geo_explain` 学生分支在原有四段骨架之外，新增以下内容（设问类型、维度扫描、变式、核验状态、缓存键均不变）：

```
## 学生对象 audiencePlan（待填）
- 段内教学流程：设问先行 → 定向读材料 → 知识选择 → 推理链 → 作答与检查 → 方法提炼
- 落位：审题＝①；破题＝②③④⑤；反思与迁移＝⑥（外层仍为四段式）
- 推进步骤（每步：做什么／为什么这么做）：
  - ① 拆设问（先行）：先看问什么：对象＋行为动词＋限定词（时间/空间/尺度/比较基准）→ 判定设问类型
    - 思维锚点（讲给学生听）：行为动词决定"答到什么程度"，限定词决定"答哪一段、跟谁比"
  - ② 带着问题读材料：拿①列出的要素清单进材料，只找用得上的证据，点明哪些信息与本题无关（涉图：图例→坐标→数值→分布→趋势）
    - 思维锚点（讲给学生听）：材料不是拿来通读的：设问问什么就去材料里找什么；先定区域与尺度，再取证
  - ③ 知识选择：…
  - ④ 推理链：…
  - ⑤ 作答与检查：…
  - ⑥ 方法提炼：…
- 第一步想什么（待填）：拿到这道题第一步做什么、为什么
- 推进步骤的具体内容（待填）：按①—⑥逐步填：每步的动作＋证据/原理＋结论
- 方法边界（待填）：这个方法适用什么条件、什么时候要换方法
- 答案由推理自然引出，不先亮答案再凑理由
- 重点写"下一步可以做什么以及为什么"
- 教师如何安排课堂、如何诊断学情的内容不占正文
- "无答案练习支架"是另一种可选交付形式，不等于学生对象本身
```

## 四、讲稿内容框架

| 段 | 对应步骤 | 必须写出什么 | 写完自检 |
| :-- | :-- | :-- | :-- |
| 一、题目定位 | 前置 | 这道题要解决什么问题、核心知识、必要联系 | 未堆年份/分值/素养标签 |
| 二、审题（设问先行） | ① | 对象／行为动词／限定词（含比较基准）→ 设问类型；第一步想什么、为什么先想这个 | 读完就知道"要答什么、答到哪、跟谁比" |
| 三、破题（带着问题读） | ②③④⑤ | ②按①的清单定向取证、点出无关信息（涉图含读图顺序）；③哪条线索激活哪条原理；④每步"为什么能推出下一步"＋逐项排除；⑤答案与检查 | 每句都能指回"哪条设问／哪条材料／哪条原理" |
| 四、反思与迁移 | ⑥ | 可迁移方法与适用边界；本题易错（基于核验偏差）；1–2 道真实变式 | 不重复解析、不编造变式来源 |
| （可选另附） | — | 无答案练习支架：提示问题、空格、步骤占位 | 不预填结论 |

## 五、示意（2025 广东卷 第 1 题，仅标题层）

```
一、题目定位
   本题要判断的是：口岸城镇的功能"发生了什么变化"
二、审题（设问先行）
   1 先拆设问：对象＝口岸城镇；行为动词＝判断变化（不是找原因）；
     限定词＝"转型升级后"；比较基准＝"早期以货物过境贸易为主、功能相对单一"
   2 判定设问类型：变化/趋势类 → 四项都要用"与早期相比"这把尺子量
三、破题（带着问题读）
   1 带着问题读材料：找"早期什么样""现在往哪变"
   2 带着问题读图：节点 → 箭头方向 → 标注 → 范围；标出与本题无关的信息
   3 知识选择：为什么想到"产业结构升级"
   4 推理链：③④为什么成立；①与前提矛盾、②绝对化无依据
   5 作答与检查：选 D；自检"为什么不是 B、C"
四、反思与迁移
   1 这类题的方法与适用边界  2 本题易错（基于核验偏差）  3 变式（题库真实候选）
（需要时另附）无答案练习支架
```

## 八、验证与生效

```
node scripts/geo-verify.mjs --source
node --test test/explainer-audience.test.mjs
```

两条命令分别等价于仓库 `verify:geo --source` 与 `test:explainer`。插件 JS 与组合改动必须**完整重启 DSH Desktop**后才进入运行进程；仅改技能文档无需例行重启。

本机 `pwsh` 在 workspace-write 沙箱下必以 `0xC0000142`（`STATUS_DLL_INIT_FAILED`）退出，提升到 full access 后才可执行命令（见 `docs/讲题三对象改造-实施记录.md` §6.1、§179）。因此上述两条验证命令需要一次沙箱提权。

## 九、风险与回滚
