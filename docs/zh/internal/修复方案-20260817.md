## 二、修复项

### P0 · 数据/解析层（`plugins/core/index.js` `parseOneQuestion`，复盘 #1/#2/#3）

**F1 主循环跳过 MANAGED-KM 块（复盘 #1，高）**
- 问题：主循环只跳过 `<!--` 开头行（`:284`），KM 块内 YAML 行全部按正文处理，`question_id: "…"` 命中 `:247` 正则覆盖干净 id。
- 改动：循环外加 `let inKm = false`；在 qid 匹配**之前**处理：
  ```js
  if (/^<!-- MANAGED-KM-START/.test(t)) { inKm = true; continue; }
  if (inKm) {
    if (/-->/.test(t)) inKm = false;   // KM 块以独立 `-->` 行结束（含同行闭合）
    continue;
  }
  ```
  保留现有 `/^<!--/` 跳过（其它注释）。与既有 `kmStart/kmEnd` 提取（`:234-241`）的边界语义一致（首个 `-->` 即结束）。
- 效果：KM 行不再污染 questionId，`knowledgePoints` 仍由 `parseKmBlock` 独立解析（不受影响）。

**F2 qid 正则兼容双引号（复盘 #2，高）**
- 改动：`:247` 单正则合并（`[^`]+` → 引号类 + `[^"`]+`），并删除 `:249-250` 的 `qid2` 死代码：
  ```js
  const qid = t.match(/^question_id:\s*["`]?([^"`]+)["`]?\s*$/);
  if (qid) { questionId = qid[1].trim(); continue; }
  ```
- 说明：F1 后 KM 双引号行已被跳过，此正则为**纵深防御**（正文万一出现引号/裸 id 也能干净解析）；`question_id_list:` 行因 `question_id` 后紧跟 `_` 而非 `:`，天然不匹配，无需处理。

**F3 stem 取真实题干（复盘 #3，高）**
- 改动：`:255` `const inline = stemMark[1].trim();` → `const inline = stemMark[2].trim();`
- 效果：题干为同一行内容时直接取到；内容在后续行时 `[2]` 为空 → `if (inline)` 不赋值 → `phase='stem'` 继续累积（现有行为不变）。下游 `detectStemMode`/`classifyQuestion`/`detectLiteracy`/全文检索全部恢复真实。

### P1 · 索引层（`plugins/core/index.js` `loadBank` + `outputs`，复盘 #4）

**F4 索引版本代际 + mtime 新鲜度检查（高）**
- 问题：`version:1` 索引由 buggy parser 生成；仅比 fileCount 时，即使 parser 修好、文件未变，旧索引仍被信任。
- 改动：
  1. 写盘 `indexData.version: 1 → 2`（parser 代际标记，`:824`）。
  2. `collectMdFiles`（`:34-65`）收集文件时附 `mtime`（防御性读 `mtimeMs ?? mtime`，拿不到置 null，不抛错）。
  3. `loadBank` 磁盘索引信任条件（`:785`）改为三条件：
     ```js
     const builtAt = Date.parse(idx.builtAt) || 0;
     let fresh = idx && idx.version === 2 && idx.fileCount === currentFileCount && Array.isArray(idx.items);
     if (fresh) {
       const maxMtime = files.reduce((mx, f) => (f.mtime && f.mtime > mx ? f.mtime : mx), 0);
       if (maxMtime > 0 && maxMtime > builtAt) fresh = false;  // 任一文件晚于 builtAt → 重建
     }
     if (fresh) { …信任… }
     ```
     stat 不可用（mock/降级）时 `maxMtime === 0` → 跳过 mtime 判断，仅信任 version+fileCount。
- 注意：mtime 单位统一为毫秒数（`Date` 用 `getTime()`，ISO 字符串用 `Date.parse`）；`builtAt` 为 ISO 字符串。

**F5 清理陈旧索引（高）**
- 改动：删除 `outputs/question-index.json`（旧 parser 产物：引号 id + "题干" stem）。重启后首次 `loadBank` 因无索引 + version 不匹配自动全量重建。删文件与 F4 的 version=2 双保险，任一项都足以兜底。
