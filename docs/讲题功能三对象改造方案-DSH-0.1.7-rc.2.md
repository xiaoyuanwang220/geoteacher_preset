## 1. 用户已确定的需求

出题功能保持不变。讲题增加学生、教师、命题人三个讲解对象，默认学生。选择题、综合题共用问题分析框架，仅在选项辨析、答案组织等具体环节区分。

学生与教师都围绕四个核心维度：知识点、解题过程、方法总结、跨学科。共同维度不意味着生成相似文章：学生重在如何解决问题，教师重在通过讲授、追问和活动启发并培养学生的地理思维，帮助其学会独立思考与总结；命题人重在设计与评价，并识别设问、材料和选项中的干扰信息及其作用。

讲解必须由地理问题、材料证据与学科原理推动，不得对照答案补理由。方法总结提炼可迁移思路及适用边界，避免固定因素清单。跨学科从地理问题出发，引入真正有解释价值的其他学科原理，不为凑章节强行关联。

学生与教师的最终回答沿用当前讲题 skill 的“题目定位—审题—破题—反思与迁移”四段式框架，在每段内按对象选择内容、调整详略和表达落点。知识点、解题过程、方法总结、跨学科是融入该框架的分析维度，不另设一套替代四段式的顶层目录。保留现有设问先行、定向读材料、知识选择依据、证据与因果解释、关键辨析、方法提炼和变式等优势；更新“教师版只是可照读的学生讲稿”“学生版仅指无答案支架”的旧规定。保留独立解题、核验、讲解的先后纪律及题库访问约束。本文四个内容维度与旧有“四问论证”不同，后者继续用于推理质量检查。

## 3. 产品行为与对象区分

### 3.1 参数与默认行为

建议增加 `audience: student | teacher | setter`，省略时为 student；中文显示“学生／教师／命题人”。年级、学情、讲授时长为可选信息，缺失不强制长表单。

“讲解这道题”默认学生；“这道题如何讲授、怎么引导学生总结”进入教师；“从命题角度分析”进入命题人。仅因为当前用户是教师，不自动选教师模式。“写一段可以直接对学生讲的话”属于学生导向讲稿。

默认只生成一个模式。用户要求多版本才并列输出。切换对象、题目未变时复用已核验分析，重新组织讲稿；改变题面或答案依据后必须重新核验。

“学生讲解”允许自然推出答案；“无答案练习支架”是另一个可选交付形式，不得混为同一模式。

### 3.2 四维内容矩阵

| 维度 | 学生 | 教师 | 命题人 |
| --- | --- | --- | --- |
| 知识点 | 学什么、何时想到、怎样使用、适用条件 | 教什么、重点与难点及原因、知识联系、突破方式 | 考什么、实际任务是否有效承载目标 |
| 解题过程 | 如何起步、选择角度、连接证据和原理、检查判断 | 怎样启发学生自主提出问题、选择角度、寻找证据、解释机制和检验判断，逐步撤去支架 | 材料和设问如何引发认知操作、是否可绕开考点；识别设问、材料、选项中的干扰及其认知作用 |
| 方法总结 | 下一次如何独立组织思考及调整 | 怎样从个例引导概括、纠正过度概括、检测迁移 | 是否测到迁移、是否仅靠记忆套路即可完成 |
| 跨学科 | 换一个视角帮助理解与求解 | 何时引入、怎样搭桥、前置知识和误解防范 | 是否服务目标、材料是否交代必要知识、有无暗中超纲 |

### 3.3 学生与教师共用现有四段式框架

以当前 `.agent-presets/geo-teacher/skills/geo-question-explainer.md` 为回答框架基线，在其上增强，不另起炉灶。保留四个主要环节，按题目和对象灵活设置子标题；不要把本方案的分析维度、字段清单逐项机械渲染为额外章节。

| 现有环节 | 融入的维度 | 学生版的取舍与侧重 | 教师版的取舍与侧重 |
| --- | --- | --- | --- |
| ① 题目定位 | 知识点为主 | 简明交代要解决的问题、核心知识和必要联系；压缩年份、分值、素养标签等与理解无直接关系的元信息 | 说明教学价值、核心与支撑知识、重点难点及原因、应培养的思维；按需要保留定位卡和讲授时间参考 |
| ② 审题 | 解题过程起点 | 引导识别对象、任务动词、限定条件和时空尺度，说明第一步想什么、为什么 | 设计让学生自主界定问题的切入与追问，关注误读与思维起点；说明如何引导学生提出分析角度，而非教师直接宣布框架 |
| ③ 破题 | 解题过程主体、知识应用、跨学科 | 保留读图、定向取证、知识选择、证据—原理—结论及关键辨析，讲清每一步如何推进；有价值时用跨学科视角帮助理解 | 沿相同解题逻辑组织思维启发：追问、学生思维动作、可能回答、分支引导、图示/反例和支架撤除；跨学科说明引入时机、对应关系及边界 |
| ④ 反思与迁移 | 方法总结为主，可含跨学科迁移 | 总结本题错因、可迁移思路和适用边界，提供简短变式或条件变化，帮助下次独立解决问题 | 说明怎样引导学生自己概括、比较和修正方法，如何避免模板化；设计独立迁移检测并说明观察什么表现 |

同一框架允许侧重点显著不同，不要求两版同字数、同子标题或逐段复制。定位可简短，但破题不能省掉关键逻辑；反思不重复解析。跨学科在真正帮助理解的环节自然融入，不强制新增第五个顶层章节。

选择题在破题中保留选项辨析与排除依据，综合题保留结论组织、条件与术语表达；二者都以解决地理问题为主，不让排除选项或凑采分点替代问题分析。原有设问类型提示作为组织参考，不变成每题必套的固定因素清单。变式仍优先使用真实候选，缺少候选时不虚构真题来源。

### 3.4 两种身份的表达与思维培养要求

**学生版**：保留当前讲题 skill 的引导式讲课口吻、无寒暄、思维显性化、答案由推理自然引出、以方法收束等优势。重点让学生知道下一步可以做什么以及为什么。教师如何安排课堂、如何诊断学情等内容一般不占正文；重要推理给出可检验的证据与解释，不机械重复同一句“为什么”。学生讲解可呈现答案，无答案练习支架仍按需另附。

**教师版**：沿用四段式，但将“审题—破题”重点转为学生思维的启发与培养，将“反思与迁移”重点转为总结方法的引导和独立迁移检测。正确解题逻辑必须清楚，主体篇幅用于如何让学生产生、检验和修正想法，而不只是教师如何解释答案。具体关注时空尺度、要素联系、过程与因果、证据比较和条件检验，按本题需要选择，不强凑思维标签。

关键节点可用“思维培养目标→问题/活动→学生思维动作→关注的回答及依据→分支追问与必要支架→撤去支架后的独立表现”组织，但不要求每一步都输出长表。避免连续使用只需回答“是/否”的诱导问题，把学生带向预设答案。没有真实学情时只提出待验证障碍；“粗心”不得替代具体错误环节分析。

教师版示例（区域差异问题）：在审题段问“比较的现象、时期和空间尺度是否一致”，引导界定问题；在破题段问“哪些条件可能造成差异，为什么”“哪条材料支持解释，有没有解释不了的现象”，引导提出假设、筛选证据和检验因果；在反思与迁移段让学生概括分析路径，再改变一个条件，检查能否独立调整判断。说明这些追问培养什么思维及何时减少提示，不复制一份学生解析后追加泛化教学建议。

### 3.5 命题人版结构

考查目标→情境/材料/设问→设问、材料与选项的干扰辨析→预期认知路径→答案成立条件及错误路径→迁移与跨学科设计→题组和质量评价。

选择题检查唯一性及干扰项机制；综合题检查合理答案范围、评分依据和开放性。分析已有题目不强迫其服从生成器的题数或生成顺序约束。无原作者说明时标注“依据题面推断”；无试测数据时不生成正确率、区分度数值或实际测量效果断言。


#### 设问、材料与选项的干扰辨析（必检）

命题人版必须逐层检查干扰，不能把“干扰项分析”缩减为错误选项解析。术语上将错误选项称为干扰项，将设问、材料中的相关内容称为干扰信息或干扰机制。

| 层次 | 识别内容 | 分析要求 |
| --- | --- | --- |
| 设问 | 易被忽略或误读的对象、任务动词、时间空间尺度、比较基准、条件限定，以及可能诱发惯性作答的表述 | 指出何种误读会把思考带向哪里，解释正确任务边界；限定词本身通常是必要条件，不能直接认定为干扰或故意陷阱 |
| 材料（含图表） | 与当前小问无直接关系的信息、显著但非主导的因素、可能诱发错误归因的数据或现象、适用尺度不同的信息 | 区分关键证据、必要背景、其他小问所需信息和实际干扰；说明其为何看似有关、不能支持哪一步推断、如何用证据和原理辨别 |
| 选项（选择题） | 概念混淆、因果倒置、证据遗漏、尺度错配、部分正确但不回答当前问题等 | 说明吸引力、可能对应的认知偏差、排除依据，以及正确项依赖的条件；不止宣布选项错误 |

每个确认存在的干扰给出：所在位置及原文/图表证据→可能诱发的错误思路→辨别所需的知识或证据→对考查的作用→质量判断（有效认知辨析、无效噪声或歧义风险）。该判断是依据题面作出的分析，不能冒称原作者故意如此设计。

综合题同样检查设问与材料；没有选项则将选项层标为不适用，可以分析典型偏离思路，但不得虚构选项。某层未发现干扰时如实说明，不强凑三层。不把所有未用于最终答案的内容都判作干扰，也不把合理限定误判为文字陷阱。评价干扰是否服务于地理思维辨析，而非仅增加阅读负担。
## 4. 方法总结与跨学科的专门要求

方法按问题结构提炼，例如比较区域差异、解释过程演变、判断因素变化的影响，而非只按“原因题”“措施题”套清单。允许用维度词表帮助排查，但最终取舍必须有问题和证据依据。不能把“材料没有明说”简单等同于“不能运用合理的课程知识推导”。

跨学科按“地理解释需要→学科工具→情境对应→解释贡献→适用限制”展开。每题检查价值，状态可记录为 applicable / not_applicable / pending；不适用时简短说明即可，证据不足时不硬讲。

例如连通器视角必须检查连通、静止液体等相关条件，区分严格适用和有限类比；不得把所有水体流动直接解释为连通器。必要的新推理交回分析与核验阶段，不能在最终重组时加入未经核验的结论。跨学科补充也不应成为未交代的作答必备知识。

建议报告添加 schemaVersion、audience、共同分析要求、audiencePlan、interdisciplinary 状态与核验引用。教师 audiencePlan 应支持思维目标、学生思维动作、递进追问、支架及撤除条件、独立迁移表现；命题人 audiencePlan 应支持按设问/材料/选项定位的干扰分析及证据、不适用状态。具体名称由现有接口决定，避免同时维护多个正文权威源。不要靠关键词启发式自动生成科学结论或跨学科关联。

### 核验约束

当前 judgeReport 主要承载标准核验骨架，不能仅因为 JSON 可解析就认定模型已经完成实质核验。执行者先检查现有记录机制，明确区分标准答案依据、独立解题产物、核验结论。

缺独立答案、核验报告损坏、qid 不一致或记录失效时，geo_explain 应返回明确的缺失/待核验状态，不静默吞错并生成“已核验”报告。仅客户端传入 verified=true 不能成为可靠证据；存在会话记录机制则绑定实际记录，否则诚实保留“提供材料待核验”的状态，并在方案实施记录中说明保证范围。

保留题面隔离和原生图片能力；不以文本读图、不恢复旧 OCR 替代链路、不直读真题库 Markdown。

## 7. DSH 分阶段执行清单

### M0：确认现状

检查 git 状态、实际安装及挂载、工具目录、技能发现、讲题调用链、渲染与保存位置。记录现有行为和待修改清单，保留用户未提交工作。运行适用基线检查，区分既有失败。

### M1：规范与技能

在现有讲题四段式内融入四维内容并实现三对象规范，更新 persona/tool 描述中的冲突规则，将教师思维启发与培养、命题人三层干扰辨析同步纳入技能、骨架、渲染和评审要求。用同一道题形成三个示例并做去标题辨识，确认区别在任务内容而非措辞。

### M2：工具、核心与显示

贯通 audience；补输入校验与核验状态；按实际消费者实现兼容；接入对象选择和显示。保留学生/教师现有四段式及其字段映射，将题型差异保留在具体分析环节，不新建替代总框架。保持出题功能源文件不变。

### M3：测试及桌面验证

执行现有命令 `npm run verify:geo`、`npm run test:native-images`（先检查依赖和脚本适用范围）。`npm run verify:workbench` 已随地理工作台退役删除（2026-09-30），不再执行。新增必要行为测试，避免仅断言提示词字符串。

在 DSH 0.1.7-rc.2 的实际 geo-teacher 新会话验证技能可发现、geo_explain 参数可见、同题三模式可调用、中文 Markdown 可阅读、涉图题图片可用、缺前置产物时不冒充核验完成。不要仅凭 Node 测试通过声称桌面端通过。

### M4：交付与恢复说明

交付修改清单、命令结果、桌面验证记录、样例路径、未完成项和恢复方式。只恢复本次变更，禁止用全仓 reset 覆盖用户工作。不要自动升级宿主或安装插件来掩盖兼容问题。

## 8. 验收矩阵

### 自动化与集成检查

- audience 缺省、三种合法值、非法值；参数从工具到核心到渲染不丢失。
- 独立答案缺失、无效 judgeReport、跨题核验、版本变化均不返回虚假完成。
- 切换对象不串缓存、不重复读入原始答案冒充独立解题。
- 旧调用默认学生仍可用；生成器行为与原生图片回归不变。
- 若实现题包适配，另测版本/指纹不一致、缺图、非 qid 标识和上下文答案污染。

### 内容评审

首轮选至少四题：自然地理选择题、人文地理综合题、一题具有有效跨学科联系、一题不宜强行跨学科。允许前两项与后两项重叠，但应覆盖两种题型、涉图与非涉图。各题生成三对象版本；通过题库工具取样，不直接读含答案的题库文件。

逐项评审：知识应用解释、问题驱动推理、方法边界、跨学科有效性、对象侧重点、事实与核验一致性。每项按“缺失/部分达到/达到”记录证据，不以章节出现就判合格。

硬性不通过：科学错误、答案泄露后冒称独立求解、伪造命题意图/试测数据、强行跨学科、教师版仅改称呼或加长学生版、方法退化为固定因素清单。

差异化专门检查：去掉标题后仍能判断服务对象；教师版须有针对本题的思维目标、学生思维动作、递进追问、支架撤除、总结引导和独立迁移检测，不能只是教师解释答案的顺序；学生版须有可执行的思考步骤；命题人版须评价设计是否奏效，并逐层检查设问、材料、选项中的干扰，说明位置、错误路径与辨别依据，不只复述说明。

结构检查通过、内容质量通过、桌面验证通过分别记录。未做人工学科评审时明确标注，不能输出“全部验收通过”。
### 本次补充需求的专项验收

- 教师版：至少展示一条从学生自主提出解释，到证据检验，再到独立迁移的具体引导路径，并标明思维培养目的；不把诱导学生猜标准答案视为思维启发。
- 命题人版：样例覆盖设问边界易误读、材料中的显著非主导因素、选择题的有效干扰项，以及综合题无选项的情况；各层可标为未发现/不适用，不能机械凑齐。
- 负例检查：不能把必要限定、必要背景或题组其他小问所需信息一律当成干扰；不能把未经验证的学生错误路径写成实际学情。
- DSH 执行时须将这两项补充同步落实到输出规范、对象专属骨架、显示和内容评审，不得只在文档末尾增加说明而保留旧主体行为。
### 现有讲题框架保留验收（最新补充）

- 学生版与教师版均能辨认出“题目定位—审题—破题—反思与迁移”四个主要环节，四维内容融入其中，不替换为此前方案列出的五段/六段新结构。
- 学生版保留现有 skill 的问题起点、读图取证、知识选择依据、推理与关键辨析、方法收束；教师版在相同环节中突出思维启发、重难点突破、引导总结与迁移检测。
- 以同题旧讲稿为基线，逐段说明保留、增强、压缩的内容与对象依据；不能为区别对象而删除必要证据、因果环节或方法边界。
- 四段式相同不等于正文相同；去掉对象标题仍可识别各自侧重点。命题人模式保留设计评价及三层干扰辨析的独立结构。
- DSH 实施时以本次明确的“保留现有框架、按身份取舍”为准，同步检查技能、工具描述、核心骨架、渲染和测试，清除任何要求放弃现有学生/教师四段式的旧表述。
