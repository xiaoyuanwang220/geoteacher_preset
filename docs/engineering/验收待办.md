## 三、工程简化与维护观察项（低优先级）

以下内部重构候选不影响外部契约，仅在修改对应模块时顺带评估：

1. **抽取插件共享 HTTP/渲染辅助函数**：`taxonomy`、`bank`、`analysis`、`generator` 四个插件内存在相同的 `sendJson`、`parseQuery`、`renderJson` 辅助函数，后续可在预设包内抽为共享模块（需同步确认 ESM 相对导入在 DSH 下正常）。
2. **`resolveImagePath` 内置化**：`plugins/core/index.js` 手写的路径拼接可评估用 `node:path` 的 `resolve`/`normalize` 替代。
3. **`geo-verify.mjs` 缺少 `DSH_WEB_URL` 时的行为**：桌面端端口已由系统动态分配，运行时检查在未提供 `DSH_WEB_URL` 时应直接给出明确提示，不再回落旧 `19387` 默认端口。
4. **`core/index.js` 单文件体积观察**：当前集中了承载解析、分析、骨架与讲题 run 状态机，后续新增大型能力时可按职责拆分子模块。
