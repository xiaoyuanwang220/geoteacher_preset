## 一、核心分层原则

1. **能程序化的检查一律程序化**：语法、导出、声明行、服务隔离、路由冲突、技能预算与讲题流水线防回退断言，统一收口到 `scripts/geo-verify.mjs`（`npm run verify:geo`），不依赖 Agent 阅读清单手工核对。
2. **开发技能与教师技能物理隔离**：
   - **开发维护类 Skill** 放在仓库根 `.agents/skills/<skill-name>/SKILL.md`，仅面向维护本仓库的编码 Agent，**绝不进入** `geo-teacher` 教师运行预设，也不随预设 npm 包分发。
   - **教师业务类 Skill** 放在 `.agent-presets/geo-teacher/skills/`，随预设加载。
3. **教师端规范内嵌，术语单一权威**：不单独设立“教师写作规范”技能，各业务技能自行内嵌表达要求，所有地理与交付术语统一以 [术语表](../术语表.md) 为唯一权威。
4. **工具 ≠ 技能**：单步确定性查询工具（`geo_taxonomy`、`geo_search_questions`、`geo_question_detail`、`geo_style_profile`）不配技能；只有需要**多阶段编排与专业判断**的任务（讲题、解题、出题/润色、课程方案）才配套技能。

## 二、开发维护技能清单（`.agents/skills/`，共 4 个）

```text
.agents/skills/
├── geo-dev-checklist/
│   ├── SKILL.md                                  # 三层验证：verify:geo + 人工判断项 + 会话轨迹审查
│   └── references/session-trajectory-review.md   # 多帧 zstd 会话日志读取与三维度轨迹审计方法
├── geo-code-review/
│   └── SKILL.md                                  # 语义代码审查（生命周期/所有权/契约/流水线纪律）
├── geo-doc-writing/
│   └── SKILL.md                                  # 开发文档写作规范（保留完整命题、删作者痕迹、对齐术语表）
└── geo-textbook-reverse/
    └── SKILL.md                                  # 高中地理教材原文结构化与学科思想逆向规范
```

| 技能 | 触发场景 | 核心职责边界 |
| :-- | :-- | :-- |
| `geo-dev-checklist` | 修改插件、组合或技能后，提交前与重启后 | 执行 `npm run verify:geo`、核对重启生效项、审查真实预设会话轨迹（工具调用序列／错误码／模型宣称 vs 校验报告事实） |
| `geo-code-review` | 代码审查、检查 diff、找回归风险 | 语义正确性与架构边界审查，findings-first 输出，默认不改代码，不替代 `verify:geo` |
| `geo-doc-writing` | 编写或修订 `docs/`、开发技能、工具 `description` | 执行 proposition-preservation（只删废话与会话残留，不删契约），强制对齐 [术语表](../术语表.md) |
| `geo-textbook-reverse` | 教材原文结构化、新增或升级分册学科思想解读 | 四级忠实切分原文、客观解码认识暗线与模块咬合，禁止写“压缩留白建议”或预设固定教法 |

## 四、确定性检查与写作边界

### 1. 静态与运行时验证入口
- `npm run verify:geo -- --source`：纯源码确定性检查（插件语法与 mock apply、bundle 导出与 patch 声明行、服务 `isolate` 白名单、路由去重、双技能根 frontmatter 预算与引用可达、讲题隔离断言、命题包双样例校验）。
- `npm run verify:geo -- --runtime`：完整重启 DSH Desktop 后探测 `/geo/core/health` 等运行时端点（读取 `DSH_WEB_URL`）。
- `node --test "test/*.test.mjs"`：行为与边界回归测试。

### 2. Proposition-Preservation 与“去元话语”边界
- **可教学推理必须保留**：审题拆解、材料证据引用、原理选择依据、因果链条、干扰项排除论证。
- **过程性元话语必须删除**：模型自述（“我推测”“我这样想”）、版本修订痕迹（“v2 改为”“之前是”）、评审痕迹（“reviewer 指出”）及照抄解析原文。
- **形式检查不等于事实正确**：`proposition-preservation` 只能防止编辑时漏掉原命题，**不能证明**地理事实准确或答案唯一；学科正确性必须依靠领域评测标准与人工核验。
