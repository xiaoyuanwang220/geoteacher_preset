## 1. 产品定位与演进重心

本模块面向高中地理日常练习打磨、课堂即时检测与师范生命题实训，确立**「以高考真题风格标尺润色模拟题为核心、课后快测简题为延伸、完整原创命题包为底座」**的务实定位：

1. **核心场景——日常模拟题高考化润色**：一线教学中使用的大量模拟题常存在语言口语化、背景材料堆砌冗余、设问指向模糊、干扰项或采分点不够严谨等问题。系统依托本地真题库提炼的省份「风格档案」与「命题蓝图」，对现有模拟题的材料裁剪、设问模式、选项错因或综合题采分点及评分边界进行精细化打磨，使其逼近高考真题水准。
2. **延伸场景——课后快速检测简题**：面向课堂收尾与当堂诊断，围绕单个核心考点与本班学情假设，快速生成轻量、聚焦的选择题（允许 1 道小题）或简短综合设问，及时检验本课关键认识是否达成。
3. **实训与比赛场景——完整可追溯命题包**：面向师范生试题命制比赛或深度教研，遵循“学情转译 → 三构思比选 → 六章节初稿 + 双视图投影 + 结构校验”完整流程，额外输出详尽的设计依据、来源证据与三水平学生模拟作答。

无论处于哪种模式，试题本体均遵循同一套质量红线：**选择题答案唯一且干扰项对应明确认知障碍；综合题分值—采分点—证据链三级自洽且开放答案边界可判定；必备知识不暗中超纲；严禁伪造试测统计数据。**

## 2. 支持题型与模式范围（V1 底座）

### 2.1 题型契约（一包一题型，禁混排）

题型由命题包顶层 `questionType` 声明一次，一个任务包只含一种题型：

| 题型 | `questionType` | 题组形态 | 评分与错因依据 |
| :-- | :-- | :-- | :-- |
| **材料型选择题组** | `single_choice` | 一则共用材料 + 2—3 道单项选择题小题（快测/专项训练允许 1 道） | 答案唯一（A/B/C/D）＋每个干扰项映射一条待验证认知障碍 |
| **材料型综合题** | `comprehensive` | 一则共用材料 + 1 道大题，内含 2—4 个小问 | 各小问分值 ＋ 采分点（要素＋证据链＋分值）＋ 至少 2 档评分标准 ＋ 开放答案边界 ＋ 典型错答模式 |

### 2.2 明确不做的事项

- 不做整卷自动组卷与全卷分值配比；
- 不在未经教师确认图表方案前直接制作正式图表；
- 不在无真实学生试做数据时输出正确率、难度系数、区分度或选项分布数字；
- 不自动修改考点库 YAML 或将生成题自动写回真题库；
- 不把真题或学术论文原题改头换面后冒充原创题。

## 3. 核心设计原则

### 3.1 先对齐方向（构思/改题诊断），再成稿
默认采用两阶段交互：先定位考点与学情认知障碍、给出 3 个实质不同的构思方向（或模拟题的问题诊断与改写方向），经教师确认选择后再输出完整题组与解析说明。图表先出文字设计提案，获批后再制图。

### 3.2 模糊学情专业化转译
教师只需用日常语言描述薄弱表现（如“热力环流概念混淆”“不会从图里找依据”），系统将其转译为 2—3 个带“可能／待验证”限定的**认知障碍**（`learningHypotheses[]`），后续干扰项或典型错答模式必须与所选障碍一一对应，严禁用“粗心”“审题不细”充当错因。

### 3.3 课标、考点库、教材共同知识与现实素材分工明确

| 依据来源 | 职责边界 |
| :-- | :-- |
| **课程标准** | 确定考查目标、行为动词、核心素养与总体边界 |
| **考点树（KPS）** | 统一考点稳定 ID、定义、`includes`/`excludes` 边界并记录文件版本；命中 `needs_review=true` 节点时记入 `knowledge.needsReviewNodeIds` 并在风险项显著提示，不擅自造新 ID |
| **教材共同知识** | 证明得出正确答案所需的必备知识属于高中生已学范围（允许情境陌生，不允许必备知识暗中超纲；材料外专业术语须在题面解释） |
| **省份风格档案** | 从本地真题库抽取七维度特征（题组结构/材料/图表/设问/选项/解析/综合题），指导模拟题润色与设问模仿；缺样本时采用通用高考规范，不伪称某省风格 |
| **现实政策/新闻/论文** | 新闻优先近 12 个月，长期战略须附近期进展；删除背景后题目若仍原样成立则属无效装饰；论文须经高中教学化转化并诚实标注读取范围（`metadata`/`abstract`/`full_text`） |

## 4. 题组与评分设计要求

1. **递进与独立性**：选择题各小题或综合题各小问共享材料但测量目标独立（如“提取描述 → 机制分析 → 评价迁移”），禁止同义反复提问，禁止后一问要求依赖前一问结论作答（防连环失分）。
2. **综合题三级自洽**：各小问采分点分值之和 ＝ 该小问 `points`；各小问 `points` 之和 ＝ 大题 `totalPoints`。每个采分点必须写清「采分要素 + 材料具体字句证据链 + 分值」。
3. **开放答案边界**：`answerBoundary` 明确列出可接受面向（`acceptable`）与不给分情形（`unacceptable`），灰区记入 `notes`，严禁用“言之有理即可”或 `notes` 代替边界。
4. **核心素养与“四翼”**：四翼（基础性、综合性、应用性、创新性）回答“怎么考”，须给出题面承载证据，不强凑四翼，不把四翼相加当难度分。
5. **四维定性难度**：覆盖「考查知识与教材依据、信息加工负荷、认知水平、错因/采分点区分度」（选择题用 `distractorDiscrimination`，综合题用 `scoringDiscrimination`，二者严禁互换）。
6. **三水平学生模拟作答**：默认模拟 A/B/C 三档认知水平学生的作答与干预建议，明确标注“预测性认知路径”；综合题只记录书面答案与 `hitPointIds`/`missedPointIds`（三档命中集合须真正拉开差距），**不写预估得分数字**。

## 5. 默认六大章节交付结构与模式裁剪

完整命题稿顶层固定为六大章节（专项训练/快测与日常润色模式可按需压缩第三、五章说明篇幅，但必须保留考点依据、答案采分点、错因/边界对应与学生/教师视图分离）：

1. **一、学生用试题**（共用材料、图表或提案说明、小题选项或综合题小问与分值）
2. **二、答案与解析**（唯一答案或分档参考答案与采分点证据链、逐题解析、干扰项分析或评分标准与答案边界）
3. **三、命题设计说明**（学情认知障碍、课标与考点库依据、立意与情境转化、题组递进、核心素养与四翼、四维难度、创新与边界）
4. **四、典型学生模拟作答**（水平 A / B / C 认知路径与教学干预）
5. **五、来源与证据**（课标与考点库版本、政策新闻数据与论文出处、地图审图合规信息）
6. **六、风险与待确认事项**（待复核考点、未制作图表、待独立语义评审项）

## 6. 合格作品十七项验收清单

- [ ] 一则共用材料且只含一种题型（选择题 1—3 道小题，或综合题 1 大题含 2—4 小问）；
- [ ] 模糊学情已转译为待验证认知障碍；
- [ ] 成稿前完成构思/改写方向确认；
- [ ] 核心与支撑考点映射当前考点树并记录版本，`needs_review` 节点已显式提示；
- [ ] 答案必备前提属于高中地理共同知识；
- [ ] 课标要求与核心素养有明确题面承载证据；
- [ ] 现实热点满足时效且与考点实质绑定（非装饰）；
- [ ] 学术论文完成高中教学化转化且读取范围诚实；
- [ ] 选择题答案唯一无歧义；综合题采分点与分值三级自洽、评分标准可判定；
- [ ] 选择题干扰项或综合题典型错答模式均映射到具体认知障碍；
- [ ] 四翼分析有主次与题面证据；
- [ ] 难度分析覆盖四维度且未伪造统计指标；
- [ ] 三档学生模拟路径与错因一致，综合题命中采分点有区分且未写预估分数；
- [ ] 拟用图表先说明内容、作用与必要性并获确认；
- [ ] 数据图、改绘示意图与地图（官方底图＋审图号，禁 AI 绘行政疆界）合规；
- [ ] 全部事实、数据与文献来源可追溯；
- [ ] 未照搬真题或论文原图冒充原创。
