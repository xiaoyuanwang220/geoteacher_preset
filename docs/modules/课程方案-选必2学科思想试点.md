# 选必2学科思想驱动教学设计试点方案

> 日期：2026-11-16 ｜ 状态：**已接入源码，待桌面会话轨迹验证**（见 [验收待办](../engineering/验收待办.md)）。
试点教材：人教版选择性必修2《区域发展》。具体版次、印次与原图完整性须在资料审定时核实。

## 1. 目标与假设

为每册教材建立有理论来源、有教材证据的学科思想解读，使模型在明确学科认识方向的基础上，自主选择情境、材料、问题组织、学习支架和评价方式。课例蒸馏与灵感索引提供可选的教学经验。

试点假设：相较于现有技能，增加经审定的教材思想解读，能够提高教学设计的科学解释质量和学生认识活动的质量，同时保持教学选择的适切性与多样性。

思想解读规定解释依据及适用边界，不预设每节课必须覆盖哪些思想，也不预设发展决策的唯一结论。思想方向正确不等于材料充分、推理成立或课堂可实施，现有依据核验与交付检查继续承担这些职责。

“地域思想、空间关系思想、尺度思想、系统思想、过程思想、地方意义视角、空间正义视角”已登记为项目分析用语，定义见术语表。它们不是统一公认的“六大思想”，教学含义见技能共用思想依据，文献读取范围见本方案末尾的维护记录。

## 3. 资料分层

### 3.1 共用思想依据

技能分别说明各思想的含义、适用情形及证据要求。章节条目分析教材如何展开认识。构思阶段可选读少量对照示例，了解同一思想怎样服务不同教学判断，以及换用案例时需要重新核实什么。

理论出处与文献读取范围保存在本方案，供维护时复核。日常备课直接使用本地解读。

### 3.2 每册教材解读

每册包含一份总体说明和按章组织的章节条目。总体说明解释全书如何安排认识递进；章节条目说明具体内容怎样承载学科思想。

| 条目内容 | 要求 |
|---|---|
| 核心认识命题 | 写清学生需要理解的关系，不能只有思想名称 |
| 教材证据 | 记录章节、栏目、图表或设问；保留可核对定位 |
| 思想对应 | 引用共用思想依据，不在各册重复定义 |
| 证据强度 | 区分直接体现、可进一步开发、证据不足 |
| 边界与误解 | 说明结论在哪些条件下成立，防止过度推广 |
| 理解表现 | 描述什么解释或判断能表明理解，不规定活动形式 |

结构化稿中的图示描述与教材图注原文应区分；涉及图值、空间关系或实际读图难度时回查原图。资料身份记录教材版本、源文件、解读版本、审定状态与修订日期。修改教材或总结后，保留对应关系，避免旧定位静默失效。

### 3.3 教学经验与灵感索引

蒸馏条目应说明：适合解决什么学习困难、依赖什么证据条件、可能支持什么认识、何时不适用，以及原课例来源。

思想与教学机制允许多对多关联，不建立“尺度思想必须用尺度切换活动”等固定映射。材料呈现、支架与反馈等一般教学经验可以不关联特定地理思想。模型可以不用索引，也可以提出索引外的设计。

## 4. 选必2解读范围

| 候选思想或视角 | 重点章节 | 重点认识 |
|---|---|---|
| 地域思想 | 第一章第二节、毛里求斯问题研究；第三章第二节 | 条件组合不同，经验迁移需要检验适用性 |
| 空间关系思想 | 第三章第一节；第四章第二至四节 | 位置、流动、分工与空间组织参与塑造发展 |
| 尺度思想 | 第一章第一节；第四章第一节 | 区域层级及其作用；过程范围与治理范围的匹配 |
| 系统思想 | 第一章第二节；第二章第二节；第四章第一节 | 相互作用与反馈形成问题，治理应回应机制 |
| 过程思想 | 第二章第三节；第三章第二节；第四章第三节 | 当前状态由演变形成，条件及其作用随时间改变 |
| 空间正义视角 | 第四章第一节 | 跨区域收益、责任与代价分配 |
| 地方意义视角 | 第一章方言与培田村材料；景德镇问题研究 | 有文化意义材料，但地方体验与依恋的任务证据有限 |

前五项作为重点分析方向；空间正义按实际任务使用；地方意义保持有限对应，不为完成分类补造教材意图。上述对应是待审定的研究假设，不是每节课的思想配额。

章节条目示例：

> **第四章第一节：流域内协调发展**  
> 核心认识：水及其影响沿流域传递，治理需要协调跨行政区的联系与利益。  
> 教材证据：流域统筹管理课文、莱茵河责任分担活动。  
> 思想对应：系统、尺度；责任分配可从空间正义视角分析。  
> 边界：统筹管理不等于取消地方管理，利益冲突也不全是技术问题。  
> 理解表现：能说明局部措施如何影响其他区域，并据此解释协作范围与责任安排。

## 5. 运行时读取与自主决策

沿用现有五阶段，不新增教师确认环节。

| 阶段 | 接入动作 | 自主选择范围 |
|---|---|---|
| 1 取依据 | 核实教材身份，读取本册概述与本节解读，回查相关原文；把采用的认识命题和来源写入现有依据文件 | 确定与本课目标有关的认识，不要求覆盖所有候选思想 |
| 2 选材料 | 判断材料能否支持所需关系、过程或决策条件 | 保留、重组教材或开发新情境，沿用已有教师方向 |
| 3 构思 | 依据学习目标、学情与材料自主设计；需要时查灵感索引 | 情境数量、教法、任务顺序、表达与成果形式 |
| 4 写材料源 | 沿用已确认构思与现有 `lesson.json` | 不要求增加思想展示章节，学生材料使用具体学习语言 |
| 5 自查交付 | 检查核心认识是否被任务与评价实际承载 | 不按思想出现次数、覆盖数量或教学机制编号验收 |

思想解读不能替代课标原文、教材原文或教师任务要求。出现冲突时先核对源文和版本，在依据文件中记录具体差异，不机械服从预设总结。模型可提出有证据的补充解释，但不自行改写已审定的共用资料。

仅对已接入的选必2读取该资料；其他教材沿用现有路径。选必2版本不匹配或总结未审定时，明确其参考状态，回到原文分析，不能声称使用了经过审定的匹配依据。

索引负责教材身份与路径匹配。模型每次读取概述和相关章节，不默认加载全册，更不默认加载全部教材。依据文件保存实际使用的解读版本与条目来源，以便复核。

首轮只增加参考文件并调整技能入口、相关引用和检查说明。暂不引入数据库、向量检索、新插件、工具或界面。后续若教材数量、版本分支和检索需求确实增长，再评估技术扩展。

思想解读保持独立文件，便于对照试验及撤回。撤回试点时恢复原读取路径，保留实验记录，不删除源教材和既有教学成果。

## 7. 职责与验证边界

教师负责测试课题选择、测试安排、评价标准、效果评价及是否推广的判断。本方案不规定测试课题、样本数量、对照分组、评分方法或课堂试验流程，也不将这些工作列入模型交付。

模型负责理论来源核验、选必2教材思想解读、技能读取规则接入及工程验证。工程验证确认文件引用、按需读取和既有生成交付流程正常，不代替教师的教学效果评价，不自动批量生成测试课程。

现有课程方案中的学生学习评价设计与交付前自查继续保留；它们属于日常课程生成职责，与本次由教师负责的试点效果评价不同。

## 8. 实施顺序与交付

1. 核实教材版本与原图，确认灵感卡的实际位置。
2. 建立共用思想依据及来源记录，审定候选术语与理论边界。
3. 完成选必2四章解读，逐项核对教材证据，形成可审阅资料。
4. 接入按需读取规则，核对既有契约，执行适用的 `geo-dev-checklist` 验证；真实会话检查仅核对读取与功能运行，不承担教学效果评价。
5. 交付共用思想依据、选必2解读、技能改动说明与工程验证结果，供教师自行测试和评价。
6. 根据教师反馈调整资料与接入方式；扩展教材及进一步调整灵感索引由后续任务确定。
