# 地理教师辅助 Agent — 使用指南

> 状态：2026-08-21（内容部分）／2026-09-27（部署与验证部分按 DSH `0.1.7-rc.2` 桌面端更新）／2026-09-28（讲题三对象）
> GeoTeacher 使用 DSH 官方多模态模型；题库图片由 `geo_solve` 作为原生附件交付，不再经过视觉转录插件。

## 一、三种使用入口

### 1. Web 面板（可视化浏览/操作）

桌面端打开 `http://127.0.0.1:19387/geo-teacher`（可用 `DSH_WEB_URL` 覆盖实际地址），含三个标签：

| 标签 | 功能 | 操作路径 |
| :--- | :--- | :--- |
| 📚 考点真题 | 考点树浏览 + 真题检索 + 真题分析 | 点考点 → 看题组列表 → 进题组 → 🔍「为什么这样考 · 命题蓝图」→ ⬇ 导出 Markdown |
| 🎯 出题助手 | 查看真题风格档案（各省融合七维度） | 打开即显示风格档案与样本来源；出题请到对话中说需求 |
| 📋 课程方案 | 占位（P4 开发中） | — |

导出的分析报告保存到 `E:\geo_edu_agent\outputs\`。

### 2. 对话使用（模型自动调用 geo 工具链）

在选择了「地理教师辅助」预设的会话里，直接用自然语言提需求，模型会自动调用对应工具：

| 你说 | 模型会做 |
| :--- | :--- |
| 「查一下『人口分布』这个考点有哪些真题」 | `geo_taxonomy`（定位考点）+ `geo_search_questions`（检索题组） |
| 「2025年湖南卷 Q4 这道题为什么这样考」 | `geo_question_detail`（取题组）+ `geo_analyze`（分析+命题蓝图） |
| 「把这个分析导出成 markdown 文件」 | `geo_export_analysis`（写入 outputs） |
| 「广东卷真题大概是什么风格」 | `geo_style_profile`（七维度风格档案） |
| 「这道题怎么做/怎么解」（讲题 Solver） | `geo_solve`（题面+审题骨架+原生图片附件，不含答案/解析；模型独立解题，需按顺序先执行此步） |
| 「我的解题对了吗/帮我核验」（讲题 Judge） | `geo_judge`（传入独立答案，开放答案/解析/采分点，核验覆盖/错误/遗漏/干扰项解释） |
| 「把这题讲成讲题稿/怎么讲给学生」（讲题 Explainer · 学生对象，默认） | `geo_explain`（传入独立答案+judge 结果，产出「题目定位—审题—破题—反思与迁移」四段式讲题稿骨架+变式；需先完成 solve→judge） |
| 「这道题如何讲授/怎么引导学生自己总结」（讲题 Explainer · 教师对象） | `geo_explain` 带 `audience: "teacher"`（同一四段式，段内侧重学生思维的启发、追问与支架撤除；附教师 audiencePlan） |
| 「从命题角度分析这道题/干扰项怎么设计的」（讲题 Explainer · 命题人对象） | `geo_explain` 带 `audience: "setter"`（考查目标→情境材料设问→三层干扰辨析→认知路径→答案成立条件→迁移与跨学科设计→题组和质量评价） |

> 讲题对象由 `geo_explain` 的 `audience` 参数决定：`student` 学生（可省略，缺省即学生）／`teacher` 教师／`setter` 命题人。默认只生成一个对象，需要多版本才说明。仅因为使用者是教师，不会自动切到教师对象。切换对象而题目未变时复用已核验分析；改题面或答案依据须重新核验。缺 solve/judge 产物时 `geo_explain` 返回「待核验」状态，不冒充核验完成。

### 3. 出题技能（专门命题流程）

对话中说「出几道题」「按广东卷风格出 3 道选择题」「出高一课堂练习」等，模型会加载 **geo-question-generator** 技能：

1. 明确年级、主题、学情和用途，核对本地考点库、课标与教材依据；真题风格通过现有工具取得。
2. 提出三个构思，等待教师选择后生成 Markdown 初稿；图表提案须另行确认。
3. 命题稿采用六大章节：学生用试题／答案与解析／命题设计说明／典型学生模拟作答／来源与证据／风险与待确认事项。
4. 命题包以 `outputs/出题/<taskId>/package.json` 为唯一编辑源；学生投影只含题面，教师投影包含答案与解析，并绑定同一 revision。
5. 按构思待选择、初稿完成、可使用、待补充四种完成度如实交付；必要图表或证据缺失时不得宣称可使用。

> 当前目录包技能与命题包 schema 已落地；M1 桌面验证和 M2 完整题组验收尚未在实施记录中闭环。以上是当前技能要求，不代表校验、投影与端到端交付已全部验证。详见 [M1 实施记录](geography-question-generation-m1-record.md) 和 [执行方案](geography-question-generation-execution-plan.md)。

### 图片解题

当前直接使用 DeepSeek 多模态模型读取图片。题库题由 `geo_solve` 返回题面与原生图片附件；教师上传的图片由当前模型读取；独立本地图片路径通过官方 `read_image` 读取。图片无法读取时说明证据缺失，不补猜图中内容。图片交付实现与状态含义见 [讲题工作流](讲题工作流修复方案.md)。

## 二、常用话术示例

```
- 出 3 道选择题，考“农业区位因素”，高一难度
- 按广东卷风格出 1 道综合题，考区域发展
- 人口迁移这个考点近几年考得多吗？都有哪些题
- 帮我分析一下 2025 年福建卷 Q7-Q8 怎么考
- 这道题怎么讲给学生听（学生对象，可省略对象）
- 这道题我该怎么讲授、怎么引导学生自己总结（教师对象）
- 从命题角度分析这道题的材料和选项（命题人对象）
- 把刚才的分析导出成 markdown
```

- ✅ 考点树 / 真题检索与详情 / 真题分析+命题蓝图 / 风格档案 / 出题技能 / 仪表盘

- ✅ 讲题三对象：学生（默认）/教师/命题人，经 `geo_explain` 的 `audience` 参数选择；**仅会话工具模式**，面板暂无讲题入口与对象选择控件（见 `docs\讲题三对象改造-实施记录.md`）

- ⏳ 课程方案生成（教学设计+学生材料+观察记录表，渲染 docx/html）——开发中
- ⏳ 教学动态模型（geo-teaching-model 接入）——规划中
- ⚠️ **联网证据按实际读取范围标注**：预设配置已启用 `fetch: true`；正文是否可读取决于会话是否加载配置以及来源站点。只能获得链接或摘要时，不得声称读过全文。历史探测与限制见 [M0 记录](geography-question-generation-m0-baseline.md) §2。
- ⚠️ 修改预设：`E:\geo_edu_agent\.agent-presets\geo-teacher\` 以 `link:` 方式挂在 `desktop` profile 上，**改仓库即改运行时，不需要同步副本**；插件/组合改动需完整重启桌面后生效（技能文档不需要）

## 五、故障排查

- **工具没出现**：确认会话用的是「地理教师辅助」预设；**插件**改动需完整重启桌面（关闭主窗口可能只是隐藏，需确认进程已退出）；技能文档改动由技能发现器监听，不需要重启。
- **面板打不开/路由 404**：重启桌面后 geo 插件应自动挂载；若仍异常，确认 `desktop` profile 的依赖指向 `E:/geo_edu_agent/.agent-presets/geo-teacher` 且该目录含 `cordis.patch.yml` 与 `skills\`；跑 `node scripts\geo-verify.mjs --source` 看接线检查。
- **导出失败**：需重启使写盘沙箱策略生效（写入 `E:\geo_edu_agent\outputs`）。
