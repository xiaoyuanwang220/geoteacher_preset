# 地理教师辅助 Agent — 使用指南

> 状态：2026-08-15　配套插件化重构 P0–P2 完成版（内核 + 考点树/真题库/真题分析/出题支持/UI 六个插件，6 个模型工具，出题技能）。

## 一、三种使用入口

### 1. Web 面板（可视化浏览/操作）

打开 `http://127.0.0.1:3080/geo-teacher`，含三个标签：

| 标签 | 功能 | 操作路径 |
| :--- | :--- | :--- |
| 📚 考点真题 | 考点树浏览 + 真题检索 + 真题分析 | 点考点 → 看题组列表 → 进题组 → 🔍「为什么这样考 · 命题蓝图」→ ⬇ 导出 Markdown |
| 🎯 出题助手 | 查看真题风格档案（各省融合七维度） | 打开即显示风格档案与样本来源；出题请到对话中说需求 |
| 📋 课程方案 | 占位（P4 开发中） | — |

导出的分析报告保存到 `E:\geo_edu_agent\outputs\`。

### 2. 对话使用（模型自动调用 geo 工具链）

在选择了「地理教师辅助」预设的会话里，直接用自然语言提需求，模型会自动调用对应工具：

| 你说 | 模型会做 |
| :--- | :--- |
| 「查一下『人口分布』这个考点有哪些真题」 | `geo_taxonomy`（定位考点）+ `geo_search_questions`（检索题组） |
| 「2025年湖南卷 Q4 这道题为什么这样考」 | `geo_question_detail`（取题组）+ `geo_analyze`（分析+命题蓝图） |
| 「把这个分析导出成 markdown 文件」 | `geo_export_analysis`（写入 outputs） |
| 「广东卷真题大概是什么风格」 | `geo_style_profile`（七维度风格档案） |
| 「这道题怎么做/怎么解」（讲题 Solver） | `geo_solve`（给题面+审题骨架，不含答案/解析，模型独立解题产出思维轨迹） |
| 「我的解题对了吗/帮我核验」（讲题 Judge） | `geo_judge`（开放答案/解析/采分点，核验覆盖/错误/遗漏/干扰项解释） |
| 「把这题讲成讲题稿/怎么讲给学生」（讲题 Explainer） | `geo_explain`（消费已验证解题过程，产出「定位—审题—破题—反思迁移」四段式讲题稿+变式） |

### 3. 出题技能（专门命题流程）

对话中说「出几道题」「按广东卷风格出 3 道选择题」「出高一课堂练习」等，模型会加载 **geo-question-generator** 技能：

1. 现场扫描本地真题库 + 考点库（以磁盘现状为准，动态增长）；
2. 按「各省融合 / 广东卷独立」抽取风格档案（优先调用 `geo_style_profile`）；
3. 生成**原创、五段式**题目：题目 / 解析 / 答案 / 评分标准 / 考察知识点；
4. **双视图交付**：教师版（全量）+ 学生版（仅题目，无答案痕迹）。

## 二、常用话术示例

```
- 出 3 道选择题，考“农业区位因素”，高一难度
- 按广东卷风格出 1 道综合题，考区域发展
- 人口迁移这个考点近几年考得多吗？都有哪些题
- 帮我分析一下 2025 年福建卷 Q7-Q8 怎么考
- 把刚才的分析导出成 markdown
```

## 五、故障排查

- **工具没出现**：确认会话用的是「地理教师辅助」预设；确认 DSH 进程重启过（工具注册随进程代际生效）。
- **面板打不开/路由 404**：重启 DSH 后 geo 插件应自动挂载；若仍异常，检查 C: 运行时副本是否与 E: 权威源同步。
- **导出失败**：需重启使写盘沙箱策略生效（写入 `E:\geo_edu_agent\outputs`）。
