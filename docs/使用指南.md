# 地理教师辅助 Agent — 使用指南

> 对象：高中地理一线教师与地理师范生。
> 说明：本文介绍日常操作入口、三大核心场景的话术用法、数据配置与常见问题排查。各模块详细验证进度见 [验收待办](engineering/验收待办.md)。

---

## 一、两个使用入口

在 DSH Desktop 中新建会话并选择 **「地理教师辅助」** 预设后，可通过以下两种方式发起任务：

### 1. 输入区功能选择器（推荐新手）

在会话输入框工具栏点选功能模块与常用参数，系统会自动将当前选定参数实时同步给模型（保持输入框干净、不破坏拖入的 `@文件` 引用，模型也不会再重复追问已选定的授课时间或年级），直接在输入框输入题号或课题发送即可：

| 功能入口 | 可选参数 | 适用场景 |
| :--- | :--- | :--- |
| **讲题** | 讲解对象：学生（默认）／ 教师 ／ 命题人 | 解析本地真题库中的高考题，获取独立解题过程或不同视角的完整讲题稿 |
| **课程方案** | 年级：高一 ／ 高二 ／ 高三<br>时间：45 分钟 ／ 10 分钟 | 依据课标与教材原文备课，生成教学设计、学生学习材料与课堂观察记录三件套 |

> **说明**：模拟题润色与快测出题正在调整专用交互形态，输入区暂不展示旧版出题按钮，请直接通过下方自然语言对话调用。预设选择器底部的 `地理解题隔离会话（内部）` 仅供讲题时后台自动调用，**日常使用请勿手动选择**。

### 2. 自然语言直接对话

无需点选按钮，直接在对话框用自然语言描述需求，模型会自动按需调用对应的地理工具链与技能：

| 你想做什么 | 可以这样说 | 系统后台执行的流程 |
| :--- | :--- | :--- |
| **查考点与真题** | 「查一下『人口迁移』近几年有哪些高考题」 | `geo_taxonomy` 定位考点 → `geo_search_questions` 检索题库 |
| **分析考情与风格** | 「2025 年湖南卷 Q4 为什么这样考」「广东卷真题是什么风格」 | `geo_question_detail` + `geo_analyze`（可导出 Markdown）或 `geo_style_profile` |
| **只看某题怎么解** | 「2024 广东卷第 17 题怎么做？」 | `geo_solve`：启动隔离会话盲做（自动附带题面图片，屏蔽答案与解析图），只返回独立答案与关键依据 |
| **生成完整讲题稿** | 「把 2024 广东卷第 17 题讲给学生听」（或指明教师对象 / 命题人对象） | 连续执行 `geo_solve` → `geo_judge`（开放标准答案并逐小问归档对照结论）→ `geo_explain`（输出纯净讲题稿，不中途打断） |
| **强制重新独立解题** | 「这道题不要复用之前的记录，重新独立做一遍」 | `geo_solve` 传入 `fresh: true` 新建隔离子会话重做 |
| **设计课程方案** | 「备一节人教版选必二《资源枯竭型城市的转型发展》45 分钟新授课」 | 加载课程方案技能：先问案例方向 → 核对课标教材落盘 `依据-<课标编号>.md` → 选材 → 出 ≤5 行「构思卡」停等你确认 → 成稿并渲染 HTML 或 DOCX 三件套 |
| **单独做课标解读** | 「用课程方案功能，只帮我解读一下课标 2.5 条目」 | 读取课标解读规范并核验原文，面向同行成文后直接结束，不走完整备课流程 |
| **润色模拟题 / 出题** | 「参考山东卷风格润色这道模拟题」「针对热力环流概念混淆出 2 道选择题」 | 加载 `geo-question-generator`：转译学情认知障碍 → 给出 3 个构思供你确认 → 产出题包并用 `geo_question_validate` 做结构校验 |
| **检查运行状态** | 输入 `/geo-status` 命令，或直接说「查看状态」 | 回显当前 DSH 版本、考点库与真题库来源、题数及最近讲题记录 |

## 二、三大功能使用要点与边界

### 1. 讲题助手
- **三种讲解对象**：默认为**学生对象**（引导式推导，答案由推理自然引出）；需要课堂启发追问与支架设计时请明确说“**按教师对象讲**”（系统不会因为你是老师就自动切为教师对象）；需要剖析三层干扰机制与测量效度时说“**按命题人对象分析**”。同一题组核验完成后，切换对象无需重做题。
- **核验状态说明**：讲题经过 `题面就绪 → 作答已提交 → 核验完成` 三态，记录保存在产物目录的 `solve-runs.json` 中。「核验完成」代表“先盲做、后对答案”的程序顺序已严格执行，**不代替教师对学科内容的最终审核**。
- **上传图片题边界**：目前自动题答分离与隔离核验仅覆盖本地结构化真题库（Markdown 题组）；你在聊天框临时粘贴截图提问时，由主会话多模态直接解答，不走隔离核验流水线。

### 2. 课程方案生成
- **构思确认门**：系统在动笔写完整教案前，一定会先给你一张 ≤5 行的「构思卡」（教学核心、学生卡点、主线、主要取舍、已知风险）并停下来等你拍板。如果你希望跳过确认直接成稿，需明确说出“直接生成／不用确认”。
- **HTML 与 DOCX 并列成品**：
  - **HTML** 适合投屏、浏览器阅读分发与直接打印；**DOCX** 适合在 Word/WPS 中二次编辑或套用学校模板。
  - 两者地位并列，由你按需指定（未指定时默认输出 HTML；指定 DOCX 时会同步生成 HTML 孪生件便于核对）。
- **原文依据**：课标与教材原文优先读取你提供的本地资料或项目依据库，绝不凭模型记忆编造课标原句或教材图号。

### 3. 模拟题润色与快测出题（开发中）
- **定位聚焦**：推荐优先用于**现有模拟题的高考化打磨润色**以及**课后单考点快速检测题**；也可按参赛/教研要求产出完整的六大章节命题包（选择题组 `single_choice` 或综合题 `comprehensive`，一包只用一种题型）。
- **结构校验 vs 质量核验**：成稿后可在对话中调用 `geo_question_validate`（或命令行运行 `.agent-presets/geo-teacher/skills/geo-question-generator/scripts/check-package.mjs --task <taskId>`）检查分值三级求和、采分点引用及学生投影防答案泄漏。注意：**结构校验通过不等于试题质量过关**，答案唯一性与科学性仍需教师把关。

## 三、数据目录与自定义配置

默认使用预设包 `geospark-ai-preset` 内置考点库与独立真题数据包 `geospark-ai-data`（7 省 115 份高考真题与 120 张配图），**不改任何配置即可直接使用**。

如果你想接入自己整理的题库或修改导出目录，可编辑 `<DSH_HOME>/geo-teacher/config.json`（Windows 下通常为 `C:\Users\<用户名>\.dsh\geo-teacher\config.json`，仓库根目录提供了 `geo-teacher.config.example.json` 模板）：

| 字段 | 说明 | 默认位置 |
| :--- | :--- | :--- |
| `knowledgeBasePath` | 考点库 YAML 所在目录 | `geospark-ai-preset` 内置 `data/config/` |
| `questionBankPath` | 真题 Markdown 根目录 | `geospark-ai-data`（`obsidian_vault/04_题目/`） |
| `outputPath` | 分析报告、讲题运行记录导出目录 | `<DSH_HOME>/geo-teacher/outputs/` |
| `questionOutputRoot` | 出题任务包（`<taskId>/package.json`）存放根目录 | `<DSH_HOME>/geo-teacher/outputs/出题/` |

修改配置文件后重启会话，发送「查看状态」即可核对实际生效的路径（显示 `user` 表示已切换为你的自定义目录，显示 `packaged` 表示使用默认随附数据）。

## 四、常见问题排查

1. **安装或更新后看不到「地理教师辅助」预设，或新改动未生效？**
   请确认已**完全退出 DSH Desktop**（检查系统托盘角标，确保后台进程已关闭）再重新打开。
2. **提示「数据不可用」？**
   发送「查看状态」检查返回的路径是否存在；不要把路径配置错误误认为“题库里没有这道题”。
3. **讲题报错 `IMAGE_DELIVERY_INCOMPLETE` 或 `QUESTION_BOUNDARY_UNCERTAIN`？**
   前者表示该题引用的图片文件缺失或损坏，系统拒绝盲猜图意；后者表示该题 Markdown 缺少规范的 `**答案**：` 分隔行，请按提示检查对应题目文件。
4. **联网检索热点或论文时提示仅读到摘要？**
   受部分学术站点反爬与 PDF 二进制限制，模型只读到摘要时会如实标注 `abstract`，不会假装读过全文；你可以直接把论文段落或图表截图发进对话供系统使用。
