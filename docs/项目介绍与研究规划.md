# GeoSparkAI 项目介绍与研究规划

> 面向关注高中地理教学与教育数字化的同行、一线教师、教研员及合作方。本文尽量以平实语言介绍项目背景、研究思路、当前实现进展、局限性与后续路线，并严格区分「已实现」与「待验证／规划中」。

---

## 一、项目概览

**GeoSparkAI** 是一套面向高中地理教学场景的智能辅助系统。不同于“打开网页直接向通用人工智能提问”的用法，它在桌面对话环境中接入了**本地高考真题库、高中地理考点树、课程标准与教材原文**，让人工智能在有据可查、有流程约束的条件下协助教师开展讲题、备课与试题打磨。

| 核心方向 | 解决什么问题 | 当前阶段 |
| :--- | :--- | :--- |
| **高考讲题辅助** | 先让系统独立解透高考题，再按学生、教师或命题人视角输出规范讲题稿 | 核心流程已实现，进入一线真实题组复验与学科评审阶段 |
| **课程方案生成** | 依据课标与教材原文，协同产出教学设计、学生学习材料与课堂观察记录三件套 | 已落地并完成首轮去模板化优化，正在推进学科思想试点与细节打磨 |
| **模拟题润色与快测出题** | 核心用于润色日常练习的模拟题，使其逼近高考真题风格；延伸面向课后快速检测简题 | **开发中**：底层风格分析与结构校验工具已初步跑通，产品定位聚焦润色与轻量化训练 |
| **地理建模探索** | 探索利用人工智能辅助构建地理教学模型 | **方向待重构**：旧版本已不适合当今人工智能的发展速度与能力水平，方向需要重新思考 |

## 二、研究背景与一线需求

本项目的起点并非技术跟风，而是来自对一线高中地理教学现场的真实调研。当前，高中地理教师的专业成长高度依赖传统的**“老带新”模式**（如师徒结对、老教师手把手听评课与传授备课经验），不仅需要资深教师持续投入大量心血，整体成长路径也较为漫长，优质教研经验很难快速沉淀与规模化复用。

一线调研同时表明，地理教师日常最集中、最耗时的刚需主要落在两件事上：**讲透高考真题**，以及**编写高质量的教案与学案（课程方案）**。围绕这两项需求，不同发展阶段的教育者面临着各自突出的痛点：

- **新教师：成长周期长，缺少随时可得的教学支架**  
  初入职场的教师对高考真题的审题切入点、思维链条拆解以及规范教案的撰写往往不够熟练，单靠零散的“老带新”带教难以覆盖日常每一节课与每一道题，亟需专业、可参照的学科辅助支架来缩短成长周期。
- **资深教师（老教师）：事务与带教双重承压，亟需减负增效**  
  经验丰富的老教师既要兼顾学校行政事务、班主任工作与家庭重担，又常承担指导新教师的带教任务，日常备课与试卷讲评时间被严重挤压。他们需要可靠的智能工具接管资料查证、初稿整理与文档排版等繁琐工作，把精力留给高价值的课堂互动与教学指导。
- **地理师范生：急需高标准的实战训练抓手**  
  师范生正处于教学技能形成的关键期，需要通过高频练习讲解高考真题、撰写规范课程方案来打磨地理教学基本功与专业表达能力，但在入职前的训练中往往缺乏随时可得、有理有据的反馈对照。

从更长远的视角看，我国不同地区之间的优质师资、教研团队与高考研究资源仍存在明显落差，教育资源相对薄弱的地区往往连稳定的“老带新”条件都难以具备。本项目在研发辅助工具的同时，更致力于沉淀一套**可复制的地理智能教研与备课方法论**。我们计划在产品与方法论成熟后，面向教育资源相对薄弱的地区进行推广，借助人工智能赋能一线教师，尽可能补足区域间的教育资源差距。

## 三、核心研究思路

### 3.1 为什么通用人工智能直接进课堂还不够？

目前直接拿通用大模型生成教学内容，整体质量往往偏低。从技术根源来看，**通用模型在训练过程中，针对真实教育教学场景的专门打磨（专业上称为“后训练”，尤其是面向教学质量反馈的强化学习）明显不足**——模型虽然读过海量通识文本，但并没有围绕“一堂好课怎样组织、一道高考地理题怎样一步步教会学生”受过充分的专项训练。因此，通用大模型直接进入高中地理课堂常暴露出三个明显落差：

1. **凭记忆生成，依据不准**：容易出现课标条目背错、教材图号张冠李戴、考点归属模糊等问题，教师核查纠错的成本反而很高。
2. **讲题“看答案编理由”**：如果直接把题目和参考答案一起交给模型，它往往顺着答案倒推解释，跳过真实考场上如何读材料、如何排除干扰项的思考过程，学生听完依然不会自己做题。
3. **模板化严重，脱离真实学情**：直接生成的教案往往浮于表面、千篇一律，既难以适配不同课时与课型，又容易忽略具体班级的认知难点。

### 3.2 我们的破局原则

针对上述落差，项目确立了一条贯穿始终的设计分工：**把确定性的工作交给程序，把教学判断交给模型，把最终把关留给教师**。具体落为四条思路：

- **依据先行，查证落盘**：所有讲题、备课与试题分析均优先对接本地真题库、考点树、课标和教材原文，要求模型先核实依据、留存出处，再生成内容。
- **先独立作答，再对照核验**：在讲题环节用程序机制把题目与答案物理隔开，强制模型先“盲做”并存档，之后才开放标准答案逐项核对，从机制上杜绝“对着答案编解析”。
- **关键节点由教师拍板**：在编写课程方案等长任务中，系统先向教师提交简明「构思卡」，经教师确认方向与取舍后再动笔成稿，确保教学设计贴合本班实际。
- **顺应模型演进，少做僵化束缚**：人工智能基座能力正在快速提升。我们的思路不是用繁琐的死规则把模型“捆住”，而是持续做厚稳定的学科底座（数据、证据核验、流程门禁与学科思想），把灵活的表达与教学组织空间还给模型和教师。

## 四、当前项目实现情况

> 口径说明：项目目前处于持续开发与验证阶段，以下如实区分「已实现功能」与「尚待更多一线实测验证的环节」。

### 4.1 底座选型与本地学科数据

本项目基于 **DeepSeek Harness（DSH）** 桌面环境构建。选择 DSH 作为技术底座，主要出于三点考量：

- **开源可控**：底层架构透明开放，便于高校研究团队持续迭代、深度定制，不受封闭商业平台规则掣肘；
- **国产自主**：契合国内教育数字化自主可控导向，对中文语境及本土教学应用生态更为友好；
- **“一切皆插件”的理念契合个性化教学需求**：教学是高度个性化的工作，不同省份考情、不同学校学情、不同教师的备课习惯差异极大。DSH 将各类功能、技能与数据源都做成可插拔组件，使系统能够像“搭积木”一样按需组合、替换与扩展，而不是强迫所有教师迁就一套僵化的统一软件。

在交互上，教师在桌面对话框上方直接点选功能（讲题／出题／课程方案）与常用参数即可发起任务；支持一键安装，也允许教师替换为自己积累的本地题库与考点目录。随系统提供的基础学科底座包括：

- **高中地理考点树**：按「领域 → 主题 → 知识单元」三级组织，当前收录 4 个领域、26 个主题、132 个知识单元（共 162 个节点），用于考点检索与定位；明确声明为维护者个人整理的教学索引，不替代官方课标与教材，对标记「待复核」的节点在使用时会主动提示。
- **本地高考真题库**：按省份与年份整理，覆盖安徽、福建、广东、海南、湖南、山东、浙江 7 省的 115 份题组、279 道小问及 120 张配图。
- **课标与教材原文**：内置高中地理课程标准与人教版教材正文，作为备课核验与知识边界判定的共同依据。

### 4.2 高考讲题辅助（核心流程已成型，进入反馈迭代）

- **工作思路**：把“做对题”和“讲好题”明确拆开——先在隔离空间里还原真实考场上的独立解题过程，彻底杜绝模型偷看答案编理由；再对照标准答案定位思维偏差；最后针对不同听众重组表达，把解题思路讲透而不是照读解析。

围绕这一思路，系统实现了**独立解题 → 两阶段核验 → 教学化重组**的三段式流水线：

1. **隔离独立作答**：面对题库中的题组，系统启动独立答题空间——模型只看得到题干材料和题面图片，看不到参考答案与解析图，也不能调用外部工具翻查资料。作答结果由系统锁定存档，后续不得篡改。
2. **开放答案逐问核验**：只有当独立作答提交存档后，系统才开放标准答案与解析，逐小问对照哪些采分点命中、哪些遗漏、哪些推理存在偏差，并将核验结论归档。
3. **按讲解对象生成讲题稿**：系统仅依据归档后的核验记录，重组出不同视角的讲题稿：
   - **学生对象（默认）**：按「题目定位—审题—破题—反思与迁移」四段式展开，融入“设问先行”的审题与推理步骤，讲清每一步的材料证据、知识选择、因果链条与干扰项错因；
   - **教师对象**：补充教学重难点、典型学情误区与课堂讲评建议；
   - **命题人对象**：从素养立意（区域认知、综合思维、人地协调观、地理实践力）切入，逐层剖析设问、材料、选项三层干扰机制。
4. **同类题比较**：在独立作答之后，从本地真题库中按设问任务、推理关系和材料特征检索同类题进行对照，提炼方法的适用边界；候选不足时如实说明缺口，不凭空编造。

### 4.3 课程方案生成（教案与学案三件套，完成首轮去模板化治理）

- **工作思路**：**以地理学科思想作为底层方法论驱动**，同时复刻优秀地理教师真实备课的思考节律——先依据课标、教材与「教材思想解读」确立本课核心的学科认识方向（如地域思想、空间关系思想、尺度思想、系统思想、过程思想等，项目分析用语，不宣称全学科公认分类）并落盘留证，再围绕这一思想主线甄选真实情境材料、用极简构思与教师对齐教学取舍，最后统一成稿排版。由此让备课摆脱“套固定格式、堆零散要点”的惯性，真正由地理学科思想统领教学目标、学习活动与评价设计。

系统按五阶段运行：**核对课标与教材并生成「依据文件」 → 甄选主情境材料 → 出具不超过 5 行的「构思卡」停等教师确认 → 编写统一材料源 → 自查并导出成品**。一次确认后可同步产出三份配套文档——**教学设计、学生学习材料、课堂观察记录表**，支持网页（HTML）与 Word（DOCX）双格式输出。

近期完成了两项关键演进：

- **去模板化治理**：解除了 22 条过度死板的格式与课型限制，允许系统根据探究、讲授、讲练、复习等不同教学任务灵活组织课堂，只守住“依据准确、目标—活动—评价一致、课时可落地”的质量底线。
- **学科思想驱动落地试点**：已在人教版选择性必修 2《区域发展》上率先完成教材思想解读接入试点，为后续全套人教版教材的思想逆向拆解打样验证。

### 4.4 生题与模拟题润色（开发中，底层能力已初步跑通）

- **工作思路**：不盲目追求让大模型凭空编造高难度原创压轴题，而是先从本地真题库中提炼真实高考的语言风格、材料组织与设问规律作为标尺，用这套标尺去精细打磨日常模拟题；对课后检测则坚持轻量、聚焦单个核心考点的思路，并由程序完成结构检查与学生／教师视图分离。

**该功能目前仍在开发中**，已确立清晰且务实的产品定位：

- **最核心定位——润色日常模拟题，逼近高考真题**：学生在平时训练中接触大量模拟题，但不少模拟题存在表述口语化、材料冗余、设问模式不够严谨、与高考风格脱节等问题。本功能的核心价值在于**对现有模拟题进行精细化打磨与润色**，使其语言风格、情境组织、设问方式与评分规范尽可能向高考真题靠拢，让学生在日常刷题中就能获得高质量的模拟实战体验。
- **未来延伸目标——生成课后快速检测简题**：面向课堂收尾与当堂反馈场景，按核心考点快速生成轻量、聚焦的基础检测题，帮助教师及时了解学生当堂掌握情况。

目前，支撑这两类应用的底层工具已初步跑通，包括：从本地真题库自动抽取七维度省份「风格档案」、生成「命题蓝图」、支持材料型选择题组与材料型综合题的数据格式与自动结构校验器，以及自动分离「学生投影」与「教师投影」的视图机制；面向模拟题润色与课后快测的完整产品流程仍在持续开发中。

### 4.5 地理建模探索（方向需要重新思考）

- **工作思路与现状判断**：早期旧版本试图通过设定较严格的外部规则，约束大模型生成地理教学模型以防“跑偏”。但在实际推进中我们发现，**基础大模型自身的理解、推理与建模能力已大幅跃升，且迭代速度极快——旧版本这种依赖强约束的设计思路已经不再适合当今人工智能的发展水平**。

随着模型原生能力迅速覆盖以往需要外挂规则才能解决的问题，继续沿用旧方案已缺乏实际意义；而面对高速演进的模型能力边界，团队目前尚难以立即锚定一个长期稳固的形态。因此，地理建模的**整体方向需要重新思考**，当前保持审慎观察，待更清晰的教学需求与技术切口浮现后再重启规划。

## 五、当前局限性

客观审视现状，项目在走向大规模一线应用前仍存在四个主要局限：

1. **程序校验不能代替人工学科评审**  
   目前系统已具备较完善的流程门禁与结构检查，但**流程走完不等于学科内容百分百正确**（例如讲题的「核验完成」仅表示完成了先独立作答、再对照答案的流程，不担保答案零瑕疵）。讲题稿的多对象学科评审、模拟题润色效果评估以及多课型课程方案的真实课堂验证，仍需持续引入一线教师与专家把关。
2. **随堂碎片化输入场景尚未完全打通**  
   当前讲题深度依赖本地结构化真题库。而一线教师日常最常见的“学生拿着错题拍照提问”或“考完小测上传整份 Word／PDF 试卷，只想讲其中一两道难题”的场景，目前尚处于方案设计阶段，还未落地运行。
3. **图表与地理专业配图能力仍有短板**  
   地理学科高度依赖地图与统计图表。目前课程方案中部分数据图表的呈现精度仍存在瑕疵，模拟题润色与出题所需的专业地理制图能力也尚未形成闭环。
4. **环境依赖与一线使用门槛偏高**  
   系统目前主要在 Windows 桌面特定运行环境下验证，安装、配置与版本更新仍需一定电脑操作基础。要真正服务好广大的普通一线教师（尤其是软硬件条件有限地区的教师），还需进一步简化交付形态。

## 六、未来发展路线图

基于上述局限与长期愿景，项目规划分三个阶段稳步推进：

| 阶段 | 核心目标 | 关键举措 |

> **为什么「定义标准与基准测试集」尤为关键？**  
> 当前各类教育人工智能产品层出不穷，但行业内普遍缺少一套地理学科专业认可的“考卷与评分尺子”，导致产品好坏难以客观衡量。谁先牵头建立科学、公开的教学设计评价标准与基准测试集（Benchmark），供学界研究与其他地理教育产品对标评测，谁就掌握了这一新兴领域的学术话语权与公信力。这不仅能反向驱动自身系统迭代，更对提升学院在“人工智能＋地理教育”方向的学术声誉与行业影响力具有关键意义。
