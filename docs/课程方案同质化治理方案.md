# 课程方案同质化治理方案

状态：方案阶段，未实施。本文规定现有教学方案 skill 的调整方向，不修改技能正文、渲染契约、样例或工作台界面。

## 1. 核心问题与目标

如何调整现有教学方案 skill，使模型在课标、学情与教学质量要求下自主构思教学设计，并尊重教师自行配置的语言风格。

治理目标是减少没有教学必要性的强制设计路径，让模型能够根据具体任务作出设计判断。同质化改善是观察结果，不以目录不同、环节数量不同、句式不同或相似度下降作为成功的必要条件。形式一致的两份教学设计可以都适切；形式不同也不代表教学设计有效。

本方案只围绕现有教学方案 skill 展开，不新建方法 skill 体系，不要求教师编排教学方法，也不新增自动安装或搜索网络 skill 的流程。

## 2. 现象与证据边界

原有观察涉及 `outputs/教学设计/` 下的《中国的耕地资源与粮食安全·置换版》与《海气相互作用教学设计》。两份产物均采用相近的板块顺序、五个教学环节、同一组环节标签，以及相似的课标解读句式；活动推进也呈现读材料、建构解释、检验等相近组织方式。

这些观察提示现有技能可能过度规定了设计路径或表达方式，但两份样本不足以确定原因。文档格式要求、任务内容、模型偏好与会话上下文都可能影响结果。实施前应重新核对产物和当前规则，不能把原有观察当作已完成的因果验证。

重点检查以下文件。路径用于定位审查范围，不表示其中每项规则都应删除：

- [lesson-format.md](../.agent-presets/geo-teacher/skills/cn-high-school-geography-lesson-planning/references/lesson-format.md)：内容要求、文档组织与渲染约束。

## 3. 课标、教材与设计空间

课标规定需要实现的学习要求。教学设计应将这些要求落实为适合本课内容和学生情况的教学目标，并安排相应的学习活动与评价证据。

教材既提供教学内容，也通过内容顺序、案例、活动与问题体现设计意图。教材可以提供设计参考，但不能直接代替面向具体班级的完整教学设计。模型应准确理解教材内容及其边界，不必机械复刻教材的活动安排。

在这些条件下，模型可以自主组织问题、选择材料、安排活动、组合或改造已有方法，也可以提出参考资源之外的设计。自主构思不要求刻意创新；适合本课的常见方法可以直接使用。设计成立的依据是目标、内容、学情与实施条件，而不是是否命中某个方法编号。

## 4. 职责与约束边界

| 承担方 | 职责 | 边界 |
| :-- | :-- | :-- |
| 现有教学方案 skill | 规定必要工作流程、教学质量要求与可用交付条件 | 不替所有课预先决定认知脚本，不替所有教师规定表达偏好 |
| 模型 | 结合任务自主构思，形成可实施的设计，并说明关键理由与取舍 | 不得以自由发挥为由虚构依据、忽略学情或取消目标与评价的对应关系 |
| 团队的方法提取工作 | 提供可理解、可借鉴的设计方法与案例资源 | 不预设为独立方法 skill；不构成封闭菜单或必经步骤 |
| 教师个人知识中的语言风格 skill | 承载教师自行配置的表达偏好 | 不改变事实、课标要求与必要教学信息 |

教师可以自行选用网络上的语言风格 skill 并配置在个人知识中。本方案不负责替教师搜索、安装或维护这些 skill。实施时需验证已配置风格能否被当前运行链路读取和应用，不能在尚未验证时宣称已经支持。

## 5. 规则调整原则

逐条审查规则：它是在保障教学设计成立，还是在预先决定必须怎样设计、怎样表达？每条规则应明确保留、限定适用条件、降为参考或删除的理由。

### 5.1 保留质量与交付要求

以下责任不得因放宽设计空间而消失：

- 课标与教材依据核验，准确理解内容范围。
- 教学目标、学习活动与评价证据对应。
- 根据已知学情设计；缺少信息时明确假设，不虚构学生表现。
- 活动在课时、资源与课堂条件下可实施。
- 来源可靠、材料使用合规、地图与学科术语准确。
- 交付前自查，以及现有三件套、数据格式和渲染契约。

这些责任可以整合到不同呈现位置，不要求每项都成为独立章节。调整板块前必须确认必要信息仍可找到、渲染仍可用。

### 5.2 放开教学设计路径

不强制所有课采用探究式组织、认知冲突、固定问题链、固定环节节律或中间成果复用。此类要求应根据具体设计的需要适用；例如，设计确实依赖前一活动的成果时，才检查后续活动是否正确使用它。

保留教学核心、学习障碍、目标达成证据等共通设计责任，但不把它们固化为唯一提问顺序或统一成文句式。共通问题本身不是同质化的充分原因。

现有认知视角、灵感机制和方法示例可作为参考。模型可以不采用，也可以组合、改造或提出其他做法，不必先选分类再生成教学设计。不得用另一组强制五问替代原有菜单。

构思简报向教师说明本课的重要设计选择及其依据，保留必要的教师确认流程；不要求提交完整内部思考过程，不强制列出多个备选方案或逐条声明与历史课程的差异。

### 5.3 将表达偏好交给教师配置

教学方案 skill 保留表达准确、清楚、必要信息完整的要求。篇幅、语气、表格或叙述、段首标签等表达偏好由教师个人知识中配置的语言风格 skill 承载，并结合本次明确要求执行。

默认表达应可读、可用，但不是所有教师必须遵守的风格。既不统一强制使用标签句式，也不统一禁止标签句式；不以减少表格或 labeled 块作为治理目标。

风格调整不得删去教学目标、评价依据、必要来源等内容。教师未配置风格时，仍应正常完成教学方案，不把配置个人 skill 设为前置条件。多个风格要求确有冲突且无法结合任务判断时，只澄清影响交付的部分。

## 6. 方法提取成果的承接

方法提取由团队其他成员负责，本方案不重复开展提取，也不提前规定其存储格式或独立技能结构。现有教学方案 skill 的约束调整无需等待方法资源完备。

后续接入时，应确认参考内容能帮助模型理解：在什么目标和条件下采用某个设计动作，为什么有效，学生应表现出什么，以及条件变化时如何调整。具体字段与组织方式待提取成果形成后再确定。

参考资源应扩大模型的选择空间。不得要求每课引用其中一种方法、标注方法编号、照搬完整案例或按固定流程执行。来源案例支持的是借鉴依据，不能直接证明新设计对当前学生有效。

## 7. 实施安排

### 第一阶段：核对并调整现有规则

核对第 2 节文件及其相关引用，形成简明的规则调整清单，记录原规则、承担的质量责任、拟调整方式和仍需保留的条件。

优先解除无条件适用的设计脚本和表达限制，同时保留质量责任及交付契约。同步修订正文、参考文件与检查清单，避免正文允许自主设计、检查清单仍要求固定套路。

这一阶段不新增跨课记忆、不修改工作台参数、不扩建骨架样例库。渲染样例继续承担格式示范作用，不作为内容范本。若具体改动涉及契约，先核对消费者与验证范围，再决定是否另行实施。

### 第二阶段：验证自主构思与风格配置

用不同教学目标和学情的任务检查设计是否随需要调整；对同一课题改变课时或资源条件，检查模型是否作出相应取舍。任务应包含现有默认路径不适用的情况，避免只验证一种课堂组织方式。

分别验证无个人风格配置和已配置不同风格的情况。检查表达是否响应配置、必要信息是否完整，并确认变化实际进入交付产物。

测试中重复使用适切方法是允许的，不要求每次产生不同结构。无法适配时应定位具体限制规则或参考资源缺口，不直接增加强制差异要求。

### 第三阶段：按成熟度接入方法参考资源

待团队成果具备可用内容后，再确定读取方式与引用范围。验证资源能否支持条件判断和迁移，而不是诱导照抄案例。接入效果单独评估，不将其作为前两阶段完成的前置条件。

## 8. 验收与观察

| 维度 | 验收重点 |
| :-- | :-- |
| 教学依据 | 课标要求得到准确落实，教材内容与使用边界清楚 |
| 教学质量 | 目标、活动和评价相互对应，方案符合已知学情与实施条件 |
| 自主构思 | 不适合默认路径的任务能形成合理设计，不被迫使用固定冲突、问题链或成果形式 |
| 必要共性 | 保留统一格式或复用方法时，不因此被判失败 |
| 个性化表达 | 已配置风格得到应用，无配置也能正常交付，必要信息不因风格变化丢失 |
| 工程可用性 | 现有交付与渲染契约不受破坏，适用静态检查与运行验证通过 |

实施技能改动时按 geo-dev-checklist 执行适用检查，包括 `npm run verify:geo`、技能 frontmatter 检查及实际桌面会话验证。静态检查只能验证其覆盖范围，不能证明教学有效性。教师反馈应重点询问设计是否符合教学需要、表达是否符合个人使用习惯，不只询问两份方案是否相似。

结构审计仅作为后置、非阻塞的辅助工具，不是首批前置条件。若后续建设，应分开报告文档结构、语言重复与活动组织，避免用单一分数代替教学判断。Jaccard 只能反映集合重合，不能解释板块顺序；素材或成果无法可靠识别时应标注未知，不能仅由渲染块类型推断。现有两份样本可作描述性基线，不用于确定合格阈值或预设脚本必须得出的结论。

## 9. 不采用的治理措施

- 强制与最近若干课保持两个以上差异维度。
- 禁止连续使用同种导入、成果形态或设计方法。
- 设置机制冷却期、素材模态配额或课型配额。
- 用固定三种骨架替代原有单一骨架，并要求每课归类。
- 以板块变化、句式变化或结构相似度下降作为交付门槛。
- 将教学方法编排转交教师，或假定已有独立方法 skill。
- 在教学方案 skill 中统一规定教师个人语言风格。

这些措施没有直接回答设计是否适合当前教学任务，还可能让模型为了差异牺牲适切性。

- 当前规则的具体内容及其对真实产物的影响，需实施时核对，不能仅据旧行号推断。
- 教师个人知识中的语言风格 skill 的发现、加载与应用方式，需要运行验证；若链路不支持，另行明确接入工作，不把它伪装成文本规则即可解决的问题。
- 团队方法提取成果的内容、组织形式和可用时间尚待确定，不预设交付接口。
