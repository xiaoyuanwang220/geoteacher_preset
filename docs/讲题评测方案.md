# 讲题功能 · 真题评测方案（P4）

> 版本：v2.0　日期：2026-09-28　状态：评测脚手架（样本清单 + 五项指标打分表 + 三对象内容评审），待教师人工评测。2026-11-06 起独立性改按隔离会话输出评价，并新增答案提前访问、题答图片分离、作答绑定三项否决检查（**源码已实现，待完整重启 DSH 后运行时验收**）。
> 配套：`讲题功能设计.md`（总设计，§八、§十、§十一）、`geo-solver.md`、`geo-question-explainer.md`、`.agent-presets\geo-teacher\skills\references\explainer-audiences.md`。

P4 是**教师人工评测门**：从本地真题库抽样 20–30 道，对「隔离解题会话 → 两阶段核验 → 讲稿」流水线做五项指标打分与三项行为检查。**达标才进入 P5（插件整合）**，否则回炉 P1–P3。

## 一、评测指标（五项）

| # | 指标 | 说明 | 计分 |
| :-- | :-- | :-- | :-- |
| 1 | **答案正确率** | 选择题判对错；综合题要点与标准答案匹配度 | 对=1，错=0（综合按要点覆盖率折算 0–1） |
| 2 | **证据准确性** | 解题依据的材料线索是否真实、有无编造 | 每处按 0/0.5/1 |
| 3 | **推理链完整性** | 每步推导是否有关联依据、有无跳跃 | 0–1（缺一步扣） |
| 4 | **采分点覆盖率** | 综合题要点覆盖标准采分点比例 | 0–1（覆盖点数/总采分点） |
| 5 | **干扰项解释质量** | 选择题每个干扰项错因是否讲清 | 每项 0/0.5/1，取平均 |

**通过门槛（建议）**：五项平均 ≥ 0.8 且答案正确率 ≥ 0.85；未达标则回炉 P1–P3（solver 方法论/骨架规则），再抽样复测。

**口径变化（2026-11-06）**：五项指标的评分对象统一为**隔离解题会话的「独立作答」**（`geo_solve` 返回的答案与关键依据），不评主会话自述；核验结论（`geo_judge` 归档）与讲稿只用于判断"是否对照、是否只读 verified"，不参与五项打分。其中干扰项解释质量按独立作答中对选项的判断依据与排除理由计分（选择题）；独立作答未逐项解释时按 0 计，不用讲稿内容补足。计数与时间戳以服务端 run 记录为准（`submittedAt`、`judgedAt`、`verifiedAt`）。

### 1.1 独立性指标（衡量"不依赖答案"）

独立性定义为：独立作答由**隔离解题会话**在答案开放前产出，且解题输入与模型上下文都不含答案信息。服务端门禁（作答提交后才开放答案）已把"先看答案解析后补答案"的路径堵住，评测仍须逐题核对：

- **通过标准**：每题先记录 `geo_solve` 返回的独立作答（答案 + 关键依据）与 run 记录，再开放 `geo_judge`；独立作答正确率与干扰项解释质量**单独计分**，作为回炉决策的否决项（不进五项平均也可）。
- **污染检测**：若独立作答出现与标准解析高度雷同的措辞/顺序，同时核对题面是否含解析图、答案痕迹或知识点提示；命中则标记"疑似答案污染"，该题独立性记 0，并按 §1.2 的题答图片分离检查复核。
- **可复核证据**：runId、`submittedAt < judgedAt`、子会话输入只含题面（解题 prompt 不含 answer/analysis/知识点）、隔离能力错误码（如 `SOLVER_ISOLATION_UNAVAILABLE`、`SOLVER_RUN_FAILED`）。

### 1.2 新增行为检查（2026-11-06，三项否决项）

三项检查逐题执行，任一不通过即该题判不合格（讲题稿不计入合格）；三项**不进五项平均**，只作否决项。打分记录写入 §三 打分表对应栏。

| 检查项 | 检查方法 | 打分记录方式 |
| :-- | :-- | :-- |
| **答案提前访问检查** | ① 核对 run 记录：`submittedAt` 早于 `judgedAt`（答案开放时间）；② 在作答提交前尝试取答案，应返回 `SOLVE_NOT_SUBMITTED`；③ 检查隔离子会话 prompt 与输出中是否出现答案/解析原文 | 通过=1／不通过=0；记 runId、两个时间戳、错误码；出现答案痕迹须写明命中片段 |
| **题答图片分离检查** | 对照题库 MD：`## 相关图片` 与 `**答案**` 之前的正文图片为题面图片，`**答案**`/`**解析**`/`## 教学备注` 之后的图片为解析图；核对 `geo_solve` 交付的附件数量/顺序与题面图片一致、解析图未交付；交付状态为 `partial`/`degraded` 即不通过 | 通过=1／不通过=0；记交付状态（`none`/`complete`/`partial`/`degraded`）、题面图片张数、解析图张数与是否零交付、错误码 `IMAGE_DELIVERY_INCOMPLETE` |
| **作答绑定检查** | ① 独立作答原文与讲稿引用一致（讲稿未改写作答）；② 题面变化后旧 run 失效（`QUESTION_VERSION_CHANGED`），须重新解题；③ 未 `verified` 时 `geo_explain` 返回 `EXPLAIN_NOT_VERIFIED`；④ 独立作答由插件 `recordIndependentAnswer` 保存，非模型参数传入；⑤ **题组按小问归档**：核对每个小问的 `conclusions[qid]` 是否各自存在且被讲稿正确引用（不得出现"第 1 问显示第 3 问结论"），部分小问未归档时 `geo_explain` 应拒绝并列出未归档 qid | 通过=1／不通过=0；记 runId、题面指纹是否变化、错误码、各小问 verdict 与讲稿引用对照结论；题组结论互相覆盖即不通过 |

## 四、评测流程建议

1. 对每题：`geo_solve` 在**隔离解题会话**中独立作答（**不得先看答案**），记录 runId、独立作答原文与 `solveStatus`；
2. 记录独立作答后，`geo_judge(qid)` 开放答案；先做答案提前访问检查（提交前取答案应被拒）与题答图片分离检查；
3. `geo_judge(qid, conclusion)` 归档对照结论，核对 `state:'verified'` 并完成作答绑定检查；用独立作答填写 §三 指标 1–5；
4. 用 `geo_explain` 生成讲题稿：学生对象（缺省）+ `audience: "teacher"` + `audience: "setter"` 各一次，检查四段式/命题分析结构、教学化重组与"讲稿只读 verified"；
5. 按 §八 做三对象内容评审与去标题辨识；
6. 逐题打分 → 汇总 20–30 题 → 算五项平均，并统计三项否决检查；
7. 达标 → 进入 P5 插件整合；未达标 → 回炉 P1–P3 后重抽复测。

## 五、通过标准（汇总）

- 抽样 ≥ 20 道，题型（选择/综合）× 难度（含基础/中档/压轴）× 省份均覆盖；
- 五项指标平均值 ≥ 0.80；
- 答案正确率 ≥ 0.85；
- 全部题目的学生/教师对象讲题稿为四段式且教学化重组；命题人对象按 §八 的独立结构交付；
- **答案提前访问、题答图片分离、作答绑定三项检查全部通过**；任一题不通过则该题判不合格（三项否决检查不进五项平均）；
- 结构检查通过、内容质量通过、桌面验证通过**分别记录**；未做人工学科评审时明确标注，不能输出"全部验收通过"。

## 六、过程性元话语与作者痕迹检测

讲题稿中以下内容需删除（一旦出现，第五项"讲题稿教学化重组"判定不合格）：

- **模型自述**："我这样想""我推测""我认为应该选 B"
- **版本痕迹**："v2.0 修订""之前改为""现在改为"
- **评审痕迹**："reviewer 指出""评审建议"
- **对解析的机械复述**：照抄真题解析原文

**必须保留**（可教学推理，是讲题稿核心价值）：审题（设问拆解）、证据（材料引用）、原理（知识选择依据）、因果链（推理步骤）、干扰项排除（为什么不是另一个答案）。

## 七、proposition-preservation 边界

命题完整性自检（五段式完整、答案-解析一致、干扰项错因明确等）用于确认编辑过程中**未遗漏关键命题**，适用于"改写/压缩讲题稿"场景。它**不能证明**：
- 答案是否正确；
- 答案与解析是否一致；
- 地理事实是否准确。

以上三项需**领域 Rubric**（学科标准）人工验证。评测时二者分开：形式完整性用 proposition-preservation 检查，正确性用五项指标中的"答案正确率"和"证据准确性"。

## 八、三对象内容评审

### 8.1 选题覆盖

首轮选**至少四题**：自然地理选择题、人文地理综合题、一题具有有效跨学科联系、一题不宜强行跨学科。允许前两项与后两项重叠，但应覆盖两种题型、涉图与非涉图。**各题生成三对象版本**；取样一律经题库工具（`geo_solve` 在隔离会话内取题面，或 `geo_question_detail`），**不直接读含答案的题库文件**。

### 8.2 逐项评审与证据

每项按"缺失／部分达到／达到"记录**证据**，不以章节出现就判合格：

- 知识应用解释；
- 问题驱动推理（讲解由地理问题、材料证据与学科原理推动，非对照答案补理由）；
- 方法边界（可迁移思路 + 适用边界，非固定因素清单）;
- 跨学科有效性（状态与依据；不适用时是否简短说明）；
- 对象侧重点；
- 事实与核验一致性。

### 8.3 硬性不通过

出现任一项即判不通过：科学错误；答案泄露后冒称独立求解；伪造命题意图或试测数据；强行跨学科；**教师对象仅改称呼或加长学生对象**；方法退化为固定因素清单。

### 8.4 差异化专门检查（去标题辨识）

去掉标题后仍能判断服务对象：

- **学生对象**须有可执行的思考步骤；
- **教师对象**须有针对本题的思维目标、学生思维动作、递进追问、支架撤除、总结引导和独立迁移检测，不能只是教师解释答案的顺序；至少展示一条"学生自主提出解释 → 证据检验 → 独立迁移"的具体引导路径并标明思维培养目的，**不把诱导学生猜标准答案视为思维启发**；
- **命题人对象**须评价设计是否奏效，并逐层检查设问、材料、选项中的干扰，说明位置、错误路径与辨别依据，不只复述说明。

### 8.5 命题人对象专项样例要求

样例覆盖：设问边界易误读；材料中的显著非主导因素；选择题的有效干扰项；综合题无选项的情况。各层可标为**未发现／不适用**，不能机械凑齐三层。

### 8.6 负例检查

- 不能把必要限定、必要背景或题组其他小问所需信息一律当成干扰；
- 不能把未经验证的学生错误路径写成实际学情；
- 不能因无试测数据而输出正确率、区分度或实际测量效果断言。

### 8.7 保留现有框架的验收

- 学生对象与教师对象均能辨认出「题目定位—审题—破题—反思与迁移」四个主要环节，四维内容融入其中，未替换为新结构；
- 学生对象保留问题起点、读图取证、知识选择依据、推理与关键辨析、方法收束；教师对象在相同环节中突出思维启发、重难点突破、引导总结与迁移检测；
