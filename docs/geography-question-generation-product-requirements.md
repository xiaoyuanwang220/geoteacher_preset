# 高中地理出题功能产品需求文档

> 状态：需求基线草案  
> 更新日期：2026-09-23  
> 当前范围：材料型单项选择题组  
> 核心场景：师范生参加试题命制比赛  
> 次级场景：教师针对学生薄弱点开展专项训练

## 1. 产品定位

本产品不是通用的“输入知识点后自动写题”工具，而是一个面向高中地理的研究型命题助手。它以教师提供的学情为起点，以课程标准、当前知识图谱、真实热点、权威数据和地理专业研究为证据，先提出可比较的命题构思，再生成可参赛、可解释、可复核的原创材料型选择题组。

产品遵循同一套试题质量标准。命题比赛作品与高考风格试题的设计取向本质一致，区别在于参赛作品需要额外提供完整的设计说明、证据链和模拟作答分析。因此：

- 试题本体必须保持答案唯一、材料有效、设问严谨、难度合理和学生认知适配；
- 热点、论文和创新必须服务于考查目标，不能成为题面装饰；
- “像某省试卷”不是创新点；省份风格只是命题技法参考；
- 参赛模式是在合格试题之上增加设计说明，不另造一套“比赛题风格”。

## 2. 目标用户与核心任务

### 2.1 核心用户：参加命题比赛的师范生

核心任务是把一个知识点和模糊学情，转化为具有时代性、学术性、教学适切性和明确测量目标的原创题组，并能向评委说明为什么这样设计。

典型输入：

> 给高一学生出一道关于热力环流的材料型选择题，难度中等，学生对热力环流的概念不理解。

### 2.2 次级用户：开展专项训练的高中地理教师

核心任务是围绕学生的薄弱点生成一个可诊断、可讲评、可用于后续干预的题组。专项训练模式与参赛模式共用命题核心，只减少参赛设计说明的篇幅。

## 3. V1 范围

### 3.1 包含

- 默认生成一则共用材料和 2—3 道单项选择题；
- 教师可要求专项训练模式只生成 1 道材料型单项选择题；
- 教师提供学情，允许模糊描述；
- 系统把模糊学情转译成待验证的认知障碍；
- 命题前提出 3 个可比较的命题构思；
- 结合当前知识图谱、课标、热点、权威数据和专业论文；
- 输出 Markdown 初稿；
- 默认模拟 3 名不同认知水平的典型学生，每级 1 名；
- 先提出图表或图片方案，经教师确认后再制作；
- 支持参赛模式和专项训练模式。

### 3.2 暂不包含

- 综合题；
- 整卷、自动组卷和分值结构设计；
- 未经教师确认直接生成正式图表；
- 无真实试测数据时生成正确率、难度系数、区分度或选项分布；
- 自动修改知识图谱 taxonomy；
- 为不同出版社教材建立独立知识体系；
- 把论文或真题原文改写后冒充原创题。

综合题作为 V2 方向，在 V1 材料型选择题组稳定后开展。

## 4. 核心设计原则

### 4.1 先构思，后成题

默认采用二阶段交互。系统不得在收到一句模糊指令后直接跳到完整参赛作品。

第一阶段提供 3 个命题构思，供教师选择、组合或修改；第二阶段才生成完整 Markdown 题组和设计说明。

### 4.2 学情由教师提供，系统负责专业化转译

教师必须主动描述学情，但不要求使用诊断术语。系统把“概念不理解”“容易混淆”“不会读图”等模糊描述转译成 2—3 个待验证的认知障碍，并明确这些是命题假设，不是真实诊断结论。

例如，“学生对热力环流概念不理解”可以转译为：

- 可能无法建立冷热差异、垂直运动、气压差异和水平气流之间的因果关系；
- 可能混淆近地面和高空的气压关系；
- 可能能够背诵概念，但不能迁移到城市风、海陆风或山谷风等情境。

教师在第一阶段选择或修正重点障碍，后续题干、设问和干扰项必须与其对应。

### 4.3 考查知识以当前知识图谱为准

知识点真源为 `E:\知识图谱\config\` 中当前有效的 taxonomy。每次命题读取最新版，不把 taxonomy 复制或固化进出题 Skill。

- 使用知识点稳定 ID、名称、定义、包含项和排除项；
- 每道小题分别标注核心考点、支撑知识和材料线索；
- 记录实际使用的 taxonomy 版本；
- 不指定教材出版社版本；
- 课标与教材原文用于核验知识边界和表述依据；
- 不修改知识图谱项目中的 taxonomy、题目页、映射结果或教师备注。

异常处理：

- 指定知识点未收录：第一阶段标明“知识图谱未收录”，由教师决定更换考点或按待确认考点继续；
- 节点标记 `needs_review`：可以提出构思，但不得无提示地生成最终参赛作品；
- 存在多个近似节点：展示候选节点及差异，由教师选择，不自动替换；
- 未获教师确认时，不新建知识点 ID，不擅自补入 taxonomy。

### 4.4 课标、教材、知识图谱和论文分工明确

| 依据 | 主要作用 |
| --- | --- |
| 课程标准 | 确定考查目标、行为要求、核心素养和总体边界 |
| 当前知识图谱 | 统一知识点名称、定义、关系、包含项、排除项和真题映射 |
| 高中地理教材共同知识 | 证明作为答案必要前提的知识确实属于学生学习范围 |
| 地理专业论文 | 保证情境、机制、数据和图示具有专业性与新颖性 |
| 权威现实材料 | 提供当下真实的问题、数据、政策和区域背景 |

所有作为得出正确答案必要前提的知识，都必须能在高中地理教材共同知识中找到依据。允许“情境超纲”，不允许“必备知识暗中超纲”：

- 论文或热点可以提供新的情境、术语、数据和研究发现；
- 材料外术语如影响作答，必须在题面中解释；
- 学生可以运用教材知识推导教材未直接给出的结论；
- 不要求学生预先掌握大学地理知识；
- 不用论文结论替代学生应完成的推理。

### 4.5 热点必须与考点发生真实关系

- 新闻事件优先使用命题时点之前 12 个月内的材料；
- 国家战略不受一年限制，但必须说明最新进展以及当前命题价值；
- 热点包括国家战略、教育热点、社会新闻、区域发展与地理环境议题；
- 每项热点标明来源、发布日期、事件发生时间和采用理由；
- 删除热点后题目若仍可原样成立，说明热点很可能只是装饰，应重新设计或更换情境。

### 4.6 学术研究必须经过高中教学化转化

论文使用链为：

> 研究问题或发现 → 提取地理机制 → 判断与考点关系 → 降低专业表达难度 → 转化为高中生可处理的材料 → 设计设问

必须记录论文出处和实际读取范围。只读取摘要时不得声称已核对全文。不得照搬论文题图、结论段或专业模型作为题目。

### 4.7 省份风格与比赛要求分层

WorkBuddy 后续形成的代表省份风格档案是外部输入。出题功能读取风格档案，选择适合本题的材料长度、题组递进、设问方式和干扰项技法；必要时抽查对应真题。

风格档案不替代比赛评价要求，也不要求每题模仿某一省份。用户明确指定省份风格时再进入区域风格模式；未指定时以成熟高考题的一般质量规范为准。

## 5. 输入要求

### 5.1 最小必要输入

- 学段或年级；
- 主题或知识点；
- 学生薄弱表现，可模糊描述。

### 5.2 可选输入

- 目标难度；
- 参赛模式或专项训练模式；
- 指定省份风格；
- 指定国家战略、新闻事件或区域；
- 指定论文、数据或素材；
- 比赛评分表、格式模板或字数要求；
- 已教范围；
- 希望重点考查的核心素养或“四翼”要求。

系统不询问教材出版社版本。缺少可选参数时采用合理默认，并在第一阶段明示关键假设。

## 6. 交互流程

### 6.1 阶段 0：输入归一与依据检查

系统完成：

1. 解析年级、知识点、学情、难度和用途；
2. 从当前 taxonomy 定位知识节点并记录版本；
3. 把模糊学情转译为待验证的认知障碍；
4. 判断是否缺少会改变考点或命题方向的信息；
5. 检查课标、知识图谱、热点检索和论文检索是否可用。

只有会实质改变结果的缺口才向教师提问，不要求教师填写长表单。

### 6.2 阶段 1：三个命题构思

每个构思至少包含：

- 构思名称；
- 核心考点与 taxonomy ID；
- 对应课标要求与核心素养；
- 针对的认知障碍；
- 热点、国家战略或现实问题；
- 可参考的论文或专业研究；
- 情境和材料设想；
- 2—3 道小题的认知递进；
- 预期“四翼”结构；
- 拟用图表或图片及其必要性；
- 创新点；
- 预计难度及主要风险；
- 证据卡：来源、日期、可用范围和可信度。

三个构思应存在实质差异，例如使用不同现实问题、不同材料证据或不同认知路径；不得只是标题和措辞变化。

教师可以选择一个构思、组合多个构思、修改局部方向或要求重新提出构思。

### 6.3 阶段 2：Markdown 命题初稿

教师确认构思后，系统生成 Markdown 初稿，包括：

1. 题组材料；
2. 拟用图表占位及图表设计说明；
3. 2—3 道单项选择题；
4. 答案；
5. 逐题解析与选项分析；
6. 命题设计说明；
7. 课标、知识图谱与教材共同知识依据；
8. 核心素养与“四翼”分析；
9. 难度分析；
10. 3 名典型学生的模拟作答；
11. 热点、数据、论文与图片来源；
12. 风险与待确认事项。

### 6.4 图表设计检查点

Markdown 初稿阶段不直接制作正式图表。每个拟用图表先说明：

- 图表名称与类型；
- 将包含什么数据、变量、单位或图像信息；
- 图表在题组中的作用；
- 为什么必须使用该图，而不能只用文字；
- 对应哪些小题和认知活动；
- 数据或原图的拟用来源；
- 后续制作方式；
- 科学性、版权、地图合规和认知负荷风险。

教师确认图表必要且方向正确后，才进入数据获取、清洗、制图和嵌入环节。

### 6.5 正式图表与作品包（后续交付能力）

正式图表完成后，更新 Markdown 并可按需导出 Word、PDF及附件包。第一版产品基线以 Markdown 为主，Word/PDF 不作为首轮必交付物。

## 7. 图表、示意图与地图要求

### 7.1 数据图表

- 使用政府部门、国际组织、科研机构或论文原始数据；
- 记录机构、数据集、年份、单位、访问日期和链接；
- 使用 Python 等工具重新绘制，不直接截取媒体图表；
- 保留原始数据或可追溯下载来源、清洗数据和绘图脚本；
- 满足打印、缩放、色觉可辨和考试阅读要求；
- 删除与考点无关的科研变量，不因追求复杂而增加认知负荷。

### 7.2 原理与过程示意图

“复刻论文图”指理解后的教学化改绘，不是截图或照抄：

- 保留与考点有关的变量、过程和因果结构；
- 删除超出高中认知范围且不影响科学性的细节；
- 不改变原研究结论；
- 图注注明“据××研究改绘”；
- 完成科学性和高中认知适配检查；
- 无法确认图意或版权状态时不直接使用。

### 7.3 地图与行政区划

- 使用官方地图或官方行政区划数据；
- 记录来源、审图号、下载时间和适用范围；
- 不使用 AI 生成的行政区划轮廓；
- 不擅自变形、裁切或遗漏必要疆界要素；
- 在合规底图上叠加题目信息时保留底图合规信息；
- 无法取得合规底图时，只提供配图需求说明，不生成正式地图。

### 7.4 图表证据卡

正式图表附内部证据卡：

> 图表用途｜数据或原图来源｜获取时间｜处理步骤｜改绘内容｜与考点的关系｜科学性检查｜地图合规信息｜是否可直接参赛

## 8. 题组设计要求

### 8.1 题组结构

默认一则共用材料和 2—3 道题。各题共享情境，但应具有相对独立的测量目标，并形成自然递进，例如：

> 提取信息或理解现象 → 分析机制 → 迁移应用或作出判断

不得为了凑题量把同一判断换三种问法，也不得让前一题答案直接泄露后一题。

### 8.2 干扰项

每个干扰项应对应一种可解释的认知错误，例如概念混淆、因果倒置、证据遗漏、时空尺度错误或表面信息匹配。不得使用明显荒谬选项、纯文字陷阱或无关知识制造难度。

### 8.3 原创与引用

- 情境组织、材料表达、题干和选项必须原创；
- 真题用于风格与质量参照，不得改写真题后冒充原创；
- 论文、新闻和数据均保留来源；
- 必要的少量事实和数据经重新组织后进入题面；
- 不能确认真实性的数据不得写成真实机构数据，可更换来源，不以“教学模拟”冒充现实事实。

## 9. 课标、核心素养和“四翼”分析

命题说明必须指出：

- 对应的课标内容要求和行为动词；
- 题目中的哪些证据和任务实际承载了该要求；
- 主要考查的地理核心素养；
- 学生需要如何理解和处理材料；
- 题组整体及每道小题的“四翼”主次要求。

“四翼”为基础性、综合性、应用性和创新性，是“怎么考”的要求，不是四个难度等级。产品采用以下操作化检查：

| 四翼 | 检查问题 |
| --- | --- |
| 基础性 | 是否立足课标、taxonomy 和高中地理主干知识，是否要求真正理解基本概念 |
| 综合性 | 是否需要综合图文信息、地理要素或关联知识，综合是否自然 |
| 应用性 | 是否在真实可信的情境中使用地理原理解决问题，材料是否真正参与作答 |
| 创新性 | 是否使用新的情境、数据、研究成果或设问角度，引导陌生条件下的独立思考 |

题组必须分析四翼的实际覆盖情况，但不强制为了“齐全”而同时体现四翼。每题标注主要要求和次要要求，并提供题面证据；某一翼没有真实题面承载时可以不标，禁止口号式贴标签。

权威依据：教育部发布的《中国高考评价体系》介绍，将“四翼”明确为基础性、综合性、应用性、创新性的考查要求：<https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202001/t20200107_414611.html>。

## 10. 难度分析

无真实试测数据时，只输出“预计难度等级＋判断依据”，不生成伪造的难度系数。

难度从以下四方面分析：

1. **考查知识与教材依据**：考什么知识；taxonomy 如何界定；作为答案前提的知识如何在高中地理共同知识中找到依据；新情境如何调用该知识。
2. **信息加工负荷**：需要处理的文字、数据和图表信息；关键证据数量；图文整合要求；合理干扰信息。
3. **认知水平**：识别与描述、理解与解释、分析与推断、迁移与应用、评价与创新解决问题等实际认知表现，并与课标行为要求相互校验。
4. **干扰项区分度**：错误选项对应的认知障碍，以及学生需要达到何种理解水平才能排除。

真实试做后，可以根据实际数据补充正确率、选项分布、区分度和修题建议，并明确样本范围。

## 11. 典型学生模拟作答

默认模拟 3 名学生，每个认知水平 1 名：

- 水平 A：准确提取信息，完成分析与迁移；
- 水平 B：掌握基本概念，但证据整合或推断不完整；
- 水平 C：存在核心概念误解，依赖表面词语或记忆结论。

每名学生呈现：

- 各小题选择；
- 简短、自然的作答思路；
- 正确理解的部分；
- 出错环节；
- 对应的认知障碍；
- 教师可据此进行的判断和干预。

模拟结果必须标注为“预测性认知路径”，不得冒充真实学生数据。教师提供真实试做记录后，应优先分析真实数据，不再以模拟结果代替。

## 12. 默认 Markdown 交付结构

以下六大章节是顶层结构；§6.3 十二项是内容要求，按 [交付格式映射表](../.agent-presets/geo-teacher/skills/geo-question-generator/references/delivery-format.md) 分配到六章。完成度采用术语表的四态；缺少必要图表只能交付带风险说明的初稿，不能标为可使用。

```text
# 题组标题
## 一、学生用试题
```

## 13. 验收标准

一份 V1 合格作品至少满足：

- [ ] 默认题组为一则材料和 2—3 道单项选择题；
- [ ] 教师已提供学情，系统已将其转译为可检验的认知障碍；
- [ ] 命题前提供了 3 个具有实质差异的构思并获得教师选择；
- [ ] 所有核心和支撑知识能映射到当前 taxonomy，并记录版本；
- [ ] 作为答案必要前提的知识属于高中地理教材共同知识；
- [ ] 课标条目、行为要求和核心素养有题面证据；
- [ ] 热点符合时间规则，且不是可删除的装饰；
- [ ] 论文经过教学化转化，没有照搬；
- [ ] 每道题答案唯一，材料充分，题干和选项无科学错误；
- [ ] 每个干扰项对应可解释的认知错误；
- [ ] 四翼分析有主次和题面证据；
- [ ] 难度分析覆盖四个维度且未伪造统计数据；
- [ ] 3 名模拟学生的错误路径与学情、选项设计一致；
- [ ] 图表在生成前说明内容、作用和必要性，并获得教师确认；
- [ ] 数据图、示意图和地图分别满足来源、科学性和合规要求；
- [ ] 所有现实数据、论文、热点、图片和地图均可追溯；
- [ ] 未复制真题或论文题图，不把模仿当作原创。
