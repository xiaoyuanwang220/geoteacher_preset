# 上传试卷讲题方案（V0）

> 状态：**方案阶段（未实施）**　日期：2026-11-07
> 关联：[讲题功能设计](讲题功能设计.md)、[讲题工作流修复方案](讲题工作流修复方案.md)、[讲题评测方案](讲题评测方案.md)、[术语表](术语表.md)
> 适用范围：教师上传学生版试卷（或题目截图）与答案，指定一个题组或其中 1–2 个小题，生成讲稿。

## 1. 背景

教师使用讲题功能主要有两类真实场景：

1. **学生问了难题，教师自己讲不清**：素材通常是题目照片或截图，教师希望得到一份能讲给学生听的稿子。
2. **小测/期中后讲评**：大部分题教师自己能讲，个别复杂题需要辅助；教师不愿逐题裁剪，通常直接给出整份 Word/PDF 并指定要讲的题。

题库的定位是**知识库与考情分析语料**，不是本功能的输入源。上传试卷讲题属于**题目级**任务，不应按“整卷入库/全卷解析”的方式建设。

已排除的方向：解析 Word 结构、识别并裁掉答案、整卷排队、答案保险箱、主模型工具收紧。这些能力主要来自题库讲题评测对“独立作答”的约束，不是教师上传试卷讲题的必需条件。

## 2. 第一性原理

1. **题目级与语料级分开**：题目级用页面图片直接交给多模态模型；文档结构解析只在“整批卷子进知识库”时才需要。
2. **答案可见性的核心影响是分析质量**：模型先看到答案，容易“对着答案找理由”，分析变差。需要保持“盲”的是**独立分析阶段**，不是讲稿阶段；教师本来就持有答案，讲稿阶段对照答案是正常流程。
3. **输入时分离答案最便宜**：学生版天然无答案；卷末整块答案可切页；每题后紧跟答案才需要人工截题。结构解析与答案裁切是最后手段。
4. **一次一个题组**：教师通常只讲一个题组或其中 1–2 个小题，不需要整卷排队与断点续讲。

## 3. 范围

| 范围 | 内容 |
| :-- | :-- |
| 支持输入 | 学生版 Word（.docx）、PDF、题目截图/照片；答案支持图片、文字、Word/PDF 文件 |
| 支持题型 | 选择题、综合题；单题与题组 |
| 支持输出 | 指定题组或指定小问的学生版讲稿（教师版按需） |
| 一次任务 | 一个题组；多题组重复执行 |
| 不做 | 整卷排队、断点续讲、题库保存、答案自动裁切/遮盖、OCR、扫描件版面重建 |

## 4. 输入与交互约定

一条消息内提供：

1. **题目材料**：学生版 Word/PDF（一般只有材料和设问，无答案），或题目截图/照片；
2. **答案材料**（可选）：答案图片、答案文字、答案 Word/PDF；
3. **指定题目**：如“17(1)(2)”或“第 17 题组”；
4. **讲解对象**：默认学生；需要教师版时明确说明。

默认交互为“一条消息：题目材料 + 答案 + 指定题号”，不接受“先传题目、再传答案”的两步流程。

## 5. 处理流程

```
题目材料（学生版 / 截图）
        │
        ├─ Word/PDF → 页面图片（保真，不解析结构、不切题）
        └─ 截图/照片 → 直接作为页面图
        │
        ▼
答案材料 → 提取/暂存（独立分析阶段不可见）
        │
        ▼
零工具隔离会话：只看题目页面，读整组、整组作答
        │
        ▼
主模型：读取答案 → 对照 → 只写指定小问的讲稿
```

要点：

- 隔离会话只接收**题目页面/截图**，不接收答案、解析、答案文件或答案文字；
- 主模型可以读取答案，因为它不承担独立作答；讲稿由“独立作答 + 答案对照”共同支撑；
- 题组内的全部小问进入独立作答，讲稿只覆盖教师指定的 1–2 个小题，其余小问作为上下文。

## 6. 答案位置与处理

| 情况 | 处理 | 失败/兜底 |
| :-- | :-- | :-- |
| 学生版（无答案） | 页面图直接进入独立分析 | — |
| 答案在卷末整块（“参考答案/答案与解析/解析”） | 按标题切页：前面为题目页，后面为答案页 | 找不到标题时**停止并询问教师“答案从第几页开始”**，不猜 |
| 答案每题后紧跟 | 请教师**只截要讲的 1–2 道题**发来，答案照常提供 | 教师无法截题时，明确说明质量风险，不自动裁切 |
| 扫描版学生卷 | 无答案，直接转页面图；不需要文字层 | 题号定位由模型看页面完成 |
| 扫描版整卷含答案 | 无法可靠自动切页 | 询问答案起始页；不能提供时请教师截题 |

## 7. 题组规则

- 独立分析会话读取**整个题组**：共用材料 + 全部小问；
- 作答覆盖整个题组，不拆开只答某一小问；小问之间的相互提示是解题信息的一部分；
- 讲稿只写教师指定的题组或小问；未指定的作答内容可删去，不进入讲稿；
- 教师只指定一个小问时，仍然整组作答，避免割裂上下文。

## 8. 建议的工具与数据流（待实施验证）

拟新增一个模型工具（名称暂定，实施时确认）：

```
geo_paper_lecture(question, answer?, target, audience)
```

- `question`：学生版附件（Word/PDF/图片）；
- `answer`：答案附件或文字（可选）；
- `target`：题组或小问标识；
- `audience`：`student`（默认）| `teacher` | `setter`。

返回：独立作答原文、答案材料（文字/图片）、题组信息、页面数、隔离会话 id、告警信息。

内部步骤：

1. 题目材料转页面图片；
2. 若为含答案整卷，按标题切页或要求教师提供答案起始页；
3. 启动零工具隔离会话，只传题目页面与“只作答第 X 题组”的说明；
4. 保存独立作答；
5. 提取答案材料，返回给主模型；
6. 主模型按讲题技能生成讲稿。

数据与清理：

- 解析产物写入临时目录（如 `<DSH_HOME>/geo-teacher/tmp/papers/<hash>/`），**不写入题库**；
- 清理策略在实施时确定（建议会话结束或保留 24 小时后清理）；
- 不把上传文件或解析产物提交到仓库。

工具描述草案（≤ 350 字符）：

> 上传试卷讲题：把学生版试卷（Word/PDF/截图）转为页面图，在零工具隔离会话中只依据题目作答指定题组或小问；作答完成后再提供答案供对照。用于教师上传整卷或题目截图、指定要讲的题目的场景。

## 9. 错误与提示

| 情况 | 提示 |
| :-- | :-- |
| 找不到“参考答案”等标题 | 询问“答案从第几页开始”，不猜测 |
| 答案每题后紧跟 | 请教师只截要讲的 1–2 道题；说明不平滑处理的后果 |
| 题目页面缺失或模糊 | 如实说明哪一页不可用，不根据模糊图编造 |
| 未提供答案 | 仅凭独立分析出稿，并注明“未提供答案，未做对照” |
| 未指定题目 | 询问要讲哪个题组/小问 |
| 页面数量过多 | 说明将按题组定位页面；无法定位时请教师补充页码 |

## 10. 实施前技术验证

1. 运行时能否把 .docx 稳定转为页面图片（LibreOffice headless 或等价方案）；
2. PDF 页面渲染质量：公式、表格、图、分栏是否可读；
3. DSH 工具如何接收用户上传的附件（文件与图片），以及能否把答案图片回传给主模型；
4. 单次工具运行时长与页面数量上限（避免超时与 token 成本失控）；
5. 页面图片进入隔离会话后，子会话仍保持零工具（沿用现有 `solver-isolation` 能力）。

## 11. V0 验收标准

| 用例 | 通过条件 |
| :-- | :-- |
| 学生版 docx（含图/表/公式）+ 答案 docx，指定 17(1)(2) | 隔离会话 prompt 只含题目页面；零工具；作答覆盖题组；讲稿只写 17(1)(2)；题目图/表/公式可读 |
| 整卷 PDF，答案在卷末 | 自动切页；隔离会话不含答案页；找不到标题时停止并询问 |
| 整卷 PDF/Word，答案每题后紧跟 | 走截图兜底；未自动裁切；教师截题后流程可完成 |
| 答案分别为图片/文字/文件 | 三种格式均能进入讲稿对照；答案不进入隔离会话 |
| 一次一个题组、不保存 | 不写题库、不建整卷队列；解析产物仅存临时目录 |

验收需结合会话轨迹核对：隔离会话输入只含题目页面、`request/header` 无工具、答案在作答提交后才进入主模型。

## 12. 非目标与后续

- 非目标：OCR、扫描件结构重建、答案自动裁切/遮盖、整卷排队、断点续讲、题库自动入库、多题组批量处理。
- 后续按真实需求评估：答案区域自动识别、页面文字层定位优化、临时题目保存与复用、多题组批处理。

## 13. 开放问题

1. 临时解析产物的保留期限与会话结束清理方式；
2. 一次消息内多个题组时的处理方式（逐个串行或批量）；
3. 同一文件重复上传是否按 hash 缓存页面图与独立作答；
4. 答案以聊天文字直接粘贴时，是否仍走工具暂存，或直接进入主模型上下文。
