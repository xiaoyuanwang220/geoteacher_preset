## 文档维护规则

- 按未来决策价值判断保留与归档，不按日期或篇幅删除。
- 现行说明更新事实；实施记录保留验证日期、证据和未完成项。
- 文档只有部分过时时，保留有效约束与独有理由，修正过时段落。
- 归档前明确现行替代入口并处理入站引用；归档正文保留历史原貌，不执行其中的旧部署、升级、清理或回滚命令。
- 决策记录继续采用有效／已废弃的轻量状态。文档归档不引入上游双语配套或冻结校验脚本。
