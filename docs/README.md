# 项目文档索引

本索引是 `docs/` 的唯一入口：先读「5 分钟了解项目」，其余按角色和主题查。文档状态用词固定为四种——

| 状态 | 含义 |
| :-- | :-- |
| **现行** | 与当前实现一致，改代码/配置时应同步更新 |
| **已实施** | 源码已落地，文档中的契约仍有效；历史过程通过 Git 追溯 |
| **方案** | 尚未实施，只代表方向与取舍 |
| **历史** | 只作追溯，结论可能已过时，不作为操作依据 |

## 5 分钟了解项目

1. [项目说明](../README.md) —— 是什么、能做什么、快速开始、架构与已知限制。
2. [使用指南](使用指南.md) —— 输入区与对话两个入口怎么用，话术示例与故障排查。
3. [决策记录](决策记录.md) —— 逐条记录关键取舍、原因、证据与关联文件。
4. [验收待办](验收待办.md) —— 哪些已实测、哪些还没验；不以源码已改代替已验收。

## 文档维护规则

- 当前操作从本索引、包内 README 和技能入口查找；**方案必须标注是否实施**，历史结论不得当作现行依据。
- 已被当前实现取代的方案、迁移步骤和阶段记录**直接删除**，历史通过 Git 追溯，不另建归档目录。
- 删除前保留仍有效的契约、独有依据和未完成验收项，并**更新所有入站引用**（本索引、README、决策记录、技能文件）。
- 决策记录保留取舍理由；标为历史的材料不作为当前操作指南。同一主题合并为一份文档时，在文档内保留原文件名与合并说明。
