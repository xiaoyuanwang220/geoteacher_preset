## 文档维护规则

- 当前操作从本索引、包内 README 和技能入口查找；方案必须明确标注是否实施。
- 已被当前实现取代的方案、迁移步骤和阶段记录直接删除，历史通过 Git 追溯，不另建归档目录。
- 删除前保留仍有效的契约、独有依据和未完成验收项，并更新入站引用。
- 决策记录保留取舍理由；其中标为历史文件的材料不作为当前操作指南。
