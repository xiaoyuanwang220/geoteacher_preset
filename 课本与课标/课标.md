一、课程性质

地理学是研究地理环境以及人类活动与地理环境关系的科学，具有综合性、区域性等特点。地理学兼有自然科学和社会科学的性质，在现代科学体系中占有重要地位，对于解决全球人口、资源、环境和发展问题，维护生态安全，建设美丽中国具有重要作用。

高中地理课程以习近平新时代中国特色社会主义思想为指导，紧紧围绕立德树人根本任务，其内容反映地理学的本质，体现地理学的基本思想和方法。地理课程旨在使学生具备人地协调观、综合思维、区域认知、地理实践力等地理学科核心素养，学会从地理视角认识自然与人文环境，尊重自然、顺应自然、保护自然，懂得人与自然和谐共生的道理，树立绿色低碳发展的观念，提高生活品位和精神境界，为培养德智体美劳全面发展的社会主义建设者和接班人奠定基础。

1. 坚持育人为本，培养学生必备的地理学科核心素养

通过高中地理学习，学生能够从地理学科视角，进一步形成正确价值观、必备品格和关键能力，具备家国情怀和全球视野，关注地方、国家和全球地理问题，增强人与自然和谐共生和可持续发展的观念。

2. 坚持素养导向，优化地理课程结构和内容

围绕地理学科核心素养培养的要求，坚持基础性、多样性、选择性并重，构建科学合理、功能互补的课程结构，满足学生全面而有个性发展的需要；在课程结构框架下，精选利于地理学科核心素养形成的课程内容，力求科学性、实践性、时代性的统一，满足学生现在和未来学习、工作、生活的需求。

3. 坚持知行合一，创新培养地理学科核心素养的教学方式

根据学生地理学科核心素养形成的特点，科学设计地理教学过程，引导学生通过自主、合作、探究等学习方式，在自然、社会等真实情境中开展丰富多样的地理实践活动；充分利用地理信息技术，营造直观、实时、生动的地理学习环境。

三、课程目标

（一）学科核心素养内涵

学科核心素养是学科育人价值的集中体现，是学生通过学科学习而逐步形成的正确价值观、必备品格和关键能力。地理学科核心素养主要包括人地协调观、综合思维、区域认知和地理实践力（附录1）。

1. 人地协调观

指人们对人类与地理环境之间关系秉持的正确价值观。人地关系是地理学研究的核心主题。面对不断出现的人口、资源、环境和发展问题，人们越来越深刻地认识到，人类社会要更好地发展，必须尊重自然规律，协调好人类活动与地理环境的关系。人地协调观的培养，有助于学生形成尊重自然、顺应自然、保护自然的意识，树立绿色发展、国家安全等观念，涵养人文情怀，增强社会责任感。

2. 综合思维

指人们从综合的视角认识地理环境及人地关系的思维方式和能力。

人类生存的地理环境是一个综合体，在不同时空组合条件下，地理要素相互作用，综合决定着地理环境的形成和发展。综合思维的培养，有助

3. 区域认知

指人们从空间—区域的视角认识地理环境及人地关系的思维方式和能力。人类生存的地理环境复杂多样，将其划分成不同空间尺度、不同类型的区域加以认识，是人们认识地理环境复杂性的基本方法。区域认知的培养，有助于学生建立地理空间观念，认识不同的区域既各有特色，又相互联系，增强热爱家乡的情感和国家认同感，增进对世界的理解，逐步形成人类命运共同体意识。

4. 地理实践力

指人们在野外考察、社会调查、地理实验等地理实践活动中所具备的行动力和意志品质。野外考察、社会调查、地理实验等是地理学常用的研究方法，也是地理课程重要的学习方式。地理实践力的培养，有助于学生在真实或模拟环境中通过地理实践活动，观察和认识地理环境，体验和感悟人地关系，并在过程中养成不畏困难、乐学善学的品质，实现知行合一。

地理学科核心素养是一个相互联系的有机整体。人地协调观是地理课程内容蕴含的最为核心的价值观，综合思维和区域认知是学生建立人地协调观所需要的重要思维方式和能力，地理实践力则是学生秉持人地协调观、运用综合思维和区域认知方法，在分析和解决地理实践中遇到问题时所具备的行动力和意志品质。

四、课程结构

（一）设计依据

1. 社会发展需求

课程结构需反映社会对人才需求的变化。随着科技进步和经济社会发展，对人的综合素质提出了更高要求。地理课程结构应以课程目标为导向，展现地理课程对培养具备系统观念、综合思维、区域认知、创新精神和实践能力的人才的重要作用，从地理学科视角对提高人的综合素质作出独特贡献。

2. 地理学科体系

课程结构需以地理学科体系为基础。地理学的学科体系中有自然地理学、人文地理学和区域地理学等。地理课程结构基于地理学科体系建构，是课程内容连贯性和系统性的基本保证。地理课程结构还要兼顾地理学不断形成新的分支学科，以及与其他学科交叉融合不断增强的特点与趋势，注重融入地球科学、海洋科学、国家安全等相关内容，加深学生对自然和社会的认知。

# 3. 学生身心特点

课程结构需适应高中学生身心发展特点。高中学生在认知能力、自我意识、责任意识等方面都有很大发展。他们在打好地理学业基础的同时，面对未来就业、升学规划，以及自身对地理学的兴趣，展现出多元化的学习需求。地理课程结构应能满足学生的学习需求，设计多样化、多层次的课程模块，体现基础性、发展性和选择性。

# (二)结构

按照普通高中课程方案的规定，高中地理课程分为必修、选择性必修和选修三类课程。必修课程的内容精选学生终身发展必备的地理基础知识和基本技能，以满足全体学生基本的地理学习需要。必修课程包括两个模块，即地理1和地理2。选择性必修课程内容在必修课程的基础上加深或拓展，以满足部分学生升学考试或就业的需要。选择性必修课程包括三个模块，即自然地理基础，区域发展，资源、环境与国家安全。选修课程为校本课程，提供多样化的课程清单，以满足不同学生基于兴趣爱好、学业发展、职业倾向等选课的需要。选修课程包括九个模块，分别侧重自然领域、人文领域、技术与实践领域（图1）。

（三）学分与选课

必修课程是全体学生必须修习的课程，每个模块2学分，两个模块共计4学分。

选择性必修课程是学生结合其未来高等教育学业与职业方向选择修习的课程，每个模块2学分，三个模块共计6学分。选择修习地理课程的学生，需要全部修满6学分。

选修课程是学生根据个人兴趣选择修习的课程，九个模块为学校开设校本课程提供参考。

（一）教学与评价建议

1. 重视问题式教学

问题式教学是用“问题”整合相关学习内容的教学方式，以“问题发现”和“问题解决”为要旨。

采用问题式教学，问题设计是基础，建议关注以下方面。（1）以学生的认知水平为基础，设计指向课程目标、符合课程内容要求并联系实际的问题。（2）有利于加强教学内容的结构化，避免碎片化。（3）根据问题创设问题情境，问题情境要蕴含并支持问题理解、问题解决的必要且真实的信息。（4）有利于激发学生的学习兴趣，引导学生探索未知并创造性地解决问题。

3. 深化信息技术应用

信息技术的发展和应用是地理教学改革的助推器，对改变学生学习方式和教师教学方式，帮助学生享有公平而有质量的地理教育具有重要作用。借助虚拟现实、人工智能、“互联网+”等信息技术，可以为学生提供自主学习、探究学习和合作学习的开放空间，促进地理学习的拓展和深入。借助信息技术，教师还可以改变评价方式，使评价更有针对性、即时性、互动性，从而更好地发挥评价对学生个体指导的 作用。

在进行信息技术辅助教学时，建议考虑以下三个方面。

（1）把握互联网及人工智能支持的学习特点。例如，利用信息技术支持下出现的“高效、开放、共享”的学习特点，积极创建人机协调的学习生态，帮助学生体验基于互联网、人工智能的开放式地理学习方式，形成人人皆学、处处能学、时时可学的线上线下学习状态。

（2）发挥移动设备和云平台的优势。例如，利用平板电脑等移动设备和互联网即时交流工具，及时了解学生的学习情况和存在的问题，体现因材施教。

（3）协调好应用信息技术与立足真实情境两种教学方式的关系。例如，运用虚拟现实、人工智能等技术支持教学时，要认识到技术支持可以在一定程度上弥补无法外出实践教学的缺憾，但不能全部代替真实环境下的实践活动。

4. 关注表现性评价

表现性评价指在真实或模拟情境中，对学生解决问题、完成有关任务的过程表现和结果（如课堂问答、地理作品展示、地理活动参与度等）作出判断。

表现性评价的设计关注以下方面。

（1）围绕评价目标设计表现性的任务。评价目标是对所期望的学习过程和结果的界定。嵌入教学活动中的评价目标与教学目标是一致的。

表现性任务应目标明确，形式多样，具有开放性，利于学生应用所学地理知识和相关学科知识等，展示多方面表现或结果。

（2）依据评价目标和学业质量要求等设计评价量规。评价量规应从学生视角出发，对学习过程和结果进行描述。评价量规的设计，首先应对主要学习过程和结果作出界定；然后对学生预期行为表现等进行刻画，通常正面描述学生能做什么；最后要确定学生表现水平的差异，形成从低到高、从简单到复杂的层级或进阶。

（3）根据评价目标的不同，选择相应的评价方式。着眼于“为了改进”的评价理念，更多采用“做中评”。例如，通过观察学生的课堂发言、地理作品的展示，以及参加地理实践的活跃程度等，发现学生的学习好在哪里，还有哪些不足需要改进。一般来说，教师应围绕评价量规组织学生讨论，指导学生依据量规，用过程表现的记录或作品等证据，说明自己在评价目标方面的达成情况，接受同学或老师的评议，反思改进自己的不足。教师还应该针对学生表现性任务或项目完成中的困难提供必要的支持、辅导。

3. 试卷结构

（2）题型结构

纸笔考试题型包含客观题和主观题。客观题一般包含单项选择题、多项选择题等，主观题一般包含简答题、填图作图题、论述题等。学业水平合格性考试以单项选择题为主，且应有一定比例的主观题；学业水平等级性考试中主观题分值占比应高于客观题。

（3）难度结构

学业水平合格性考试主要依据学业质量水平1设计难度结构，兼顾学生群体特征，重点关注临界合格水平学生。学业水平等级性考试主要依据学业质量水平3设计难度结构，兼顾学生群体特征和招生录取率等因素。两类考试均应依据预设难度合理配置难、中、易试题分值比例。

真实性。情境要基于客观存在的地理事象，联系生产生活实际，反映时间、空间、情节等要素，符合逻辑、真实可信，避免使用主观臆造的地理事件、数据等，杜绝使用有悖事实和常理的材料。

适切性。情境要符合学生身心发展特点和认知发展状况。情境的复杂程度要与考试性质、考试目的相适应。

# 附录2 地理学科核心素养水平划分

# (一)人地协调观

|水平|人地协调观|
|---|---|
|水平1|在结构良好的地理情境中,能够从人地关系的角度,简要描述地理环境为人类活动提供基础、人类活动对地理环境产生积极与消极影响的事实;简要说明出现的人地关系问题及解决的途径和方法。|
|水平2|在结构不良的地理情境中,能够从人地关系的角度,说明地理环境对人类活动的影响,以及人类活动影响地理环境的方式和强度;分类描述具有全球性和区域性的人地关系问题,并对解决问题的途径和方法进行评价。|
|水平3|在结构不良的地理情境中,能够从人地关系的角度,说明不同空间尺度区域中人口、资源、环境、发展之间的相互关系,用证据说明人地关系是对立统一的,并分析、评价人地关系中存在的问题,提出自己的见解。|

# (二)综合思维

|水平|综合思维|
|---|---|
|水平1|在结构良好的地理情境中,能够从地理要素相互影响、相互制约的角度,简单分析地理事物和现象的成因、结果和影响,并关联时间和空间,合理推断其发展变化过程;综合地理要素相互作用和时空变化过程,简要解释区域地理环境特征的形成。|
|水平2|在结构不良的地理情境中,能够从地理要素相互影响、相互制约的角度,解释地理事物和现象复杂的因果关系,及其产生的结果和影响;从时空相互关联的角度,分析地理事物和现象的现状,推测其形成过程及发展方向;综合地理要素相互作用和时空变化过程,解释区域地理环境的形成、特征和变化。|

# 续表

|水平|综合思维|
|---|---|
|水平3|在结构不良的地理情境中,能够运用要素综合、时空综合、地方综合的思路,综合分析地理事物和现象的主要特征、成因及变化过程,对现实的地理问题展现出较强的洞察和综合分析能力。|

# (三)区域认知

|水平|区域认知|
|---|---|
|水平1|在结构良好的地理情境中,能够从区域整体性的角度,简要描述区域中地理环境和人类活动具有相对一致性的事实,并刻画区域主要特征;从区域差异性的角度,比较不同区域的特征、联系和结果;简要分析区域发展的地理背景。|
|水平2|在结构不良的地理情境中,能够从区域整体性的角度,收集、整理区域重要信息,发现并归纳区域地理事物和现象的空间分布,并分析其原因;从区域差异性的角度,采用恰当的认识区域的方法,选择具有可比性的区域,分析区域差异和区域联系;为赞同或质疑某一区域发展决策提出相关论据。|
|水平3|在结构不良的地理情境中,能够从区域整体性的角度,收集、整理区域重要信息,发现并归纳区域地理事物和现象的空间分布,并说明区域内一个环境条件改变对其原有空间分布的影响;从区域差异性的角度,运用认识区域的方法和工具,综合分析不同区域的发展条件、路径和结果;较全面地评析某一区域发展决策的得失,并提出较为可行的改进建议。|

# （四）地理实践力

|水平|地理实践力|
|---|---|
|水平1|在结构良好的地理情境中,能够进行细微观察和调查,获取和处理信息,有探索问题的兴趣;能够使用地理工具,设计和实施较简单的地理实践活动,用证据解释实践结论;在参与地理实践的过程中,有自己的想法,主动从体验和反思中学习,有克服困难的勇气和方法。|
|水平2|在结构不良的地理情境中,能够进行分类观察和调查,获取和处理较复杂的信息,主动发现和探索问题;能够使用地理工具,设计和实施较复杂的地理实践活动,并有物化形式的实践结果,善于在实践和总结中不断提升行动力;在参与实践的过程中既有自己的想法,又与同伴互助交流,有克服困难的勇气和方法。|
|水平3|在结构不良的地理情境中,能够进行较系统的观察和调查,用科学方法对获取的数据、资料进行处理,主动发现、探索和解决问题;能够使用地理工具,有创意地设计和实施地理实践活动,并有证据充分的、以物化形式呈现的实践结果,对解决实际问题有一定作用;在参与实践的过程中既有创造性的想法,又能博采众长,有克服困难的勇气和方法,并体现出一定的组织领导力。|
