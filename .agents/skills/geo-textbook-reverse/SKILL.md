# 高中地理教材结构化与学科思想逆向规范

本技能面向**开发与内容维护**阶段，用于将高中地理教材原文加工为两类资产：① 标准结构化教材稿；② 供课程方案技能按需读取的「教材思想解读」。不进教师运行预设。

## 适用范围与定位

- **输入原文**：`课本与课标/` 下的分册文本与 `课本与课标/课标.md`。
- **结构化产物**：`课本与课标/结构化/<出版社><模块>《<书名>》教材结构化.md`（参照标杆：`人教版选择性必修2《区域发展》教材结构化.md`）。
- **逆向产物**：`.agent-presets/geo-teacher/skills/cn-high-school-geography-lesson-planning/references/textbooks/<分册目录>/` 下的 `overview.md` 与 `chapter-<n>.md`，并在同目录 `index.md` 登记路由（单节标杆见选必2 `chapter-1.md` 的 `C1S2` 与 `chapter-2.md` 的 `C2S3`）。
- **术语权威**：所有地理与思想术语以 `docs/术语表.md` 为准；共用思想含义见 `.agent-presets/geo-teacher/skills/cn-high-school-geography-lesson-planning/references/disciplinary-foundations.md`。

## 阶段一：教材原文结构化模板

原则：**忠实原文、按实有栏目切分、严格区分图注原文与图示说明**。

```markdown
# 第X章 <章标题>

## 章首页
<章首引言原文>
在本章，我们重点探讨以下问题：
- <问题1>
> 章首页图片：<名称>（照片/地图）。<意象说明>

## 第X节 <节标题>

### 情境设计
<节首情境正文与设问>
> 图X.X <图名>（照片/地图/示意图/统计图）
>
> 图注原文：<原书有图注时逐字保留>
> 图示内容：<无图注或需说明视觉要素时写客观描述，不与图注原文混写>

### 一、<一级小标题>

#### 课文
<正文原文；脚注紧跟所在段后用引用块>
> 脚注① <术语>：<脚注原文>

#### 思考（插在课文中段时注明：教材插于本小标题课文中段）
1. <设问1>

#### 课文（续）
<后续正文>

#### 案例：<案例标题>
<案例正文与图块>

#### 活动：<活动标题>
<材料、图块、标准 Markdown 表格（留表号与数据来源）与编号设问>

### 自学窗：<自学窗标题>
<正文与图块>

## 本章要点
1. <要点1>

## 问题研究：<课题名>
### 研究背景
### 知识拓展
#### 资料1 <标题>
##### 资料分析
### 问题探讨
```

**结构化底线**：
- 标题严格四级：`#` 章 → `##` 章首页/节/本章要点/问题研究 → `###` 情境设计/一级小标题/自学窗 → `####` 课文/思考/案例/活动/资料。
- 某节无`思考`、`案例`或`自学窗`时直接省略，**不补造栏目**；插在课文中段或案例后的栏目保留原书先后位置。
- 原图未核实时，图示内容只作客观结构说明，不编造图上读数或页码。

## 阶段二：按教材实有模块逆向学科思想模板

先读本节结构化稿（含所属章的`章首页`、`本章要点`与`问题研究`）及课程方案技能中的 `disciplinary-foundations.md`，再按以下骨架逐节编写：

```markdown
## C<章>S<节> <节标题>

**核心认识：<一句话写清学生要理解的具体地理关系，不堆思想名称>**

- **章级上位**：<章首页对应问题 + 前后节及章末问题研究衔接 + 本章要点底线>
- **按教材实有模块展开**：
  - **`<实有模块名>`（<关键案例/图号/脚注>）**
    - *学科思想与认识层次*：<思想标识 + 用平实教学语言说清本块将认识推进到哪一层>
    - *材料与设问解码*：<文字、脚注、配图与设问梯次各自承担什么认知动作，点出前后呼应与暗线>
    - *模块咬合*：<承接上一模块什么、为下一模块铺垫或交接什么>
  - ...（严格按结构化稿本节实有模块逐块展开）
- **全节编排主干**：<一行箭头串起所有模块间的暗线推进链>
- **思想对应**：<区分直接体现与可开发/依材料展开>
- **边界**：<客观科学边界与教材证据/数据时点限度>
- **理解表现**：<去掉思想术语后，学生应能做出的具体地理判断或解释>
```

**章末问题研究（`C<章>Q`）**沿用同一思路，按 `研究背景 → 资料1..n（含资料分析）→ 问题探讨` 实有模块展开即可。

**跨分册思想处理**：优先复用已登记思想（`F-REG / F-REL / F-SCA / F-SYS / F-PRO / F-MEAN / F-JUS`）。逆向必修一/二、选必一/三时，若确有现有思想无法妥善涵盖的学科核心思想，先向维护者提出增补建议，经审定同步更新 `docs/术语表.md` 与 `disciplinary-foundations.md` 后再启用，不擅自引入未登记代号。

## 五条硬约束（防压制自由度与防跑偏）

1. **不写「教材压缩留白」或具体深化点子**：只客观解码教材本身，绝不列“建议补 XX 数据/XX 故事”，避免锚定模型、压制备课自由度。
2. **不预设教法、活动形式或固定课序**：逆向的是认知推进暗线，不是教案步骤模板。
3. **不宣称「编者意图」**：本资料定性为基于教材证据的项目备课解读，不冒充编写者声明或课标原文。
4. **不用人为分级代号**：禁止写入 `L1/L2/L3` 等内部等级标签，用自然教学语言表达认识层次，防术语泄漏进成品。
5. **证据边界压短降噪**：如某统计图仅呈总量变化，用极简一句点明限度即可，避免写得过重诱发模型把地理课跑偏成数据审计课。

## 接入与自检清单

- **升级已有分册章节**（如选必2其余节）：原地更新对应 `chapter-<n>.md` 条目；每条核对图号、脚注号、数据年份与结构化稿逐字一致。
- **新增分册**：在 `.agent-presets/geo-teacher/skills/cn-high-school-geography-lesson-planning/references/textbooks/` 下新建 `<出版社-模块-英文短名>/`（含 `overview.md` 与 `chapter-<n>.md`），并在该目录 `index.md` 表格登记教材身份、入口路径与目录匹配依据。
- **完成校验**：
  1. 确认无「压缩留白」建议、无 `L1/L2/L3` 代号、无未登记思想标识、无作者会话残留（如“本次升级”“旧版改为”）；
  2. 运行 `npm run verify:geo -- --source` 与 `node --test "test/*.test.mjs"`，确认 0 项失败。
