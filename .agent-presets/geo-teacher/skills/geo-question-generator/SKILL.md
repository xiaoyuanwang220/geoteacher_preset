# 高中地理命题（两阶段）

面向高中地理的原创题组命题。**先构思、后成题**：不得在收到一句模糊指令后直接跳到完整作品。

## 任务边界

- 交付物：一则共用材料的题组，及其设计说明、来源与风险记录。
- **两种题型，一个题包只用一种**。题型由题包顶层 `questionType` 声明一次（术语表规定"题型"只指这一对取值）：

| `questionType` | 中文 | 题组形态 | 作答与评分 |
| :-- | :-- | :-- | :-- |
| `single_choice` | 材料型选择题组 | 2—3 道单项选择题（`items[]` 的小题） | 选项 A/B/C/D，答案唯一；每个干扰项映射一种认知错误 |
| `comprehensive` | 材料型综合题 | 1 道大题（`items[]` 唯一一项），内含 2—4 个小问（`subQuestions[]`） | 各小问带分值、采分点、证据链、评分标准与答案边界；无干扰项 |

- 专项训练模式压缩设计说明与来源篇幅；选择题组可只出 1 道小题，综合题不因压缩而省略评分标准与答案边界。
- 学科固定为地理，不询问；**不询问教材出版社版本**。
- 最小输入：学段或年级、主题或考点、教师提供的学情（可模糊）。缺少可选参数时采用合理默认，并在构思阶段明示关键假设。
- 不把年级等同于固定教学进度。

## 两种用途

| 用途 | 判定 | 差异 |
| :-- | :-- | :-- |
| 参赛模式（默认） | 教师提到比赛、备赛、参赛作品 | 完整设计说明、证据链与模拟作答 |
| 专项训练模式 | 教师提到针对薄弱点、专项练习 | 压缩设计说明与来源部分，但**不省略**知识依据、答案解析、干扰项对应（综合题则为采分点与答案边界）与学情诊断 |

省份风格是可选约束，不是第三种用途。**没有风格档案时使用成熟高考题的一般规范，不得声称模仿了某一省份。**

## 两个默认确认点

1. **构思**：先给出 3 个实质不同的命题构思，等教师选择、组合或修改后才成题。未经确认不生成题组。
2. **图表**：图表只先给设计说明（内容、作用、必要性），**经教师确认后才制作**正式图。

除上述两点，只有会实质改变结果的情况才追加询问（考点未收录或待复核、来源不足、地图不合规、比赛要求冲突）。措辞、局部版式、普通检索词、可自行核验的细节自行处理。

## 真源与写权限

| 数据 | 位置 | 权限 |
| :-- | :-- | :-- |
| 考点树（taxonomy） | 插件配置的考点库目录（键 `knowledgeBasePath`；考点库随包时为 `<预设包>/knowledge/`） | **只读**；不写回、不新建 ID、不擅自补录 |
| 本地真题库 | 插件配置的真题库目录（键 `questionBankPath`） | **只读**，且**只经工具访问**（见下） |
| 出题任务包 | `outputs\出题\<taskId>\` | 可写；`package.json` 是唯一编辑源 |

- **实际生效的路径以 `/geo/core/health` 的回显为准**（它同时给出该目录是否存在），不要凭记忆或本文件推断。

- **考点定位一律走 `geo_taxonomy`；真题一律走 `geo_search_questions` / `geo_question_detail`。** 严禁用 read/glob 直接读取题库 md 文件——题库文件含答案与解析，直读等同读取答案，属流程违规。
- 每次会话现场读取当前 version 与 `needs_review`，并记录实际使用的版本；taxonomy 当前为草稿状态，**不得表述为"正式定稿"**。
- **实际用到的节点只要源中 `needs_review=true`，就必须记入 `knowledge.needsReviewNodeIds`，并在 `risks` 中明示**：可以提出构思，但不得无提示地交付为最终作品。
- 工作产物不写入技能源目录。

## 质量红线（不可降级）

- 答案唯一（选择题）；材料证据充分；题干与选项／小问无科学错误、歧义、偏题与暗中超纲。
- **选择题**：每个干扰项对应一种可解释的认知错误，并映射到学情障碍；禁止明显荒谬选项与"其它选项错误"式解析。
- **综合题**：每个小问的 `points` 必须等于该问 `answerKey` 各采分点 `points` 之和，`totalPoints` 必须等于各小问 `points` 之和；每个采分点须写出证据链，只写结论不写证据视为不合格；答案边界（`answerBoundary`）必须可判定，评分标准至少 2 档且能依据采分点判定。
- **综合题不得退化为照抄材料**：设问须要求判断、解释、评价或提出适用条件，不能只是"写出材料中的措施"。
- 作为正确答案必要前提的知识，必须能在高中地理教材共同知识中找到依据。**允许情境超纲，禁止必备知识暗中超纲**；材料外术语若影响作答须在题面解释。
- **无真实试测数据时只输出定性预计难度与依据，禁止输出正确率、难度系数、区分度或选项分布。** 综合题的模拟作答只记书面答案与命中的采分点，**不写预估得分数字**——数字容易被误读为试测数据，而采分点 id 已足以推导得分。
- 三名模拟学生（A/B/C 各 1 名）必须标注为"预测性认知路径"，不得冒充真实试测。
- 来源不等于证据：每个来源必须记录它实际支持了哪项事实或设计决策。
- 论文必须经教学化转化，记录实际读取范围；只读摘要时不得声称已核对全文，不得复刻论文图。
- 四翼（基础性/综合性/应用性/创新性）分析须有主次与题面证据；**没有真实题面承载的不标**，禁止凑齐四项。
- 热点须与考点发生真实关系；**删除热点后题目仍原样成立，即判为装饰**，须重新设计或更换情境。
- 原创：不改写真题题干、选项或解析，不把模仿当原创。
- 地图：只用官方标准地图或官方行政区划数据并记录审图号；**禁止 AI 生成行政区划轮廓**；无法取得合规底图时只出配图需求说明。

## 完成条件

按 `readiness` 如实声明，不得跳级：

| readiness | 含义 | 可对教师声明 |
| :-- | :-- | :-- |
| 构思待选择 | 已形成三个构思，未获教师确认 | 可比较、选择或修改方向 |
| 初稿完成 | 完整题组与说明已形成，可能含图表占位或待核验依据 | Markdown 初稿完成，并列出尚缺内容 |
| 可使用 | 必要材料与图表齐备，结构与语义核验完成，无阻断项 | 题组可用于相应教学任务；是否符合具体比赛规则仍按该比赛要求判断 |
| 待补充 | 证据、确认或必要图表缺失 | 只能交付构思或初稿，不宣称最终对齐或完整成品 |

**必须读图才能作答、而图尚未制作时，只能到"初稿完成/待补充"。** 结构检查通过不等于质量通过；语义项未完成时保持 `pending`，不得报告"全部门禁通过"。

**综合题另有两条语义条件**（结构检查查不出，必须由评审给出）：采分点与分值自洽且覆盖参考答案的每一条推理；答案边界在常见作答上可判定。这两条未评审前，综合题不得标 `usable`。若 `knowledge.needsReviewNodeIds` 非空，交付稿必须明示该节点待复核。

## 平台与生效边界

- 本技能以目录包形式提供（`SKILL.md` + `references/`）。改动 `references/` 不刷新技能目录，下次显式读取即取得新内容；插件或组合改动需完整重启桌面。
- 字段名与枚举以 `plugins/question/package.schema.json`（schemaVersion 2）为准；术语以 `docs/术语表.md` 为唯一权威，输出中的"考点""题组""小问""小题""采分点""干扰项"等用法必须与之一致。
