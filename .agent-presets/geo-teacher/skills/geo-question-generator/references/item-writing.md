# 构思比较、题组、干扰项与学情对应

## 何时读这份文件

在以下动作发生前读本文，读完再动手：

- 把教师提供的学情转译为待验证认知障碍（`learningHypotheses`）；
- 写 `concepts[]` 三个构思、比较构思差异、判断是否需要重新提出构思；
- 设计题组的材料、题量与小问／小题的认知递进；
- **选择题**：写题干、选项、`distractorMap`、`analysis`；
- **综合题**：写小问、分值、采分点与证据链、评分标准、开放答案边界、典型错答模式；
- 写 `fourWings`、预计难度；
- 写 A/B/C 三水平模拟作答。

不覆盖：交付章节与题包字段总览、确认与回退流程、来源范围与降级、图表提案审批。那些规则在其他支持文件中，本文不重复。

术语以 `docs/术语表.md` 为准：说考点（不说"知识点"）、题组、**小问（综合题）／小题（选择题）**、题干、材料、干扰项（仅选择题）、采分点、核心素养、设问模式、题型。**不得用"小问"指选择题题组内的题，也不得用"小题"指综合题内的小问。**

## 一、学情 → 认知障碍

教师原话逐字进 `request.learningStateRaw`，同时逐条复制进每条假设的 `learningHypotheses[].teacherInput`；不改写、不概括、不补术语。

从原话转译 2—3 条认知障碍（schema 限定 minItems 2、maxItems 3），每条：

- `id`：`LH-01`、`LH-02`… 稳定不复用；
- `statement`：必须含"可能"或"待验证"。正例："学生**可能**尚未建立冷热差异→垂直运动→气压差异→水平气流的因果链"；反例："学生不理解热力环流"——这是照抄结论，不是假设；
- `observableErrors`：可观察错误，写成"作答中会出现什么"。**选择题**写选项层面的错误表现（如"把水平气流方向直接由等压线疏密推出"）；**综合题**写答卷层面的漏点或错答表现（如"只罗列措施，不说明措施与土地退化环节的对应关系"）；
- `candidateErrorStrategy`：可选。选择题写将来对应哪类错因的干扰项；综合题写典型错答或漏点策略；
- `status`：`proposed` / `selected` / `rejected` / `revised`，教师选择或修正后立即更新。

纪律：措辞不得冒充真实诊断结论。禁止"学生确实……""经诊断……""学生无法……"（把"可能"删掉即降级为事实断言）。这些是命题假设，只有教师可选、可改、可驳回。

## 二、三个构思与实质差异

提出 3 个构思再排序，`concepts[]` 每条至少覆盖四个比较项：**情境（现实问题不同）、主要证据（材料倚重的数据/图文不同）、认知推进方式（先机制还是先现象）、创新方式（新情境/新数据/新设问角度）**。

判定：只有标题和措辞变化——情境仍是同一现实问题、证据仍是同一组数据、推进仍是同一顺序——即视为**失败**，必须重新生成，不得把三个近似版本交给教师选。G3 与 PRD §6.2 用的是同一条判据。

构思卡字段与落点：核心考点与角色（`coreKnowledge[].taxonomyId` + `role`，取 `core_exam_point` / `supporting_knowledge`）、对应课标要求与核心素养、针对的障碍（`learningHypothesisIds`，至少 1 条）、情境与来源（`context.issue` + `context.sourceIds`）、论文转化、认知递进（`itemProgression`）、四翼主次（`fourWings`）、图表提案（`visualProposalIds`）、创新点（`innovation`）、预计难度与风险（`expectedDifficulty` + `risks`）。

`itemProgression[].item` 的序号含义随题型：**选择题**为题组内第 N 道小题；**综合题**为第 N 个小问。综合题的递进必须写清各小问之间是"提取—分析—评价/决策"还是"现象—机制—措施"，不允许三个小问都停在同层。

课标引文与论文转化的书写规则见证据类支持文件，本文只管构思是否可比、是否实质不同。

## 三、题组结构

题组形态由顶层 `questionType` 决定，一个题包只用一种，不混排。

**选择题组（`single_choice`）**

- 默认：一则共用材料 + 2—3 道**单选**小题（`items` minItems 1、maxItems 3）；专项训练允许只出 1 道。
- 递进走"提取信息或理解现象 → 分析机制 → 迁移应用或作出判断"，允许少于三步，不允许倒序。
- 不得为凑题量把同一判断换三种问法——三题各写一遍"热力环流的方向"即不合格，应换测量目标或减题。
- 不得让前一题答案直接泄露后一题：后一题不得以"根据上题结论"默认前一题答案。
- 各小题共享情境但测量目标相对独立，逐题对照 `coreExamPoint` 与 `cognitiveLevel` 确认没有重号。

**材料型综合题（`comprehensive`）**

- 一则共用材料 + **1 道大题**（`items` 恰好 1 项），大题内含 **2—4 个小问**（`subQuestions`）。
- 小问按真实综合题的设问分层组织，典型组合是"描述/比较 → 分析成因或机制 → 评价措施、提出条件或作出判断"。不得三问同层，也不得把一问拆成三问凑数量。
- 各小问分值合计等于大题 `totalPoints`；单问分值按其需要调动的地理要素数量与推理长度定，不平均分配。
- 小问之间不得串答案：后一问不得要求学生"根据第（1）问的结论"作答。
- 综合题没有干扰项，测量目标的独立性靠**采分点互不重叠**来保证：两个小问的 `answerKey` 不得出现同一采分要素的重复给分。

两类题型共同的取题纪律：参照真题时一律走 `geo_style_profile`、`geo_search_questions`、`geo_question_detail`；不得用文件读取工具直接打开题库 md（题库 md 含答案与解析，直读等同读取答案）。

## 四、生成顺序（有依赖，不可乱序）

选择题：

1. 固定测量目标与认知障碍：写定 `learningHypotheses` 与所选障碍，`selectedConcept` 绑定对应 revision。
2. 固定每题核心考点 / 认知水平 / 四翼主次：先定这三项，再动笔写任何文字。
3. 确定材料中的必要证据：逐题列出答案成立必须出现的材料信息；材料里没有的，先补材料或换构思。
4. 写题干：设问模式由动词 + 对象 + 限定词构成，一题一个设问动作。
5. 先写正确答案及其成立条件：把正确项写出来后，显式写出它成立依赖的材料条件。
6. 按认知障碍构造干扰项：见第五节。
7. 回查材料是否足以支持唯一答案：逐选项比对材料，找得出第二个可辩护选项就回到第 3 步。
8. 检查题间独立性与递进：确认无答案泄露、无重复测量点、顺序符合第三节。
9. 生成解析与选项分析：见第七节。

综合题：

1. 固定测量目标与认知障碍；写定三个构思并取得教师选择。
2. 先定各小问的设问层级与分值分配，再动笔写题干。
3. 按小问逐一列采分点：**先写采分要素，再写它依据的材料证据**（证据链），最后分配分值。顺序反过来会出现"有分无据"的采分点。
4. 写参考答案（分档），据此写评分标准：至少 2 档，每档说明答案特征与对应分值区间。
5. 写答案边界：列出可接受的表述方式与应判错答／不给分的常见情形；灰区只能写进 `notes`，不得用 `notes` 代替边界。
6. 写典型错答模式（`misconceptionPatterns`），每条指明落在哪个采分点或哪条边界上失分。
7. 回查：各问采分点分值之和 = 该问分值；各问分值之和 = `totalPoints`；采分点之间不重复给分；小问之间不串答案。

倒过来做（先写题干、后用选项或采分点凑考点）必然出现多解、漏点或暗超纲，属于退回局部修改的情形。

## 五、选择题：每题必填与干扰项

每题必填，缺一项即结构不合格：`itemType`（`single_choice`）、`stem`、`options.A–D` 齐全、`answer` 唯一（A/B/C/D 之一）、`analysis`、`distractorMap`（**正确项不得出现在其中**）、`coreExamPoint`、`supportingKnowledge`、`materialClues`、`cognitiveLevel`、`fourWings`。

`distractorMap` 的每个键对应一个错误选项，写 `errorType` 与 `misconceptionId`：

- `errorType` 取一种可解释的认知错误：概念混淆 / 因果倒置 / 证据遗漏 / 时空尺度错误 / 表面信息匹配；
- `misconceptionId` 必须指向 `learningHypotheses[].id`（如 `LH-02`），且在教师已选障碍范围内；无对应障碍的错误选项应删改，不为"凑满三个错项"保留；
- 禁用"粗心""审题失误""没看清"当错因——它们不指向任何认知障碍。

红线：不得使用明显荒谬选项、纯文字陷阱（换同义词、加"都/只/一定"制造歧义）、无关知识制造难度（搬入未在材料或课标中出现的知识）。四个选项都必须是学生真实可能选的项，正确项由材料条件唯一支撑。

## 六、综合题：小问、分值、采分点与答案边界

**小问 id 与字段**：`subQuestionId` 形如 `Q1-1`（大题 id + 小问序号）。每个小问必填 `stem`、`points`、`answerKey`、`rubric`、`answerBoundary`、`cognitiveLevel`；`misconceptionPatterns`、`materialClues`、`fourWings` 可选但建议填。

**采分点（`answerKey[]`）**是综合题的评分骨架，每个采分点写三件事：

- `statement` 采分要素：学生答案中必须出现的地理要素、判断或结论。写成可判定的短句，不写"分析合理即可"；
- `evidenceChain` 证据链：该要素成立所依据的**材料具体字句**与推理结论。只写结论不写证据的采分点是无效的，与选择题"据材料……可知"同一标准；
- `points` 分值：`pointId` 在本包内唯一（`KP-1`、`KP-2`…），六个采分点各 1 分就写六个 `points: 1` 的采分点，不要用一个 6 分的粗颗粒采分点。
- `acceptableVariants`：可接受的等价表述（如"水土流失／土壤侵蚀"），**只放宽措辞，不放宽边界**。

纪律：

- 采分点数量与分值必须能覆盖参考答案的每一条推理，不得出现"参考答案里有、采分点里没有"的给分点，也不得出现"有分值、无对应要素"的空采分点；
- 采分点不得重复给分：同一要素在多个采分点出现即须合并，或在 `answerBoundary.unacceptable` 中说明只给一次；
- 不把材料原文照搬成采分要素——照抄材料的答案不构成地理判断，不得给分。

**评分标准（`rubric[]`）**至少 2 档（schema 强制 minItems 2）：每档写 `level`、`scoreRange`、`description`，描述必须能依据采分点判定。禁用"认真分析、条理清晰即可给满分"式措辞。

**开放答案边界（`answerBoundary`）**是综合题区别于选择题的关键字段，必须写清：

- `acceptable`：可判为正确的答案面向或表述方式；
- `unacceptable`：常见但应判为错答或不给分的情形，须与 `misconceptionPatterns` 呼应；
- `notes`：仍需教师裁定的灰区。**灰区不得用 `notes` 代替边界**——若边界主要靠 `notes` 兜底，说明该小问还没设计完。

边界不可判定时，该小问不得随题包标为可使用（这条是语义条件，结构校验查不出，由评审判定）。

**设问红线**：综合题设问须要求判断、解释、评价或提出适用条件，不得退化为"写出材料中的措施"式照抄。删除该小问后大题仍完整成立时，说明该问没有独立的测量目标。

## 七、解析与答案说明质量

- 必须引用材料具体信息，写成"据材料'……'可知"这个句式；材料给出的数据、时间、地名、变量要落到具体字句。
- 禁止"其它选项错误""由常识可知""不符合题意"式空话。
- **选择题**：`analysis` 与 `answer` 完全一致；解析推导出的结论必须就是给定答案，不允许"解析推 A、答案给 B"；每个选项都有对应判定（正确项写依据的材料条件，错误项写错因类型与 `misconceptionId`），三处措辞不得互相矛盾。
- **综合题**：参考答案按评分档次分列，每档答案须逐条对上采分点；不得出现参考答案提到某个给分点而 `answerKey` 中无对应采分点的情况，反之亦然。

## 八、四翼

四翼（基础性、综合性、应用性、创新性）是"怎么考"的要求，**不是四个难度等级**。两类题型同一标准。

- 每题／每小问标 `fourWings.primary` 与 `secondary`，题组给主次，不强凑四项；
- 某一翼没有真实题面承载就不标——禁止为了"齐全"贴标签，禁止在 `evidence` 里写设计意图当证据；
- `fourWings.evidence` 给题面证据，写清本题面哪句话、哪个数据、哪个任务动作承载该要求（如"要求综合材料中的季节数据与地形信息"），不写"体现了综合性"；
- 不把四翼数量与难度挂钩，不把四翼相加当作难度分数。

## 九、难度

无真实试测数据时，只输出定性预计等级 + 判断依据，`design.expectedDifficulty.level` 用等级词（如"中等"），`rationale` 分四方面写：

1. `knowledgeBasis` 考查知识与教材依据：考什么考点、作为答案前提的知识如何在高中地理共同知识中找到依据；
2. `informationLoad` 信息加工负荷：需处理的文字 / 数据 / 图表信息、关键证据数量、图文整合要求；
3. `cognitiveLevel` 认知水平：识别与描述、理解与解释、分析与推断、迁移与应用中实际达到哪一层；
4. **第四个维度按题型写，二者不得互换**：
   - 选择题 → `distractorDiscrimination`：每个干扰项指向的认知障碍，以及排除它需要达到何种理解水平；
   - 综合题 → `scoringDiscrimination`：采分点能否把不同水平的学生区分开（A/B/C 三档在采分点命中上是否真的分开），答案边界是否在常见作答上可判定。**综合题不得把这一维度写成干扰项分析。**

禁止输出正确率、难度系数、区分度数值、选项分布。不把材料长度当难度（长而信息密度低的材料不等于难）。不把四翼相加当难度分数。真实试做数据到手后按 PRD §10 补充，并注明样本范围。

## 十、三水平学生模拟

A/B/C 各 1 名，写 `cognitiveDescription`、各小题／小问的 `responses`、`teacherInterpretation`、`intervention`。三档画像：

- A：准确提取信息，完成分析与迁移；
- B：掌握基本概念，但证据整合或推断不完整；
- C：存在核心概念误解，依赖表面词语或记忆结论。

共通要求：每条 `responses` 写 `correctUnderstanding`（正确理解的部分）、`errorStep`（出错环节）、`misconceptionId`；每条模拟必须带 `disclaimer: "预测性认知路径"`，并在表述中说清这是预测。禁止把它写成试测结果、正确率来源或"学生普遍如此"的结论。教师提供真实试做记录时，优先分析真实数据，不再用模拟代替。

**选择题**的 `responses`：写 `itemId`、`selected`（A/B/C/D）、`reasoning`。**选错时 `misconceptionId` 必须与该选项在 `distractorMap` 中的 `misconceptionId` 一致**，也必须落在教师已选障碍内；选对时可为 null。

**综合题**的 `responses`：写 `itemId`（大题 id）、`subQuestionId`、`writtenAnswer`（该水平的书面答案，要写得像学生真的会写出来的样子，不能写成标准答案）、`hitPointIds`（命中的采分点）、`missedPointIds`、`reasoning`。

- **不写预估得分数字**。命中的采分点 id 已足以按 `answerKey` 推导得分；写数字会被误读为试测数据。
- `hitPointIds` 与 `missedPointIds` 的并集必须是对该小问有意义的采分点全集：只命中一部分、或全部漏掉（`hitPointIds: []`）都可以，但不得出现既不在命中也不在漏掉、且未被说明的可给分点。
- `misconceptionId` 必须与该问 `misconceptionPatterns[]` 中的某一条或 `answerBoundary.unacceptable` 中的某情形呼应。
- 三档必须在采分点命中上真正分开：若 A/B/C 的 `hitPointIds` 完全相同，说明该小问的采分点无法区分水平，须回到第六节重设采分点或调整分档，而不是改模拟文字。
