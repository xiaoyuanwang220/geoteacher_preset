# 地理讲题稿（Explainer · 三对象）

把 **solver（独立解题轨迹）+ judge（核验偏差）** 的已验证结果，按**讲解对象**重组为可直接使用的讲解文档。本技能只负责"怎么讲得对、讲得像老师"，不重新解题。

## 铁律：讲题源自已验证解题过程

- 顺序即 **solve → judge → explain**，不得跳步：先有 solver 独立解题（未读答案）与 judge 核验（开放答案对照），再进入讲题。
- `geo_explain` 只消费已验证的解题轨迹与核验偏差；**不在讲题阶段重新做题、不直接拿标准解析原文推导讲法**。解析只作为"核验结论"被转述，不作讲稿主体。
- 讲稿必须教学化重组，禁止照抄解析原文。
- **取题纪律**：取题一律走 `geo_solve` / `geo_judge` / `geo_explain`，检索用 `geo_question_detail`；**严禁**用 `read`/`glob`/`pwsh` 直接读题库 md 文件（题库目录下所有 .md 均含答案/解析，直读等同读取答案）。
- 保留题面隔离与原生图片能力：不文本读图、不直读题库 Markdown、不恢复旧 OCR 链路。

## 对象路由（讲解对象）

`geo_explain` 的 `audience` 参数：`student`（默认，缺省即学生）｜`teacher`｜`setter`，中文显示"学生／教师／命题人"。

| 对象 | 触发 | 讲稿回答的核心问题 |
| :-- | :-- | :-- |
| 学生（默认） | "讲解这道题""这题怎么做""怎么讲给学生听" | 我下一步该做什么、为什么 |
| 教师 | "这道题如何讲授""怎么引导学生总结""课堂怎么组织" | 怎样让学生自己产生、检验、修正想法 |
| 命题人 | "从命题角度分析""这道题考得怎么样""干扰项怎么设计的" | 这道题实际考到了什么、设计是否奏效 |

- **仅因为当前用户是教师，不自动选教师对象**。"写一段可以直接对学生讲的话"属学生对象。
- 默认只生成一个对象；用户要求多版本才并列输出。
- 切换对象而题目未变时复用已核验分析，只重新组织讲稿；**改变题面或答案依据后必须重新核验**。
- 学生对象**允许自然推出答案**；"无答案练习支架"是另一个可选交付形式，不等于学生对象。

## 学生对象与教师对象：共用四段式

以「题目定位—审题—破题—反思与迁移」四个主要环节为骨架，把**知识点、解题过程、方法总结、跨学科**四个维度融入段内。**不另设替代四段式的顶层目录**，也不把维度清单逐项机械渲染成章节；子标题按题目与对象灵活设置。

| 环节 | 学生对象侧重 | 教师对象侧重 |
| :-- | :-- | :-- |
| ① 题目定位 | 要解决什么问题、核心知识与必要联系；压缩年份/分值/素养标签等与理解无关的元信息 | 教学价值、核心与支撑知识、重点难点及原因、应培养的思维 |
| ② 审题 | = ① 拆设问（先行）：对象＋行为动词＋限定词（含比较基准）→ 设问类型；第一步先拆设问、为什么 | 设计让学生自主界定问题的切入与追问；引导提出分析角度，而非教师宣布框架 |
| ③ 破题 | = ② 带着问题读材料 → ③ 知识选择 → ④ 推理链 → ⑤ 作答与检查：定向取证、证据—原理—结论、关键辨析；涉图读图顺序并入② | 沿同一解题逻辑组织思维启发：追问、学生思维动作、可能回答、分支引导、图示/反例、支架撤除 |
| ④ 反思与迁移 | 错因、可迁移思路与适用边界、简短变式或条件变化 | 怎样引导学生自己概括、比较、修正方法；设计独立迁移检测并说明观察什么表现 |

- 同一框架允许侧重点显著不同：不要求两版同字数、同子标题或逐段复制。定位可简短，**破题不能省掉关键逻辑**；反思不重复解析。
- 选择题在破题中保留选项辨析与排除依据；综合题保留结论组织、条件与术语表达。二者都以解决地理问题为主，**不让排除选项或凑采分点替代问题分析**。
- 跨学科在真正帮助理解的环节自然融入，**不强制新增第五个顶层章节**；是否生成本身也要先过四问判定（见"方法总结与跨学科"）。
- 变式优先使用真实候选；缺少候选时不虚构真题来源。

## 学生对象要点

保留引导式讲课口吻、无寒暄、思维显性化、答案由推理自然引出、以方法收束；重点让学生知道下一步可以做什么以及为什么。重要推理给出可检验的证据与解释，不机械重复同一句"为什么"。

学生对象在四段式**段内**按**设问先行六步**推进：① 拆设问（先行）→ ② 带着问题读材料 → ③ 知识选择 → ④ 推理链 → ⑤ 作答与检查 → ⑥ 方法提炼；落位：审题＝①，破题＝②③④⑤，反思与迁移＝⑥。方法主线是**先拆设问、再看材料**。六步是段内序列，不得写成顶层目录；完整六步表与两条约束见 `references/explainer-audiences.md` §4.1。

## 教师对象要点

正确解题逻辑必须清楚，但**主体篇幅用于如何让学生产生、检验和修正想法**，而不只是教师如何解释答案；关键节点组织模板与硬性要求见 `references/explainer-audiences.md` §5，不要求每一步都输出长表。

- 至少给出一条"学生自主提出解释 → 证据检验 → 独立迁移"的完整引导路径，并标明思维培养目的。
- 避免连续使用只需回答"是/否"的诱导问题；没有真实学情时只提出**待验证障碍**，"粗心"不得替代具体错误环节分析。
- 关注时空尺度、要素联系、过程与因果、证据比较、条件检验，按本题需要选择，不强凑思维标签。

## 命题人对象要点

结构：**考查目标 → 情境/材料/设问 → 设问、材料与选项的干扰辨析 → 预期认知路径 → 答案成立条件及错误路径 → 迁移与跨学科设计 → 题组和质量评价。**

- 选择题检查唯一性及干扰项机制；综合题检查合理答案范围、评分依据与开放性；分析已有题目不强迫其服从生成器约束；无原作者说明时标注"依据题面推断"，**无试测数据时不生成正确率、区分度数值或实际测量效果断言**。
- 必须**逐层**检查设问、材料（含图表）、选项中的干扰，不能缩减为错误选项解析；错误选项称**干扰项**，设问与材料中的相关内容称**干扰信息/干扰机制**；三层识别内容、每条干扰必给字段与负例约束见 `references/explainer-audiences.md` §6。
- 综合题无选项时将选项层标为**不适用**，可分析典型偏离思路，但不得虚构选项；某层未发现干扰时如实说明，不强凑三层。

## 方法总结与跨学科

- **方法总结**按问题结构提炼（比较区域差异、解释过程演变、判断因素变化的影响……），不按"原因题""措施题"套固定因素清单，并写明适用边界；可用维度词表排查，但取舍必须有问题和证据依据。
- **跨学科不是必填段：先判定，再决定是否生成。** 四问判定（任一不通过即不记跨学科）：必要性（删去该学科原理后结论是否仍成立）、参与环节（是否进入推理链而非只影响读图与表达）、学科归属（是否本属地理课程自身能力）、可交代性（是否为学生已学且题面有交代，否则至多 `pending`）。通过才记 `applicable`，并按「地理解释需要 → 学科工具 → 情境对应 → 解释贡献 → 适用限制」展开；未通过记 `not_applicable` 并说明卡在第几问。判定标准、校准例与有限类比约束见 `references/explainer-audiences.md` §八。
- 需要的新推理**交回分析与核验阶段**；跨学科补充不得成为未交代的作答必备知识；不把"材料没有明说"等同于"不能运用合理的课程知识推导"。

## 讲稿语言与文体

1. **无寒暄、讲课口吻**：开篇直接进入审题；用"我们/大家"引导，口语化但有讲解节奏，地理术语严谨；结尾以可迁移方法收束，不留客套话。
2. **思维显性化**：从"拿到题第一步想什么"起步，每推一步说明"为什么能推出下一步"（材料证据 × 原理 × 设问），不跳步。
3. **方法导向 + 答案克制**：破题与反思落到可迁移的思维模板、判断标尺或排除逻辑；答案由推理自然引出，不先亮答案再凑理由。

教师对象是教学引导稿、命题人对象是设计评价分析，**均不套用学生对象的讲课口吻**。

## 步骤0——前置门禁与取已验证解题过程

- **硬门禁**：未取得**本题**（同 qid）的 `geo_solve` 独立解题轨迹、且未完成 `geo_judge` 核验之前，**不得**进入讲题重组；缺失时先按序执行 solve → judge。
- 缺独立答案、核验报告损坏、qid 不一致或核验记录失效时，**如实返回"待核验/缺失"状态并说明缺什么**，不得静默吞错，也不得生成"已核验"讲稿。
1. `geo_solve` 取题面 + 审题骨架 + 原生图片，整理独立解题轨迹（上一环节已做则沿用）。
2. `geo_judge` 传入独立答案开放答案对照，得到采分点覆盖、推理错误、干扰项解释质量、遗漏分析。
3. `geo_explain` 传入独立答案、judge 返回内容与 audience，取讲稿重组骨架。
4. 任一步未完成先补齐，不得跳步直接讲。

## 步骤1–4（按四段式推进）

1. **题目定位**：学生对象简明交代要解决的问题、核心知识和必要联系；教师对象保留定位卡与讲授时间参考（题型 · 难度 · 年份省份题号 · 分值 · 是否涉图 · 主导核心素养与思维类型 · 建议讲解时长 · 建议年级）并说明教学价值与重点难点；命题人对象说明考查目标与本题在题组中的位置。
2. **审题**：以"拿到题先想什么"组织，拆设问为对象 + 行为动词 + 限定词 → 思维层级 + 设问类型（原因/影响/过程/比较/评价/措施/分布/趋势），各类型组织逻辑见 `references/explainer-audiences.md`，只作组织参考；学生对象讲清第一步想什么、为什么，教师对象设计让学生自主界定问题的切入与追问。
3. **破题**：每一步先讲"怎么想"，再用材料证据、原理和设问说明"为什么能推出下一步"（不跳步）。选择题：读图（涉图时独立：图例→坐标→数值→分布→趋势）→ 定向读材料 → 逐项排除链（材料证据 × 知识 × 设问；正确项证据、干扰项错因）→ 讲清"为什么不是另一个答案"；综合题：读图/定向读材料 → 设问分层 → 要素维度排查（材料支持的维度 → 采分点 → 每点表述 → 逻辑顺序）→ 术语规范 → 点到 judge 的采分点覆盖。教师对象把该逻辑转成思维启发；命题人对象按设问/材料/选项三层做干扰辨析。
4. **反思与迁移**：学生对象写错因（基于 judge 偏差）+ 可迁移思路与适用边界 + 1–2 道同考点真实变式（题库无则说明，不编造）；教师对象写怎样引导学生自己概括、比较、修正方法及独立迁移检测与观察点；命题人对象写迁移与跨学科设计评价、题组与质量评价。

## 交付

- 标注 **audience**，并清晰区分"解题轨迹"与"核验结论"。
- 学生对象：四段式讲稿（可直接用于讲解），可含答案；如需学生自练，另附**无答案练习支架**（提示性问题、空格、步骤占位，不预填结论）。
- 教师对象与命题人对象的交付规范见 `references/explainer-audiences.md` §5、§6。

## 质量自检清单（每份讲稿过）

- [ ] 顺序合规：解题→核验→讲题，未跳步、未在讲题阶段重新解题；取题只经 geo_solve / geo_judge / geo_explain，未直读题库 md 文件；
- [ ] audience 正确且已标注；缺前置产物时未冒充核验完成；
- [ ] 学生/教师对象为四段式（定位—审题—破题—反思与迁移），四维内容融入段内而非另设顶层目录；
- [ ] 学生版按设问先行六步推进（六步是段内序列、未成为顶层目录）；
- [ ] 去标题后仍能判断服务对象：学生对象有可执行的思考步骤；教师对象有本题专属的思维目标、学生思维动作、递进追问、支架撤除、总结引导与独立迁移检测；命题人对象评价设计是否奏效；
- [ ] 语言合规：无开场白/寒暄；学生对象保留讲课口吻；教师/命题人对象未套用学生口吻；
- [ ] 方法导向：落到可迁移通法且说明适用边界，未退化为固定因素清单；
- [ ] 选择题讲排除链+每个干扰项错因；综合题讲采分点组织+术语；未让排除选项或凑采分点替代问题分析；
- [ ] 四问论证覆盖（为什么用这个知识/为什么靠这条材料/为什么能推出下一步/为什么不是另一个答案）；
- [ ] 跨学科先过四问判定（必要性／参与环节／学科归属／可交代性），不通过则不生成；通过才按"需要→工具→对应→贡献→限制"检查并记状态；无强行关联、无未经核验的新结论；
- [ ] 命题人对象逐层（设问/材料/选项）检查干扰并给出位置、错误路径、辨别依据与质量判断；不适用/未发现如实标注；
- [ ] 易错基于 judge 偏差、变式来自真实候选；未把未经验证的学生错误路径写成实际学情；
- [ ] 无过程性元话语与作者痕迹（模型自述、版本痕迹、评审痕迹、解析机械复述）。

不达标 → 回到对应步骤补全后重新输出，不静默省略。
