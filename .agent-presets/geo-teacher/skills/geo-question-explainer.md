# 地理讲题稿（Explainer）

将 **solver（独立解题轨迹）+ judge（核验偏差）** 的已验证结果，重组为教师能直接讲给学生听的四段式讲题稿。本技能只负责"怎么讲得像老师"，不重新解题。

"教师"始终指当前用户。讲题稿是第一交付物；如教师需要，可附学生版支架。

## 铁律：讲题源自已验证解题过程，不重新解题

- 必须先有 solver 独立解题（未读答案）与 judge 核验（开放答案对照）的产物，再进入讲题阶段。顺序即 **solve → judge → explain**。
- `geo_explain` 只消费已验证的解题轨迹与核验偏差做教学化重组；**不在讲题阶段重新做题、不直接拿标准解析原文推导讲法**。解析原文只允许作为"核验结论"被转述，不作为讲稿主体。
- 讲题稿必须教学化重组：用学生能听懂的语言、设问类型化的组织逻辑、可迁移的思维模板，禁止照抄解析原文。
- **取题纪律**：取题一律走 `geo_solve` / `geo_judge` / `geo_explain`（题面与核验骨架），检索用 `geo_question_detail`；**严禁**用 `read`/`glob`/`pwsh` 直接读题库 md 文件（题库目录下所有 .md 均含答案/解析，直读等同读取答案）。

## 与教师保持沟通

用一至两句话说明将把已验证的解题与核验过程重组为四段式讲题稿，并标注哪些是"解题轨迹"、哪些是"核验结论"。面向教师只说讲稿本身，不说内部工具或骨架机制。

## 步骤0——前置门禁与取已验证解题过程

- **硬门禁**：未取得**本题**（同 qid）的 `geo_solve` 独立解题轨迹、且未完成 `geo_judge` 核验之前，**不得**进入讲题重组；缺失时先按序执行 solve → judge。
1. 用 `geo_solve` 取题面+审题骨架并把独立解题轨迹整理好（若上一环节已做，直接沿用）。
2. 用 `geo_judge`（传入你的独立答案）开放答案，得到核验结果：采分点覆盖（对/漏/部分）、推理错误、干扰项解释质量、遗漏分析。
3. 用 `geo_explain`（传入独立答案与 judge 返回内容）取讲题稿重组骨架（题目定位卡字段、四段式结构、要素维度扫描、同考点变式候选、核验摘要）。
4. 若上述任一步未完成，先补齐 solve/judge，不得跳步直接讲。

## 步骤1——题目定位卡（给教师快速决策）

用骨架生成一张定位卡：

- 题型（选择/综合）· 难度（基础/中档/压轴）· 年份省份题号 · 分值
- 是否涉图 · 主导素养与思维类型 · 建议讲解时长（选择题 2–4 分钟，综合题 5–8 分钟）· 建议年级

## 步骤2——审题（设问先行 + 设问类型框架）

- 拆设问：对象 + 行为动词 + 限定词 → 思维层级 + **设问类型**（原因/影响/过程/比较/评价/措施/分布/趋势，联动组织逻辑，见下表）。
- 明确"要答什么方向"，点明设问类型对应的组织提示（骨架 `structure.examine.hint`）。

| 设问类型 | 该组织什么逻辑（而非机械模板） |
| :--- | :--- |
| 原因 | 直接原因→根本条件→触发→加剧；材料没提不硬凑 |
| 影响/意义 | 分主体（自然/人文、受益/受损）+ 分层次（直接—间接、短期—长期） |
| 过程 | 按阶段与时间顺序：环节链 + 每阶段驱动因素 |
| 比较 | 可比指标 + 同口径 + 区域限定 |
| 评价/利弊 | 分主体利弊 + 代价与可行性 + 适用条件 |
| 措施/对策 | 针对性（对应原因/问题）+ 分主体 + 可行性 |
| 分布/特征 | 方位/范围/形状/集中分散 + 数据支撑 |
| 变化/趋势 | 动态表述（方向+幅度+速率） |

## 步骤3——破题（分题型）

- **选择题**：读图（涉图时独立：图例→坐标→数值→分布→趋势）→ 定向读材料 → 逐项排除链（每项：材料证据 × 知识 × 设问；正确项证据、干扰项错因）→ 讲清"为什么不是另一个答案"（solver 独立排除论证 + judge 的干扰项解释质量核验）。
- **综合题**：读图/定向读材料 → 设问分层 → **要素维度排查**（用骨架的 dimensionScan，材料支持的维度→采分点→每点表述→逻辑顺序）→ 术语规范 → 点到 judge 的采分点覆盖：独立答案对在哪、漏在哪、部分在哪。

## 步骤4——反思与迁移

- **易错警示**：基于独立解题 vs 答案核验的偏差（judge 产出）+ 常见错误（答非所问/漏维度/术语不规范）。
- **方法提炼**：一类题的思维模板（可迁移），升维成"这类题怎么做"。
- **变式链接**：从骨架 `variants` 候选里挑 1–2 道同考点/同设问真题；若题库暂无，说明"当前题库该考点情境较少"，不编造。

## 学生版支架（基础版）

讲题稿外，若教师要学生练习用，给一个**不给答案**的支架：

- 提示性问题（引导学生自己想）、空格/引导性设问、步骤占位；
- 保持认知负荷：不预填结论，只给"下一步该往哪个方向想"；
- 教师可在讲完后再收起支架做课堂检测。

## 交付

- 面向教师：完整讲题稿（定位卡→审题→破题→反思迁移），清晰标注"解题轨迹" vs "核验结论" 的区分。
- 面向师范生（备赛/教研）：额外说明你的设问类型化组织依据与采分点排查逻辑。
- 学生版支架按需附后。讲完后主动询问：是否换同考点的变式再讲一道、是否导出讲题稿 markdown、是否需要调难度/讲法。

## 质量自检清单（每份讲稿过）

- [ ] 顺序合规：解题→核验→讲题，未跳步、未在讲题阶段重新解题；
- [ ] 取题只经 geo_solve / geo_judge / geo_explain，未直读题库 md 文件；
- [ ] 讲稿为四段式（定位—审题—破题—反思迁移）；
- [ ] 选择题讲排除链+每个干扰项错因；综合题讲采分点组织+术语；
- [ ] 四问论证覆盖（为什么用这个知识/为什么靠这条材料/为什么能推出下一步/为什么不是另一个答案）；
- [ ] 设问类型化组织、以材料为据，无机械套模板；
- [ ] 易错基于 judge 偏差、变式来自骨架候选（无则标注）；
- [ ] 学生版支架（如需）不预填结论、不给答案。

不达标 → 回到对应步骤补全后重新输出，不静默省略。

## 术语引用

本技能中的地理术语（考点、干扰项、采分点、设问类型、核心素养、四问论证、讲题稿、解题轨迹、核验报告等）以 `docs/术语表.md` 为唯一权威。讲题稿中的术语必须与术语表一致。

## 过程性元话语与作者痕迹检测

讲题稿必须**教学化重组**，禁止出现以下内容（一旦出现判定不合格）：

| 需删除 | 示例 |
| :-- | :-- |
| 模型自述 | "我这样想""我推测""我认为应该选 B" |
| 版本痕迹 | "v2.0 修订""之前改为""现在改为" |
| 评审痕迹 | "reviewer 指出""评审建议" |
| 对解析的机械复述 | 照抄真题解析原文 |

**必须保留**（可教学推理，是讲题稿核心价值）：
- 审题（设问拆解：对象+动词+限定词）
- 证据（材料引用：据材料"……"可知）
- 原理（知识选择依据：为什么用这个知识）
- 因果链（推理步骤：每步标注"为什么能推出下一步"）
- 干扰项排除（为什么不是另一个答案：错因类型 + 材料证据）

## proposition-preservation 边界

命题完整性自检（五段式完整、答案-解析一致、干扰项错因明确等）用于确认编辑过程中**未遗漏关键命题**。它**不能证明**：
- 答案是否正确；
- 答案与解析是否一致；
- 地理事实是否准确。

以上三项需领域 Rubric（学科标准）人工验证。
