# 中国普通高中地理课程设计 Skill（V3.2）

为高中地理教师生成课标对齐的课堂材料：教学设计、学生学习材料、课堂观察记录表，以及课程确实需要的地图或数据材料。HTML 与 DOCX 都是最终产物，教师按使用场景选择（HTML 适合屏幕阅读、投屏与浏览器打印；DOCX 适合二次编辑与学校模板）。

## 定位

本 Skill 默认按**学生自主建构**组织（探究取向）。探究式组织是默认形式，不是所有课的必需形式：讲授、讲练、复习等课，只要目标、活动与评价对应，符合学情与课时、资源条件，可以按任务需要采用。

本 Skill 提供科学解释的依据与边界，具体教学实现由模型自主决定：

| 由模型自主完成（本 Skill 不作规定） | 由本 Skill 提供（模型原生不具备） |
|---|---|
| 情境选择、问题链编排、任务设计、教学判断 | 依据核验、教材思想解读、真实素材核实、材料源格式与渲染、交付前自查 |

课标与教材原文使用教师知识库资料，教师明确提供的本地原文也可使用；真实素材（数据、案例）经联网搜索核实来源、年份与口径。教材思想解读不能替代原文。真实数据不可得时，按 `references/source-and-map-policy.md` 判断是否可用明确标注的教学模拟数据；模拟数据不能替代课标或教材原文。

流程要点：阶段 1 把课标原文、教材边界与素材来源落盘为 `依据-<课标编号>.md`，后续引用只对照该文件；阶段 3 出 ≤5 行构思卡后停下等教师确认；阶段 5 按教师选择的格式渲染。详见 `SKILL.md`。

## 安装

按 DSH 预设的安装方式导入本目录（见仓库 `scripts/setup.mjs`），保持 `references/`、`scripts/` 与 `SKILL.md` 的相对位置不变。

## 文件构成

生成路径与纪律见 `SKILL.md`。`references/` 按阶段读取：

| 文件 | 内容 | 读取时机 |
|---|---|---|
| `source-and-map-policy.md` | 来源优先级、联网核验、数据与案例规则、中国地图合规 | 阶段 2 涉及现实材料、地图或高考真题时 |
| `subject-notes.md` | 课标定位与解读、地理学科判断、认知深度判据、借角度看问题、灵感索引 | 阶段 1、3 按需 |
| `disciplinary-foundations.md` | 各思想的简明含义、适用条件与备课判断 | 匹配教材后，只读本课涉及小节 |
| `textbooks/index.md` | 教材身份匹配、回退与读取规则 | 阶段1教材明确时 |
| `disciplinary-examples.md` | 选必2的三则备课取舍及其理由 | 阶段 3 需要参照时选读 |
| `textbooks/rj-xb2-regional-development/` | 选必2概述、四章教材分析与证据定位 | 命中人教版《区域发展》后按课题取用 |
| `lesson-format.md` | `lesson.json` 结构、三件套写作要求、展开边界 | 阶段 4 写材料源时 |
| `delivery-checklist.md` | 渲染前的交付自查清单 | 阶段 5 |
| `example_lesson.json` | 渲染契约样例（内容为占位），只用于比对结构，不作教学内容参考 | 验证渲染链、核对块字段时 |

`scripts/` 提供材料源渲染：`render_documents.py` 及其依赖。

## 交付后的改进回路（可选）

教师对已交付课程不满意并提出具体调整要求时，由模型按教师原话逐条改问题链与任务链，给出不超过两个改造候选，由教师选定后回到阶段 3 重新确认。**触发权在教师**，主流程不自行发起，也不得用它替代阶段 5 自查。本版本不依赖外部审查专家（V3.1 审查组件已于 2026-09-12 退役，能力已折入 `references/delivery-checklist.md`）。

## 文档渲染

HTML 渲染只需要 Python 3。生成 DOCX 还需要：

```text
python-docx>=1.1.2
Pillow>=9.0        # 图表绘制；也用于把 WebP 等 Word 不认的位图格式转成 PNG
```

**图片格式**：HTML 能直接显示 PNG/JPEG/GIF/WebP/SVG；**DOCX 只支持位图**（PNG/JPEG/GIF/BMP/TIFF）。WebP 会在嵌入前自动转成 PNG，两种产物显示同一张图。**SVG 不支持输出到 DOCX**：需要向量图时请交付 `--format html`，或在材料源中改用 PNG。图片无法嵌入时渲染会**报错退出**，不会丢掉图片后仍返回成功——否则 HTML 有图、DOCX 无图，两种产物就不再是同一份内容。

（实测环境：Python 3.9 / 3.12 + python-docx 1.2.0。DOCX 输出为 A4 页面，中文行文用宋体、标题用黑体，西文用 Arial。）

示例命令：

```powershell
python scripts\render_documents.py lesson.json --format both --outdir output
```

如果 `python` 不是 DSH 运行环境中的命令，请使用该环境配置的 Python 3 解释器。DOCX 依赖不可用时可先输出 HTML；不得改回作者电脑的绝对解释器路径。
