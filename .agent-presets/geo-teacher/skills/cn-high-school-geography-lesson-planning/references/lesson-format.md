# 材料源结构与三件套写作要求

阶段 5 展开时读取。本文件只负责把**教师已确认的构思**写成可渲染的材料源与三件套；不重新选择情境、任务链、证据顺序、主要活动、关键成果或检测目标。

## 一、材料源 `lesson.json`

```json
{
  "shared":      { "任意键": "块、块数组，或 {student, teacher} 双版本" },
  "theme":       { "可选，全部文档的默认主题；文档内 theme 覆盖它" },
  "documents": [
    { "id": "教学设计", "eyebrow": "教师用", "title": "…教学设计",
      "audience": "teacher", "sections": [ { "heading": "…", "blocks": [ … ] } ] }
  ]
}
```

- **`id` 即输出文件名**（`教学设计.html/.docx`）。路径分隔符与标点会被替换为 `_`，中文保留。
- **重复内容只写一次**：`shared` 里的键用 `{"type": "from_shared", "key": "…"}` 引用，防止三份文档分叉。学生与教师措辞不同时，`shared` 中只写 `{"student": {…}, "teacher": {…}}`——**不要加 `"type": "faceted"`**，否则会被当作普通块字符串化、内容丢失。该双版本按文档的 `audience` 展开：**学生版只出 `student` 面**（教师话术绝不进入学生材料；`student` 面缺失则什么都不渲染），**教师版出 `teacher` 面并把 `student` 面作为一行「学生活动」附在后面**——所以教师版里出现学生措辞是预期行为，不是泄漏。
- 教学设计中出现的任务，与学生材料中的同一任务必须来自同一共享键，不得各写一份。

### 常用块类型

| type | 关键字段 | 用途 |
|---|---|---|
| `paragraph` | `text` | 正文段落 |
| `labeled` | `label`、`text` | 标签＋正文（如"设计理由：…"） |
| `h2` / `h3` | `text` | 小节标题 |
| `callout` | `label`、`text`、`kind` | 强调框；`kind` 如 `student-task` |
| `instructions` | `text` | 任务指令行 |
| `list` / `checklist` | `items[]`、`ordered`、`label` | 列表／勾选项 |
| `table` | `headers[]`、`rows[][]`、`display:"large"` | 数据表、对比表 |
| `fill_table` | `headers[]`、`rows` | 待填表格；**必须至少一行可填写空白单元格**，不能只有表头 |
| `workspace` | `height_pt`、`ruled` | 作答区；横线留白 |
| `labeled_box` | `label`＋作答区 | 带标签的作答框 |
| `source_card` | `title`、`author`、`date`、`origin`、`text`/`excerpt`、`url` | 材料卡；来源与链接由它承载 |
| `phase_header` | `name`、`minutes` | 教学环节标题＋时长 |
| `columns` / `group` | `left[]`/`right[]`、`blocks[]` | 分栏、成组防断页 |
| `from_shared` | `key` | 引用共享内容 |
| `page_break`、`cards`、`fill_in`、`number_line` | 见字面含义 | 版式需要时才用 |

最小结构示例见 `references/example_lesson.json`——它以占位内容覆盖上表全部常用块，可直接渲染，用于验证渲染链可用；**它是渲染契约样例，不是内容范本**。块字段写错会渲染成空块，自查时须看渲染结果。

## 二、教学设计

### 表达纪律

- **保留并转写**：具体学习困难、材料作用、学生行动、学习成果、评价依据、教师反馈。
- **写成课堂操作**：教师投放材料、提出问题、提供支架、根据学生作品反馈、调整时间——用可执行动词。
- **不得进入成品**：内部检查项、方案版本、发现编号、严重度、取舍与残余风险、对设计过程的自我辩护。没有"设计理由与保留取舍"这类总结章节。
- 分析维度只用于内部检查，不机械转成标题或表格行；课标、教材、学情、重难点按"依据或现状—解释—教学决策"写成连贯判断。
- 每段都应说明教师怎样教、学生怎样学或教师怎样判断学习。一句话若只在解释方案为何成立，删掉。
- 文档保持简短可扫描；同一指令只写一次。

### 常用功能关系

```text
分析段落：依据或现状 → 对本课的判断 → 相应教学决策
目标表达：所用材料或条件 → 学生行为 → 成果或表现 → 必要的质量要求
教学过程：材料或情境 → 关键问题 → 学生行动 → 学习成果 → 反馈与后续
设计理由：具体学习困难 → 当前活动的作用 → 可观察的学习证据
```

### 板块要求

- **课程基本信息**：课程名称、学时、年级或模块、教材目次；版本无法确认时标"未指定"，不猜测。
- **课标分析**：取最匹配的内容要求原文，按原文实有的要素拆——**A 行为主体、B 行为动词、C 行为内容、D 行为水平**；原文省略的要素不解读、不补写。再说明这些要素如何约束目标、任务与评价，选承担核心认知工作的 1—2 项素养。段末用一句话收束：「本节课的〔情境〕，使学生〔学习内容〕，〔育人价值〕。」
  - **呈现**：每个要素单独成段，不用表格、不套小标题层级；不机械按 A—D 铺满，原文没有的要素整段略去。篇幅以上课教师能快速判断目标与任务为准，通常不超过 300 字。写完逐句问：删掉这句，教师对目标或任务的判断会不会变？不变就删。
- **教材分析**：内容位置、知识逻辑、前后联系、本课边界，再交代保留／重组／补充／替换什么及理由。教材小标题可帮助划界与核对，**不直接规定教学阶段顺序**。**不得为复用教材自带导入、案例或活动写辩护**（如"该材料属公共文献、非教材原创"）；教师明确要求保留时，写明这是教师的要求。**教材的示意图、模式图、统计图可以作为本课用图**（投屏、学生读图、任务材料均可），写明图号即可——要交代的是取舍依据，不是为"用了教材的图"作辩护。
- **学情分析**：连接"已有基础—目标差距—具体困难—教学响应"，标明依据来自前测、作业、观察还是教师经验预判。
- **教学目标与评价**：用可观察行为，写明证据或条件、成果与质量要求；每项配置对应评价证据与判断标准，不机械覆盖四项素养。
- **重点与难点**：默认各写成一个带标签的完整段落（重点：关键内容＋依据＋落实任务＋达成表现；难点：认知障碍＋成因＋突破支架＋验证表现），不拆成维度表。
- **方法与资源**：一个主要方法＋必要辅助方法，说明它如何影响任务与评价。课程依赖的地图、照片、数据表、任务卡、图表、媒体**必须随包提供或给出已核验的准确获取路径**，不保留"此处插图""播放相关视频"等占位指令。教材中的示意图、模式图、统计图直接写「教材＋图号＋页码」即为已核验路径，不必另做副本，也不要为了"避开教材"而改用自制低质替代图。可行时给出不改变目标与关键认知动作的低技术执行方式。材料清单与教学阶段双向对应，不增加课堂不用的附件。
- **教学过程**：按教学核心与任务链组织阶段，不套固定课序，**不用表格排教学过程**。每阶段以"环节名称＋时间"为标题，用完整语句写明材料或情境、任务或问题、教师活动、学生活动、学习成果、评价与反馈、设计理由。环节名称尽量表达学生正在进行的认知活动，不只写"新授一、活动二"。
- 45 分钟课通常保留 **3—5 个主问题**；实验、制图、建模或作品修订耗时较多时减少。不强制设置统摄全课的"核心问题"栏目，也不在没有认知依赖时强行组织成问题链。
- 教师版对每个主问题写清：对应目标与任务、预期回答边界、答不出时的阶梯提示、答偏时的纠偏或证据回扣、可观察回答及其后续用途。确定性概念给出必要结论与条件；评价与决策问题给出证据要求与可接受范围，不强设唯一答案。
- 每个主问题应有可观察回答或成果，但只选其中 **2—3 个关键节点**作为主要评价证据，避免逐问打分。"抢答""小组讨论""学生思考"只说明组织方式，必须进一步写出学生实际作出的判断、引用的证据、形成的图表或完成的解释。
- 教学意图按需用一个短段落说明（如"让实验结论成为解释过程图的证据"），不为每阶段机械补写，不写"激发兴趣、活跃课堂"。
- **板书设计**：默认只给 2—4 条建议，围绕核心知识关系、关键学生成果与呈现顺序；不强制生成完整板书图。
- **课堂观察**：围绕本课目标与主要学习阶段设至少 3 项观察点，写可观察行为、学习证据、教师下一步动作；使用"引用图表数据解释降水差异"这类可由作品或作答支持的行为，不写"认真听讲、积极参与"。观察表与目标、主要任务、课堂检测使用**同一判断口径**。

## 三、学生学习材料

学生材料是学生在课堂中实际阅读、操作、记录和作答的工具，不是教学设计的缩写。

- 使用学生能直接执行的动作，不写"教师引导""培养素养""突破难点"；术语首次出现给解释或图示，后续名称一致。
- 情境导语只保留完成任务需要的信息；长材料分段、编号或加小标题。
- 任务指令包含：**材料或对象＋行为动词＋观察/分析维度＋成果形式**。不用"思考一下""讨论一下""谈谈认识"代替可执行任务。

下表为**示例，不是行为动词的全集**；表外动词（如归纳、绘制、判读、论证、提出）按其实际认知要求处理。

| 行为动词（示例） | 学生实际要做的事 | 常见成果 |
|---|---|---|
| 描述 | 提取位置、方向、数值、形态或变化 | 描述语句、标注图 |
| 比较 | 用相同指标找共同点与差异 | 比较表、结论句 |
| 解释 | 建立证据、要素与过程之间的关系 | 因果链、解释段、过程图 |
| 评价 | 按条件比较收益、成本、风险或影响 | 判断＋证据化理由 |
| 设计 | 在约束条件下形成可执行方案 | 方案表、路线图、模型 |

- 给地图、图表、文字、实验或案例材料**连续编号**，问题指明用哪一份；一份材料有多个信息时说明各自提供什么。材料中已有的结论不再要求学生原样抄写。
- 递进可按"观察或读取 → 归纳特征 → 解释原因 → 检验或修正 → 应用或决策"选配；后一任务明确或自然地使用前一成果。任务相对独立时，只要共同服务一个内容关系或方法即可，不必强行串成问题链。
- 表格用于统一口径、支持比较或组织复杂信息：比较表用同一组指标；实验表覆盖变量／条件、观察结果、必要数据、结论位置；调查表写明观察对象、记录单位、判断标准；过程图留出学生需补画的关键关系并说明箭头与图例要求。学生已在表格或图中作答时不再增设重复答案框。
- 实验或实践任务写清：要解决的问题、材料与工具、条件／变量／观察维度、操作步骤与安全提示、数据记录位置、由结果形成的解释或改进任务。并行小组用不同条件时保持测量协议与记录框架一致，以便汇总比较。
- 支架帮助学生定位信息、组织证据或表达关系，**不替学生完成结论**：关键词提示用于开放探究的维度提示；句式支架放在最需要完整表达的任务旁并留出填证据与关系的空间；半句提示避免把教材整段改成连续填空；示例只说明成果形式，不提供当前任务的答案。
- **练习与课堂检测**分两层，每题对应一个明确目标：
  - **基础题**原创，直接检查本课核心概念、环节、关系、方法或必要表征；**不为基础题虚构"某地"案例**，使用现实材料时仍执行来源与联网规则。
  - **挑战题**选与目标和教材边界匹配的高考地理真题：**完整保留原题**的材料、图表、图号、数据、选项与设问，不改写地点、条件、结论或认知要求，不把含图题转成文字题。必须联网打开完整原题核对，标明年份、地区或卷别、题号与直接来源链接；图表或选项无法完整取得时换题，不补写、不删图改编。
  - 新情境检测继续使用课堂形成的方法，不复述课堂案例。课堂检测控制阅读量与作答时间；课后任务写明成果与完成标准。
- **作答空间与版面**：一个词或数字留小空间，解释、绘图、比较、方案留相称空间；任务、材料与作答处相邻，避免跨页寻找；学生作答所需的材料、图表与来源说明先于对应任务出现，材料编号连续，课内任务与作业不得引用材料包中不存在的图版或原卷；同一任务的编号、措辞、数据与图号在教学设计中保持一致；页面按课堂使用顺序组织，学生不需了解教学设计结构即可独立操作。

## 四、展开边界

细化已确认活动时只允许补充执行细节，不得改变教学骨架：

- 材料可裁剪、编号、调整呈现顺序、补必要说明——**不改变**主要活动锚点、关键材料及其证据功能、情境选择；
- 指令、局部追问、阶梯提示、步骤衔接可补足——**不改变**核心任务链、主要证据顺序、活动顺序；
- 成果载体、反馈方式、非承重支架可补——**不改变**关键中间成果、成果用途、目标达成证据；
- 地图、数据、实验的可执行操作可补写——**不改变**证据类型、关键变量、学生应完成的核心推理；
- 检测的新材料、指令与作答形式可补——**不改变**检测目标、认知要求、评价证据。

若修改会改变教学核心、认知路径、活动顺序、主要时间分配、关键材料与证据、学生动作、成果用途，**停止细化，回到阶段 4 重新取得教师确认**；形式上仍属同一活动，不代表骨架未变。学生材料不得泄露教师答案、追问脚本或纠偏路径。
