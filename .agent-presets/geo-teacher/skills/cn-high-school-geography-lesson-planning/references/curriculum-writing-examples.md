# 课标解读的局部成文参照

以下片段展示四要素中单个解读项或总结段内部的成文，不是课标原文或完整范文。完整解读仍须按 ABCD 逐项呈现。这些片段只供理解如何展开解释、如何写材料的适切理由、如何避免假递进，以及总结怎样做整体判断；不替代其他要素，也不作为固定句式。片段中的条文用字用于演示，正式成文以教师确认的现行原文为准。

## 地域文化：材料类型与适切理由

分析要点：行为内容是地域文化“体现在”城乡景观中；条件“结合实例”要让人看见这种体现。教师未指定地方时，写类型和理由，不点名。

> 行为内容是“地域文化在城乡景观中的体现”，条件是“结合实例”。地域文化要落到城乡里看得见的景观上，如建筑、聚落布局或土地利用，才谈得上“体现”。适合的材料是一处同时呈现景观形态和其由来的实例：学生能指出某种景观对应着当地怎样的生产、制度或习俗。教师应让学生理解，教学的关键是把景观和它所体现的文化对上。教师尚未指定地方时，写明这一类实例及其适切理由即可。

这是 C 项里条件与材料的写法：用途是说明“体现”，适切理由是内容特点（文化要在景观中可见）与材料作用（实例同时给出形态和由来）对得上。不靠点出某一处地方来显得具体。B、D 仍分别解读动作与认知要求，并各写自己的教学意义。

## 产业结构：展开限定词，并说明资料为何适合

分析要点：“过程”需要不同时期的信息；“原因”需要该地区的驱动条件。这是条文自己的先后，不是另加的台阶。

> 行为内容是“地区产业结构变化过程及原因”，条件是“以某地区为例”。“过程”要看见产业构成怎样随时间改变，“原因”要联系促使它改变的区域条件。不同时期的产业比重资料对得上“过程”，对照才能看出构成变了；与当地有关的技术、市场、政策等资料对得上“原因”。教师应让学生理解：先看清这个地区的构成如何变化，再从它自己的条件里找原因。地区尚未指定时，保持“某地区”和上述资料类型即可。

这是 C 项的局部成文。没有时间变化要求的条目，不必照此展开。

## 交通与区域发展：把关系具体展开

分析要点：运输方式与交通布局是两个相关对象；二者与区域发展的关系是相互作用。按条文的实际关系写，不排成多层动词台阶。

> 行为内容是“运输方式和交通布局与区域发展的关系”。运输方式关系到人员和货物怎样流动，交通布局影响这些流动连接哪些地方。与区域发展的关系是相互的：交通改善能够带来发展机会，区域人口和产业的变化也会产生新的运输需求。学生熟悉的“修路带动发展”可以作为起点。教师应把另一侧——区域变化怎样反过来要求交通——一并放进实例，让学生理解这种相互促成。实例要能同时看见交通的变化和区域发展的变化。

这是 C 项中对行为内容的展开。完整 C 项还需解释条件“结合实例”的适切理由，写法见上文地域文化一节；其他条目是否存在双向关系，应由其内容决定。

## 地质年代表：展开「演化」

分析要点：“演化”是时间中的相继变化，不是年代名称的罗列。地质年代表适合，因为它按时间排出阶段，并对照各阶段的主要面貌。

> 行为内容是“地球的演化过程”，条件是“运用地质年代表等资料”。演化是地球的海陆、大气与生命在时间中怎样相继改变，后一阶段承接前一阶段。地质年代表把宙、代、纪按时间排开，并给出各阶段的主要面貌，所以能支撑对“过程”的描述。教师应让学生理解：描述演化，是说出主要阶段的面貌如何不同、如何接续。教师已经指定某份年代表或某一组阶段时，再绑定那一份资料。

这是 C 项对“演化”的展开，并写明资料类型与适切理由。

> 行为水平由“简要描述”决定。学生要按时间顺序说出主要阶段的面貌差异和接续。“简要”是抓住主要特征，个别事件和生物细节可以取舍。教师应把教学放在阶段之间的差异与接续上：学生能够用自己的语言连贯说出地球面貌和生命发展的主要变化，就达到了这一水平。

这是 D 项：承接对“描述”和“演化”的解释，说明做到什么程度，避免只贴层级标签。材料的适切理由留在 C 项，这一段不重复。

## 假递进：联系必须有条文依据

分析要点：动词或内容里没有的台阶，不要排成层层递进。生命周期、推拉理论解释不了本条时，不进入成文。

不宜写成：学生先观察景观，再识别地域文化，进而描述特点、解释成因，最后评价保护，层层递进，并用推拉理论和生命周期加以分析。本条只要求结合实例说明地域文化怎样体现在城乡景观中；那五步和这两个概念都不是本条的要求。

> 实例中的景观与它所体现的地域文化是对应关系。学生要能指出哪一处景观对应着怎样的生产、制度或习俗。教师应把教学放在这种对应上，按这条的实际关系来写。

条文里确有先后时仍要写清。例如“变化过程及原因”是先看见变化、再找原因，这是条文自己的关系。人口迁移的影响因素若确由迁出地的推力与迁入地的拉力构成，推拉理论可以用来解释这一条；地域文化、地球演化等条目用它解释不了，就不写。假递进指强加条文没有的层次，或塞入解释不了本条的工具概念。

## 教学总结：教师的整体判断

> 大气的组成、垂直分层，以及它们与生产生活的联系，在这条里是一件事。教师应让学生借助图表分清各成分、各层的主要特点，并看这些特点怎样成为生产生活的条件：对流层的天气变化直接影响农业和交通，平流层的稳定关系到高空飞行。学生要理解的是，大气的结构怎样成为人类活动的条件。这种对应说得具体，人地协调观就有了可观察的表现。

这段接在完整四要素解读之后，是教师对整条的整体判断：内容怎样连成一件教学上的事，学生要理解到哪里。人地协调观因条文已要求“与生产和生活的联系”，前文又写出了具体对应，才自然出现。总结不逐项重述，也不用一串“不是……”“脱离资料不计入”“须能检测”代替判断。其他条目按自身内容总结，不照搬句式，也不强加相同的核心素养。
