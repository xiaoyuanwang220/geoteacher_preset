# 课标解读的局部成文参照

以下片段展示四要素中单个解读项内部的成文，不是课标原文或完整范文。完整解读仍须按 ABCD 逐项呈现；这些片段只供理解如何展开解释，不替代其他要素，也不作为固定句式。

## 产业结构：展开限定词的教学含义

分析要点：“过程”需要不同时期的信息；“原因”需要联系驱动因素。

> 行为内容是“地区产业结构变化过程及原因”，条件是“以某地区为例”。“过程”关注不同时期产业构成的变化，单一时点的资料难以呈现它怎样演变。教学中需要结合该地区不同时期的产业构成资料，引导学生比较各产业比重的变化，再联系技术、市场、政策等信息，帮助学生理解当地产业结构为什么发生变化，学会从区域条件中寻找原因。

这是 C 项的局部成文：展开对象与条件之间的联系，使材料要求有理由。B、D 仍分别解读动作与认知要求；没有时间变化要求的条目，不必照此展开。

## 交通与区域发展：把关系具体展开

分析要点：运输方式与交通布局是两个相关对象；二者与区域发展存在相互作用。

> 行为内容是“运输方式和交通布局与区域发展的关系”。运输方式关系到人员和货物怎样流动，交通布局则影响这些流动连接哪些地方。这部分教学的重点在于两者与区域发展的联系：交通改善能够带来发展机会，区域人口和产业的变化也会产生新的运输需求。学生熟悉的“修路带动发展”可以成为理解的起点，对交通布局的认识还需要进一步联系区域发展的需求。

这是 C 项中对行为内容的展开，用具体联系解释“相互作用”。完整 C 项还需解释条件；其他条目是否存在双向关系，应由其内容决定。

## 地质年代表：说明行为水平的具体表现

分析要点：“演化”关注时间中的变化；“简要描述”要求选择主要特征。

> 行为水平体现为能够按时间顺序简明描述地球演化的主要阶段。“简要”要求把握主要特征，因此这部分教学宜把精力放在各阶段面貌的差异与接续上，个别事件的细节可以有所取舍。学生能够用自己的语言连贯说出地球面貌和生命发展的主要变化，就体现了对演化过程的整体认识。

这是 D 项的成文：承接 B 中对“描述”的解释，进一步说明达成程度与表现，避免只贴层级标签。材料作用仍在 C 项解读，不以这一段替代其他要素。

## 教学总结：将各项解读落到整体教学考虑

> 因此，大气组成与垂直分层的教学，应把基础知识同生产生活联系起来。不同成分的作用、不同大气层的特点，都是认识这些联系的基础；教学中把两部分贯通，学生对大气的认识才会从成分和层次的名称，进一步发展为对其生活意义的理解。

这段选择内容之间的联系作为总结重点，体现教师对整体教学的判断，并未另列材料与活动。它接在完整四要素解读之后，不替代任何解读项；其他条目按自身内容总结，不照搬句式或强加相同教学途径。
