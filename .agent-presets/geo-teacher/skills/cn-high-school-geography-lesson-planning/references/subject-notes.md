# 学科参考：课标定位、地理判断与灵感索引

按需读取，不是每课必经。本文件只提供判断框架，不收录课标原文，也不是必须逐项套用的教案模板。

## 一、课标定位与解读

### 权威依据

以教师知识库中提供并确认适用于当前任务的教育部课程标准文件为依据；引用时核对文件名称、版本、发布机构与适用范围。

不要用旧版、摘要、教辅转述或模型记忆替代教师指定的现行课程标准。知识库中存在多个版本时，依据教师说明选择；教师未说明且版本差异会影响设计时，先请教师确认。

### 课程结构

- 必修：地理 1、地理 2。
- 选择性必修：自然地理基础、区域发展、资源环境与国家安全。
- 选修：由学校根据课程方案、师资和学生发展需要开设。

不同地区、学校和教材版本的年级安排、章节顺序与案例不同。**不要把"高一"等同于固定模块，也不要把出版社目录当作全国统一教学顺序。** 按教师提供的信息定位到：年级与学期 → 模块 → 内容主题或课标内容要求 → 本课承担的行为要求 → 对应学业质量表现。不得根据教材章节号反推唯一课标条目。

| 模块 | 优先识别的内容类型 | 常见主课型 |
|---|---|---|
| 地理 1 | 地球环境、自然地理过程、自然灾害与地理实践基础 | 自然地理过程与机制；地理实践 |
| 地理 2 | 人口、乡村与城镇、产业区位、交通、人地协调发展 | 人文地理过程与区位 |
| 自然地理基础 | 自然地理过程、自然环境整体性和地域分异 | 自然地理过程与机制 |
| 区域发展 | 区域特征、区域联系、区域发展问题与治理 | 区域认知与区域发展 |
| 资源环境与国家安全 | 资源、环境、生态、国土和国家安全问题 | 资源、环境与国家安全 |

本表只用于初步路由，最终以教师提供的模块信息与经核验的课标条目为准。

### 核心素养

人地协调观、综合思维、区域认知、地理实践力。四项相互联系，一节课不必平均覆盖：选承担核心认知工作的 1—2 项，写出可观察表现。

### 定位步骤

- **有明确课标条目**：核对版本、模块、条目与原文，逐字保存原文，在教学设计中只完整呈现一次。
- **只有课题或教材章节**：**先请教师指定其知识库中本课对应的课标文件与模块**，版本由教师确认。教师未提供时，可将课题中的对象、过程、区域、问题与行为动词作为检索词核对官方发布渠道，但这只是兜底——不得把自检索结果或模型记忆当作课标原文使用。不因主题相同就选认知要求较低的条目。
- **一个课题对应多个条目**：选本课实际完成的一个主条目，其余只作前后置连接。
- **找不到可核验原文**：教师未提供时最多尝试 3 次官方检索；仍无结果时不得用引号或"课标原文"标签呈现记忆内容，写"课标条目待核对"并请教师提供条目或授权继续制作非最终草案；原文未核验前不交付声称完全课标对齐的最终材料。

### 四要素拆解

按原文实有的要素拆，原文没写的要素不补写：

| 要素 | 含义 | 写法 |
|---|---|---|
| **A 行为主体** | 条文要求的承担者 | 多数条目省略主语，此时不解读此项，不硬填"学生" |
| **B 行为动词** | 学生要做的认知动作 | 直接取原文动词，如"说出""说明""分析" |
| **C 行为内容** | 动作指向的对象、范围与条件 | 取原文的对象与限定语，不换成本课边界外的对象 |
| **D 行为水平** | 该动作要求的认知层级 | 按 B 在条目中的实际要求判定，下表只作参照 |

C 决定素材与任务处理什么对象，D 决定课堂任务与检测到哪一层。对象被换掉、层级被压低，都算解读失败。原文没有的要素（常见是 A）跳过即可，不为凑齐四项写空话——四项齐全是形式，解对才是目的。

下表只是**示例，不是课标行为动词的全集**。课标条目的动词远多于此处所列，同一动词在不同条目中要求的深度也不一致。本表用于校准判断，不用于归类。

| 常见动词（示例） | 学生任务应体现 |
|---|---|
| 描述 | 从材料中准确说出空间分布、变化或特征 |
| 说明 | 用证据阐明关系或影响 |
| 分析 | 拆分要素并建立相互作用关系 |
| 解释 | 建立过程、机制或因果链 |
| 比较 | 使用一致指标识别共性与差异 |
| 评价 | 基于标准权衡收益、成本和风险 |
| 调查 | 设计并实施可执行的数据采集方案 |
| 设计 | 提出满足约束、回应证据的方案 |

表内顺序只提示常见的由浅入深方向，不是严格等级。D 按条目原文的实际认知要求判定：动词不在表内（如"归纳""绘制""判读""论证""提出"）时，直接判断它要求学生做到哪一步，不强行套进表中某一项，也不因"表里没有"而按低层处理。课堂检测至少保持目标条目中的最高认知要求。

### 教学提示

课标的教学提示（情境创设、途径、活动方式建议）是参考，不是必须遵守的情境清单：

- 已实际读取到教师资料中的教学提示时，可把它登记为构思阶段的**优先候选之一**。"优先"只指先考虑、先比较，不指默认采用；与内容要求的行为或对象不一致时不采用。
- 其他来源的情境——本地乡土材料、可核验现实事件、古诗词与典故、历史记录、实验现象、学生认知冲突、教师提供资料——只要能更好支持教学核心与目标表现，就可以胜出，不需要辩护为何不用课标推荐情境。
- **双向都不豁免**：采用课标推荐情境仍要接受情境检验（换成同类情境后任务是否几乎不变、删除后课程能否原样运行）；弃用它也不需要证明自创情境更新颖。判断依据只有一条：哪个情境能让学生实际使用其中的线索、证据或决策条件，形成学习终点要求的表现。
- 教学提示同属课标文本，只有实际读取后才能引用；成品中不出现"依据课标教学提示第 X 条"这类政策式标注，情境选择理由写成教学判断。

### 课标引用格式

教学设计中只完整出现一次：

```text
课程模块／内容要求编号（如可核验）
原文：……
来源：《普通高中地理课程标准（2017年版2025年修订）》
```

其余位置写"模块或编号＋十余字概述"，不重复整段原文。

### 课标解读小结

课标分析段末用一句话收束，串起情境、学习内容与育人价值：

```text
本节课的〔情境〕，使学生〔学习内容〕，〔育人价值〕。
```

三项都取自本课已确定的设计：情境写本课实际使用的那一个，学习内容写学生自己建立起来的关系或结论，育人价值指向具体的人地关系判断或地理观念。不写"培养核心素养""树立环保意识""激发兴趣"这类无法观察的价值表述。

## 二、地理学科判断

### 共通原则

- **证据先行**：先让学生接触地图、遥感影像、统计图表、景观照片、剖面图、过程示意、调查记录或情境材料，再形成或检验结论。
- **空间与尺度**：说明研究对象的位置、范围、尺度及区域联系；迁移时关注尺度变化是否改变结论。
- **时间与过程**：区分状态、趋势、过程和驱动机制，不把同时变化直接当作因果。
- **综合分析**：解释要素如何相互作用，识别主导条件、限制条件、变化条件或反馈关系，而非罗列因素。
- **人地权衡**：比较不同主体、空间尺度与时间尺度下的收益、成本与风险。
- **方法迁移**：用新区域、新图表、新数据组合或新决策情境检验迁移能力，而不只复述课堂结论。

### 认知深度（判断点 D5）

本节是「共通原则」中综合分析与尺度要求的操作化，也是判断供给的一处：学生年级与教材版本不决定深度，问题的内部结构才决定。**下面是判别用的两侧信号，不是生成条款**——照着"深的形态"逐条去写，会得到一份每项都轻微满足、整体仍然浅的课。

**一句话判别**：正确答案若可由材料中的单条信息直接推出、或由一条已学结论直接套用，这个问题就是浅的——情境再新、活动再热闹都不改变这一点。课上"活动很多但学不到东西"，通常是动作多、关系少。

**深度的六个来源**（不是层级，一节课抓住 1—2 个即可）：

| 来源 | 浅的形态 | 深的形态 |
|---|---|---|
| 主导与限制互换 | 列出有哪些有利条件 | 同一条件在什么情况下由优势变限制（五常热量劣势如何转为品质优势） |
| 因果链延长与回环 | A→B | A→B→C，且能从 C 反推 A；或指出反馈与阈值 |
| 尺度转换 | 在一个尺度内解释 | 机制在局地成立，须在区域或全球尺度重新解释其表现 |
| 模型适用边界 | 用已学模型解释新现象 | 新证据与模型冲突时，说明哪一步失效、如何修正 |
| 数量与口径 | 定性描述趋势 | 需要计算或估量级；识别统计口径造成的假象 |
| 不可通约的权衡 | 两方案各有优缺点 | 两目标不能同时最优，须说明代价由谁承担、何时偿还 |

**六种冒充深度的假动作**（出现任一，问题并未变深）：

- 换身份不换题：给了角色（规划师、评审员），问题仍是"说出三个因素"；
- 加数据不加推理：塞进统计表，只要求"描述变化趋势"；
- 画图代替推演：图上每个箭头都是课本原图的复制；
- 讨论代替论证：各自表态，没有共同证据标准，无法判定谁对；
- 名词升级："影响"改成"机制"，"因素"改成"驱动"，问题结构没变；
- 材料代替推理：要素给全，学生只需把要素搬进答案。

**三个约束**（避免为深而失控）：

- 深度必然带来"课堂上可能卡住"。一节课有 1 个会卡住的承重问题，好过 5 个人人秒答的问题；卡点须配阶梯提示与纠偏路径（见交付自查第 13 条）。
- 深度不等于堆叠。六个来源全用上，课会碎成六个片段，每个都浅。选与本课核心关系最匹配的那一个。
- 深度不等于学术化。搬来辐射强迫、位势涡度这类大学概念冒充深度，是另一种浅——学生只是换了一批不认识的词。

判据来源：11 份高中地理课例的原始文档（ima「课例」库，必修一、必修二、选必一、选必2）。表中负信号均可在其中指认到具体环节，不是概括出来的印象。

### 选择认知视角

以最能承担本课核心任务的视角为主，必要时吸收另一个。视角可组合，教学阶段可按课题、学情、课时增删重排。

- **自然地理过程与机制**（大气、水、地貌、植被、土壤、自然带、地球运动、自然灾害机理）：从可观察现象或时空差异出发，读取变量与过程证据，用因果链、过程图、剖面或模型解释"如何发生、为何发生"，再到新条件中检验解释。至少一项真实或合规第一手证据应进入核心解释或迁移检测，而不只用于导入；实验或模型要说明现实对应、尺度转换与局限，并最终用于解释或检验真实材料。
- **人文地理过程与区位**（人口、城市、农业、工业、服务业、交通、文化、全球化、产业转移）：围绕地点选择、空间变化或发展决策组织学习，以具体证据判断因素作用、主导条件及其变化，考虑信息不完全与利益权衡。避免把区位因素清单或单一区域结论套到所有情境。
- **区域认知与区域发展**（区域特征、差异、联系、产业转型、流域治理、城市群、区域协调）：先明确位置、范围、尺度与比较对象，再选能解释问题的关键要素，分析特征、联系、变化或发展方案。比较采用可比指标与口径，区分可迁移方法与依赖当地条件的结论。
- **资源、环境与国家安全**（资源开发、生态环境、能源与粮食安全、海洋权益、自然灾害、国土安全）：从资源流、环境变化、风险链条或治理情境切入，分析自然基础、人类活动、技术与制度的共同作用，比较方案的有效性、公平性、成本、风险与长期影响。涉及国家版图、国界与海洋国土时执行 `source-and-map-policy.md`。
- **地理实践与地理信息技术**（观察、调查、实验、野外考察、地图制作、遥感判读、GIS 分析、方案设计）：围绕可调查的地理问题选择地点、变量、样本、工具与记录方法，让学生处理并表达数据、解释结果、认识误差或局限。工具服务于地理问题；教学数据与学生真实采集数据应清楚区分。

### 借一个角度看（可选）

叙事作品处理"怎么让一个人非想明白不可"这件事，比教案成熟。可借的是它看问题的角度，不是它的写法——课还是地理课，不是把地理讲成故事。

- **视角决定看见什么。** 同一片海，渔民看风险、画家看光、工程师看潮位。地理上：同一区域换一个主体（农户、企业、政府、下游居民），主导因素就变了；"分析区位"与"分析谁的区位"是两道题。
- **张力来自信息差，不来自信息量。** 悬念是读者与人物知道的东西不一样多。地理上：材料的给出顺序决定学生什么时候知道什么；先给结论就没有推理，先给反例才有。
- **推动力是"想要而未得"，不是"该讲下一节了"。** 小说不为介绍家世而转场。地理上：问题应由"学生的现有解释遇到反例"推动，而不是由教材目录推动。
- **一个细节胜过三段概述。** 小说用一枚纽扣交代一个人的处境。地理上：一个具体数值、一张具体照片，比"影响因素有三条"更能让人开始想。
- **开头出现过的东西，结尾必须再响一次。** 地理上：导入的现象要在结尾被新建立的机制重新解释；只出现一次的情境是装饰。
- **可以误导，但要公允。** 允许红鲱鱼，前提是线索早已给足。地理上：材料里的干扰项要能被证据推翻，不能靠"老师没讲"排除。

六条里能用上一两条就够，全部套用会把课上成叙事练习。

### 核心素养转化为可观察表现

| 核心素养 | 可观察表现示例 | 避免的写法 |
|---|---|---|
| 人地协调观 | 比较治理方案对居民、产业和生态的长期影响 | 培养环保意识 |
| 综合思维 | 用水分、热量和地形的相互作用解释植被差异 | 综合分析影响因素 |
| 区域认知 | 用可比指标分析两个区域并解释差异 | 了解区域特征 |
| 地理实践力 | 设计样点、记录变量并评价数据误差 | 提高实践能力 |

学习目标可用"学生能够……"表达，结合行为、所用证据与预期质量；避免只写"理解、掌握、认识"。

### 思维模型与表征

- 思维模型是可选认知工具：学生需梳理多个要素、连续过程、空间关系或方案条件时可用模型简化表达；简单任务不必强制建模。
- 模型只保留对当前问题有解释力的要素与关系，并由材料或地理原理支持；注意其成立的时间、空间与条件，不把个别案例写成普遍规律。
- 模型可由教师提供、师生共同完善或学生自主建构，也可只体现在推理过程中；形式按任务选择，不规定统一样式。
- 新证据与原有模型不一致时，可以引导学生调整解释；不为了保持预设结构忽略反例，也不把某一课例的模型变成跨主题答题模板。
- 选最适合认知任务的地图、图表、数据、影像、模型或调查材料，**不以材料数量衡量课程质量**；学生应实际读取、比较、绘制、解释或使用关键表征。
- 现实数据标明来源、年份、单位与统计口径；教学模拟数据明确标注并符合基本地理规律。涉及比例尺、时差、密度、增长率、坐标、单位与图表读数时核验计算与表达。
- **计算进入主要任务前检查四点**：目标是否需要数量方法；不计算是否无法完成核心地理推理；结果是否直接用于解释真实地理证据、空间差异或过程变化；复杂度与耗时是否符合学情与课时。不能同时满足时，优先改用读图、比较、排序、估算、过程图或地理解释。模拟计算只能检验模型或练习方法，不能证明现实地理事实。
- 地图的来源、边界与审图要求按 `source-and-map-policy.md` 执行。学生绘制的过程示意、空间关系草图或调查地图可按学习目标简化，但不要把示意表达冒充正式地图或精确比例成果。

## 三、灵感索引（可选）

初始构思不读本节，只在需要另找路径时按情形选 1—2 条：**这些是候选机制，不是规则，也不进入交付自查。**

```text
不可直接观察的过程需要转为证据和模型：DC-V2-01
多因素内容需要组织并行比较：DC-V2-02
需要用反例或异常条件修正过度概括：DC-V2-03
中间成果需要被后续任务持续使用、检验或修正：DC-V2-04
需要建立"意义或功能"的联系（证据丰富的同一系统）：DC-V2-05
先形成粗略作品、再用新知识诊断和改进作品：DC-V2-06
无法实地开展、需保留真实方法动作：DC-V2-07
用真实约束下的决策成果整合知识：DC-V2-08
```

没有匹配项时不强行调用。说明它为当前构思提供了什么新可能即可，不能因为机制存在就把它变成所有课程必须满足的要求。
