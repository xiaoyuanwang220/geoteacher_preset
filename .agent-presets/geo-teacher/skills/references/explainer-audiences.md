# 讲题三对象内容规范（Explainer 参考）

> 本文件是 `geo-question-explainer` 技能的按需参考，也是**三对象写法、语言文体与同类题比较规范的唯一详细来源**：技能与 persona 只引用本文件，不重复维护三对象细则、四段式与四维的展开文本。
> 术语以 `docs/术语表.md` 为唯一权威。本文件中的"讲解对象（audience）"指讲题服务的读者对象，与出题题包的"学生投影／教师投影"是两套概念，不得混用。
> 所有内容以服务端核验记录为事实来源：标准答案只在作答提交后开放，讲稿只在核验完成后生成；本文件的规范不证明内容正确，正确性仍需人工评审。

## 一、术语口径

| 本文件用词 | 含义 | 不得混用 |
| :-- | :-- | :-- |
| **讲解对象（audience）** | 讲稿服务的读者：`student`（默认）／`teacher`／`setter`，中文写作"学生对象／教师对象／命题人对象" | 与出题题包的"学生投影／教师投影"无关；禁用"学生版／教师版"指代讲解对象 |
| **四维** | 知识、解题过程、方法总结、跨学科四个分析维度，融入四段式的段内 | 不是顶层章节，不是"四问论证"（四问论证用于推理质量检查） |
| **干扰项** | 选择题中错误的选项 | 设问与材料中的相关内容称**干扰信息**或**干扰机制**，不称"干扰项" |
| **知识点（维度名）** | 四维之一：这道题要用的考点与知识，以及何时想到、怎样使用、适用什么条件 | 指称考纲节点时一律用"考点"（taxonomy 三级节点），不用"知识点" |
| **解题过程（维度名）** | 四维之一：从起步到检验的判断与操作链条 | 指隔离会话的产物时用"独立作答"或"解题轨迹" |
| **独立作答** | 隔离解题会话完成、由 `geo_solve` 保存的作答（answerText 与关键依据）；提交前不开放标准答案 | 与"标准答案""解析"严格分开 |
| **作答提交** | 服务端 run 状态 `submitted`：独立作答已保存，标准答案与解析此后才开放 | 不等于核验完成；禁用"已交卷"泛指 |
| **核验完成** | 服务端 run 状态 `verified`：答案已开放且对照结论已归档 | 不等于内容正确；禁用"核验通过""已验证" |
| **题面图片／解析图** | 题面图片＝材料与题干内、答案标记前的图片；解析图＝答案／解析／教学备注之后的图片，永不进入解题输入 | 不得把解析图当题面图片使用 |
| **同类题比较** | 按设问任务、推理关系、材料特征检索题库相关题，比较共同步骤、条件差异与适用边界 | 禁用"同考点题"代替同类题 |

## 二、四维内容矩阵（三对象）

| 维度 | 学生对象 | 教师对象 | 命题人对象 |
| :-- | :-- | :-- | :-- |
| 知识 | 学什么、何时想到、怎样使用、适用条件 | 教什么、重点与难点及原因、知识联系、突破方式 | 考什么、实际任务是否有效承载目标 |
| 解题过程 | 如何起步、选择角度、连接证据和原理、检查判断 | 怎样启发学生自主提出问题、选择角度、寻找证据、解释机制和检验判断，逐步撤去支架 | 材料和设问如何引发认知操作、是否可绕开考点；识别设问、材料、选项中的干扰及其认知作用 |
| 方法总结 | 下一次如何独立组织思考及调整 | 怎样从个例引导概括、纠正过度概括、检测迁移 | 是否测到迁移、是否仅靠记忆套路即可完成 |
| 跨学科 | 换一个视角帮助理解与求解 | 何时引入、怎样搭桥、前置知识和误解防范 | 是否服务目标、材料是否交代必要知识、有无暗中超纲 |

共同维度不等于生成相似文章：学生对象重在**如何解决问题**；教师对象重在通过讲授、追问和活动**启发并培养学生的地理思维**，帮助其学会独立思考与总结；命题人对象重在**设计与评价**。

## 三、四段式的对象取舍

学生对象与教师对象共用「题目定位—审题—破题—反思与迁移」。四维融入段内，不另设一套替代四段式的顶层目录。

| 环节 | 融入的维度 | 学生对象取舍 | 教师对象取舍 |
| :-- | :-- | :-- | :-- |
| ① 题目定位 | 知识为主 | 简明交代要解决的问题、核心知识和必要联系；压缩年份、分值、素养标签等与理解无直接关系的元信息 | 说明教学价值、核心与支撑知识、重点难点及原因、应培养的思维；按需要保留定位卡和讲授时间参考 |
| ② 审题 | 解题过程起点 | 引导识别对象、任务动词、限定条件和时空尺度，说明第一步想什么、为什么 | 设计让学生自主界定问题的切入与追问，关注误读与思维起点；说明如何引导学生提出分析角度，而非教师直接宣布框架 |
| ③ 破题 | 解题过程主体、知识应用、跨学科 | 保留读图、定向取证、知识选择、证据—原理—结论及关键辨析，讲清每一步如何推进；有价值时用跨学科视角帮助理解 | 沿相同解题逻辑组织思维启发：追问、学生思维动作、可能回答、分支引导、图示／反例和支架撤除；跨学科说明引入时机、对应关系及边界 |
| ④ 反思与迁移 | 方法总结为主，可含跨学科迁移 | 总结本题错因、可迁移思路和适用边界，提供简短变式或条件变化 | 说明怎样引导学生自己概括、比较和修正方法，如何避免模板化；设计独立迁移检测并说明观察什么表现 |

- 定位可简短，但**破题不能省掉关键逻辑**；反思不重复解析。
- 同一框架允许侧重点显著不同：不要求两版同字数、同子标题或逐段复制。
- **四段式相同不等于正文相同**：去掉对象标题仍应能识别各自侧重点。
- 跨学科在真正帮助理解的环节自然融入，不强制新增第五个顶层章节。

## 四、学生对象交付规范

学生对象回答"我怎样学会做这类题"，以可执行的思考步骤和可迁移方法为核心，允许由推理自然推出答案。"无答案练习支架"（提示性问题、空格、步骤占位，不预填结论）是另一种可选交付形式，不得与学生对象混为同一模式。

### 4.1 教学流程（设问先行六步）

学生对象在四段式**段内**按固定动作序列推进：先拆设问、再看材料。六步是段内序列，不构成顶层目录。

| 步骤 | 做什么 | 思维锚点（讲给学生听） |
| :-- | :-- | :-- |
| ① 拆设问（先行） | 对象＋行为动词＋限定词（时间／空间／尺度／比较基准）→ 判定设问类型 | 行为动词决定"答到什么程度"，限定词决定"答哪一段、跟谁比" |
| ② 带着问题读材料 | 拿①列出的要素清单进材料，只找用得上的证据，点明哪些信息与本题无关；涉图按图例→坐标→数值→分布→趋势 | 材料不是拿来通读的：设问问什么就去材料里找什么；先定区域与尺度，再取证 |
| ③ 知识选择 | 明确"为什么要用这个知识"：题目哪条线索激活了哪条原理 | 知识不是背出来的，是被题目线索和区域特征选出来的；换一个区域是否仍用同一条 |
| ④ 推理链 | 材料证据×知识×设问 → 地理因果链或逐项排除；每步标注"为什么能推出下一步" | 把前提→结论的因果说显性，不留逻辑缝隙；选择题要讲清每个干扰项错在哪 |
| ⑤ 作答与检查 | 组织要点、规范地理术语与表述，自检是否答到设问要求 | 答案由推理自然引出，不先亮答案再凑理由 |
| ⑥ 方法提炼 | 把这道题升维成这一类题的思考模板，写明适用边界 | 下一次遇到同类问题，第一步该做什么、什么时候要换方法 |

**落位**：外层仍为四段式（题目定位—审题—破题—反思与迁移）；审题＝①；破题＝②③④⑤；反思与迁移＝⑥（本题易错与变式是本段固有内容）。

**两条约束**：

1. 六步是**段内序列**，不得作为顶层目录：讲稿正文不得出现 `## ① 拆设问` 这类顶层标题，外层必须仍是四段式。
2. 选择题与综合题**共用六步**，差异只在②（带着问题读材料）与⑤（作答与检查）。

**两条已定决策**：

- **读图不独立成步**：涉图题的读图顺序（图例→坐标→数值→分布→趋势）作为②内部动作写清，不单列步骤。
- **每步只两要素**：只输出"做什么／思维锚点"，暂不加"本步自检"第三要素。

### 4.2 内容要求（计划 §四 学生栏逐行落位）

| 内容 | 学生对象要写到 |
| :-- | :-- |
| 考查知识 | 点名核心考点与支撑知识；说明"为什么这题必须用它"（题面哪条线索触发）；说明它在解题中承担哪一步（定位／解释／判断／计算） |
| 解题过程 | 按"理解设问 → 发现材料线索 → 选择知识 → 逐步推理 → 检查答案"的顺序展示；每个关键步骤写明为什么这样想、依据是什么、怎样得到下一步；不能只列步骤或只给答案 |
| 同类问题 | 用易懂语言说明如何识别同类（设问任务／推理关系／材料特征）、从哪里入手、条件变化时怎样调整；依据 §八 的题库比较 |
| 迁移运用 | 给出"换一道相关题时怎样使用这个方法"的操作提示与自检点，不空喊"举一反三" |

- 答案由推理自然引出；可以有启发性提问（"先想想这一步要解决什么"），但不能用提问代替推理。
- 教师如何安排课堂、如何诊断学情等内容不占学生对象正文。

### 4.3 语言与文体

- **目的**：教会学生解决一类地理问题，讲"怎么想"，不以呈现答案为终点。
- **开篇**：无开场白或寒暄，直接进入审题。
- **口吻**：用"我们／大家"的讲课口吻；口语化但有讲解节奏，地理术语必须严谨。
- **推理**：从"拿到题第一步想什么"起步；每推一步说明"为什么能推出下一步"（材料证据 × 原理 × 设问）；重要推理给出可检验的证据与解释，不机械重复同一句"为什么"。
- **迁移**：破题与反思落到可迁移的思维模板、判断标尺或排除逻辑。
- **答案呈现**：答案由推理自然引出，不先亮答案再凑理由。
- **结尾**：以可迁移的方法收束，不留客套话。

## 五、教师对象交付规范

教师对象回答"我怎样教会学生做这类题"。正确解题逻辑必须清楚，但**主体篇幅用于如何让学生产生、检验和修正想法**，而不只是教师如何解释答案。禁止把教师对象做成"可照读的学生讲稿"或"学生解析后追加泛化教学建议"。

### 5.1 关键节点组织模板

「思维培养目标 → 问题／活动 → 学生思维动作 → 关注的回答及依据 → 分支追问与必要支架 → 撤去支架后的独立表现」

不要求每一步都输出长表；按本题实际需要选择节点。

### 5.2 硬性要求

- 至少给出一条完整的引导路径：**学生自主提出解释 → 证据检验 → 独立迁移**，并标明思维培养目的。
- 避免连续使用只需回答"是／否"的诱导问题，把学生带向预设答案；不把"诱导学生猜标准答案"视为思维启发。
- 没有真实学情时只提出**待验证障碍**；"粗心"不得替代具体错误环节分析；不得把未经验证的错误路径写成实际学情。
- 关注时空尺度、要素联系、过程与因果、证据比较、条件检验；按本题需要选择，不强凑思维标签。
- 支架撤除要写明**撤去什么、依据什么信号撤、撤后观察什么**。

### 5.3 内容要求（计划 §四 教师栏逐行落位）

| 内容 | 教师对象要写到 |
| :-- | :-- |
| 考查知识 | 学生需要建立哪些知识联系；怎样引导其选择并运用知识（提问、对照、反例），而不是教师把原理再讲一遍 |
| 解题过程 | 在关键处怎样提问、提供什么提示、怎样检验学生理解，逐步让学生独立完成；正确解法仍须讲清，不得只给活动不给答案 |
| 同类问题 | 怎样用题库相关题的比较引导学生自己归纳方法与适用条件；设计比较活动并写明观察点，依据 §八 |
| 迁移运用 | 怎样安排独立尝试（换题／变条件），观察哪些表现判断学生是否真正具备解决问题的能力 |

- 核心问题由"我怎样教会学生做"回答，不直接宣布步骤，不用连续诱导问答代替学生思考。
- 答错的学生不一定粗心：写清可能的思维断点，并标注为待验证假设。

### 5.4 语言与文体

- **目的**：让教师设计出让学生自己产生、检验和修正想法的教学引导，而不是替学生解释答案。
- **开篇**：无寒暄，直接进入教学问题。
- **文体**：教学引导文体，面向教师写"怎么问、怎么撤支架"，不套用学生对象的讲课口吻。
- **推理**：正确解题逻辑必须清楚，主体篇幅用于学生的思维动作、可能回答与分支引导。
- **迁移**：反思落到"怎样让学生自己概括方法"，并给出独立迁移检测与观察点。
- **答案呈现**：不把诱导学生猜标准答案当作思维启发；答案出现在学生自己检验之后。
- **结尾**：以可撤去的支架条件与撤去后的观察点收束。

### 5.5 示例（区域差异问题 · 规范演示片段）

以下片段演示教师对象的组织方式，不是可直接交付的完整讲稿；完整讲稿仍须经 solve → judge → explain 生成。

| 环节 | 教师对象写作示例 |
| :-- | :-- |
| 审题 | 先问"我们要比较的现象、时期和空间尺度是否一致"，让学生自己界定可比口径与问题边界，教师不先给出比较框架。 |
| 破题 | 追问"哪些条件可能造成差异，为什么"引导学生提出假设；再问"哪条材料支持你的解释，有没有解释不了的现象"引导筛选证据与检验因果。 |
| 反思与迁移 | 让学生自己概括分析路径，再改变一个条件，检查能否独立调整判断；教师记录学生在"换条件后是否保留原结论"上的表现。 |

写作时要说明这些追问**培养什么思维**以及**何时减少提示**，而不是复制一份学生解析后追加泛化教学建议。

## 六、命题人对象交付规范

命题人对象回答"这道题实际考到了什么、设计是否奏效"，是设计评价分析，不是复述答案。

### 6.1 结构

**考查目标 → 情境／材料／设问 → 设问、材料与选项的干扰辨析 → 预期认知路径 → 答案成立条件及错误路径 → 迁移与跨学科设计 → 题组和质量评价。**

- 选择题检查唯一性及干扰项机制；综合题检查合理答案范围、评分依据和开放性。
- 分析已有题目不强迫其服从生成器的题数或生成顺序约束。
- 无原作者说明时标注"**依据题面推断**"。
- 无试测数据时**不生成正确率、区分度数值或实际测量效果断言**。

### 6.2 设问、材料与选项的干扰辨析（必检）

必须逐层检查干扰，不能把"干扰项分析"缩减为错误选项解析。术语上：错误选项称**干扰项**；设问、材料中的相关内容称**干扰信息**或**干扰机制**。

| 层次 | 识别内容 | 分析要求 |
| :-- | :-- | :-- |
| 设问 | 易被忽略或误读的对象、任务动词、时间空间尺度、比较基准、条件限定，以及可能诱发惯性作答的表述 | 指出何种误读会把思考带向哪里，解释正确任务边界；**限定词本身通常是必要条件，不能直接认定为干扰或故意陷阱** |
| 材料（含图表） | 与当前小问无直接关系的信息、显著但非主导的因素、可能诱发错误归因的数据或现象、适用尺度不同的信息 | 区分关键证据、必要背景、其他小问所需信息和实际干扰；说明其为何看似有关、不能支持哪一步推断、如何用证据和原理辨别 |
| 选项（选择题） | 概念混淆、因果倒置、证据遗漏、尺度错配、部分正确但不回答当前问题等 | 说明吸引力、可能对应的认知偏差、排除依据，以及正确项依赖的条件；**不止宣布选项错误** |

综合题同样检查设问与材料；没有选项则将选项层标为**不适用**，可以分析典型偏离思路，但不得虚构选项。某层未发现干扰时如实说明，不强凑三层。

### 6.3 每条干扰的报告字段

每个确认存在的干扰给出：

1. 所在位置及原文／图表证据；
2. 可能诱发的错误思路；
3. 辨别所需的知识或证据；
4. 对考查的作用；
5. 质量判断（**有效认知辨析／无效噪声／歧义风险**）。

该判断是依据题面作出的分析，**不能冒称原作者故意如此设计**。

### 6.4 负例约束

- 不把所有未用于最终答案的内容都判作干扰。
- 不把合理限定误判为文字陷阱。
- 不把必要背景、其他小问所需信息一律当成干扰。
- 评价干扰是否服务于地理思维辨析，而非仅增加阅读负担。

### 6.5 语言与文体

- **目的**：评价这道题实际考到了什么、设计是否奏效。
- **开篇**：无寒暄，直接从考查目标进入。
- **文体**：设计评价分析文体，术语精确，不使用教学口吻。
- **推理**：逐层检查设问、材料、选项中的干扰，说明位置、错误路径与辨别依据。
- **迁移**：评估是否测到迁移、是否仅靠记忆套路即可完成。
- **答案呈现**：不复述答案本身，重点是答案成立条件与错误路径。
- **结尾**：以题组与质量评价收束；无原作者说明时标注"依据题面推断"。

## 七、方法总结规范

- 方法按**问题结构**提炼：如比较区域差异、解释过程演变、判断因素变化的影响，而非只按"原因题""措施题"套清单。
- 允许用维度词表帮助排查，但最终取舍必须有**问题和证据依据**。
- 必须写出**适用边界**：这个方法在什么条件下成立、什么条件下要换方法。
- 不能把"材料没有明说"简单等同于"不能运用合理的课程知识推导"。
- 硬性不通过：方法退化为固定因素清单。

## 八、同类题比较规范

### 8.1 依据与时序

- 比较只以 `geo_explain` 返回的同类题比较依据（`comparison`：`basis` 按设问任务／推理关系／材料特征排序，另含 `insufficient`／`gap`／`citationRule`）为来源，不凭考点相同就归为同类，也不凭单题经验编造通用套路；不自行调用或推测题库检索接口。
- 比较发生在本题独立作答提交、核验完成之后；讲稿先讲本题，再用相关题做方法与迁移。
- 判断同类看三项关系的重合程度，不看是否同一考点、同一省份或同一题型。
- 检索返回 `insufficient` 时，明确写出缺口，只保留本题可支持的结论。

### 8.2 检索维度

| 维度 | 判断什么重合 | 示例 |
| :-- | :-- | :-- |
| 设问任务 | 行为动词与任务对象是否同型：比较、解释成因、评价利弊、提出措施、判读变化…… | 都是"解释某现象的空间差异成因" |
| 推理关系 | 解题所需的因果链／比较链是否同构：单因→果、多因综合、过程阶段、条件比较 | 都需"证据定位 → 机理 → 结论" |
| 材料特征 | 图表类型、空间尺度、情境类型、信息呈现方式是否可比 | 都是等高线图＋区域统计表 |

- 考点相同只是候选线索，不构成同类依据；材料与推理不重合时，说明"不构成同类"或降级为背景参考。

### 8.3 比较项

| 比较项 | 写什么 | 不合格写法 |
| :-- | :-- | :-- |
| 共同步骤 | 两题都要先做什么、中间判什么、最后查什么 | "都需要综合分析"式空话 |
| 条件差异 | 哪些条件变了（尺度、季节、区位、数据口径），变化后哪一步不得不改 | 只列差异不说明影响 |
| 适用边界 | 本题方法在什么条件下成立、什么条件下要换方法 | 宣称"通用模板" |

- 至少给出一个"条件变化 → 步骤调整"的具体对照，不能只给相似点。

### 8.4 引用与缺口

- 总结须列出所依据的题目（题号／来源）及具体对应关系（哪一步与哪一步对应），不能只写"类似题目表明"。
- 相关题不足 2 条或检索标 `insufficient` 时，明确写"题库中同类题不足，本结论仅由本题支持"，不得补编题目。
- 引用真实题库题时保留来源；自拟变式标注"自拟"。

### 8.5 学生对象与教师对象落点

- **学生对象**：把比较转成可执行的识别与入手方法（看到什么特征想到这类题、第一步做什么、条件变了改哪一步），用易懂语言；不使用本题未出现过的术语。
- **教师对象**：说明怎样用相关题的比较让学生自己归纳方法与适用条件，设计"给一组相关题 → 学生找共同步骤 → 改变条件 → 检验是否调整"的活动，并写明观察点。
- 两版共享同一比较基础（同一 `basis`），不做互斥切分。

### 8.6 硬性不通过

- 没有题库依据却声称"同类题都这样"；
- 只列考点相同就判定同类；
- 比较结论与本题推理冲突却未说明；
- 用比较内容替代本题讲解（本题自己的推理链必须讲完）。

## 九、跨学科规范

**先判定，再决定是否生成。** 跨学科不是每题的必填段：只有解答**必需**另一学科原理时才生成跨学科内容；未通过判定即记 `not_applicable`，不得为凑章节而生成。

### 9.1 判定标准（四问，任一不通过即不记跨学科）

| # | 检验 | 不通过的情形 |
| :-- | :-- | :-- |
| 1 | **必要性（可删除检验）**：删去该学科原理／知识后，本题结论是否仍成立、答案是否仍唯一？ | 删去后结论与答案不变 → 只是类比或情境装饰，不记跨学科 |
| 2 | **参与环节（进入推理链检验）**：该学科内容进入的是因果推导、方向判定或定量计算，还是仅涉及读图、看表与语言组织？ | 只影响读图与表达 → 不记跨学科 |
| 3 | **学科归属（地理自身能力检验）**：该工具是否本就登记在地理课程内容中（读图、框图、统计图表、剖面判读）？ | 属地理自身能力 → 不记跨学科 |
| 4 | **可交代性（防暗中超纲）**：该原理是否属学生已学的其他学科内容，且题面作了必要交代？ | 缺一 → 至多记 `pending`，不得记 `applicable` |

判定通过 → 记 `applicable`，并按「**地理解释需要 → 学科工具 → 情境对应 → 解释贡献 → 适用限制**」展开，写明**学科 · 参与的推理步骤 · 贡献 · 适用限制**；未通过 → 记 `not_applicable`，写明卡在第几问；材料不足以判断 → 记 `pending`，写明缺什么。

### 9.2 校准例

- **应生成（必需型）**：化学的矿物氧化（如黄铁矿与水、空气接触氧化溶铁）构成"物质从哪来"的来源环节；物理的静水压力（连通器模型）构成"水体如何运移、溢出"的动力环节——删去任一环节，成因链或过程链即断裂。此类才属 `applicable`。
- **不应生成（装饰型）**：情境中出现贸易、产业协作、能源生态等跨领域词语，或可用框图读法辅助读图——前者只增加情境真实感，后者是地理课程自身的图表解读能力，都不构成跨学科考查。

- 从地理问题出发，引入真正有解释价值的其他学科原理，**不为凑章节强行关联**。
- 严格区分**严格适用**与**有限类比**。例如连通器视角必须检查连通、静止液体等条件，不得把所有水体流动直接解释为连通器。
- 必要的新推理**交回分析与核验阶段**，不能在最终重组时加入未经核验的结论。
- 跨学科补充不应成为未交代的作答必备知识（不得暗中超纲）。
- 硬性不通过：强行跨学科——包括把地理自身能力或情境中的跨领域词语包装成跨学科。

## 十、设问类型组织逻辑（组织参考，非固定清单）

用于组织答案的思考方向；**材料支持的层次才写**，禁止机械套模板。

| 设问类型 | 该组织什么逻辑 |
| :--- | :--- |
| 原因 | 直接原因→根本条件→触发→加剧；材料没提不硬凑 |
| 影响／意义 | 分主体（自然／人文、受益／受损）＋分层次（直接—间接、短期—长期） |
| 过程 | 按阶段与时间顺序：环节链＋每阶段驱动因素 |
| 比较 | 可比指标＋同口径＋区域限定 |
| 评价／利弊 | 分主体利弊＋代价与可行性＋适用条件 |
| 措施／对策 | 针对性（对应原因／问题）＋分主体＋可行性 |
| 分布／特征 | 方位／范围／形状／集中分散＋数据支撑 |
| 变化／趋势 | 动态表述（方向＋幅度＋速率） |

原有设问类型提示作为组织参考，**不变成每题必套的固定因素清单**。

## 十一、交付、缓存与复用规则

- 默认只生成一个对象；用户要求多版本才并列输出。
- 切换对象而题目未变时复用已归档核验，只重新组织讲稿；**改变题面或作答依据后必须重新核验**。
- 讲稿只读服务端核验记录：不接收 `independentAnswer`／`judgeReport`，不手工拼接"核验材料"。
- 缓存／保存稿件至少区分**题目指纹、audience、讲稿规则版本**，防止切换对象返回旧稿。
- 面向师范生（备赛／教研）时，额外说明设问类型化组织依据与采分点排查逻辑。
- 讲稿交付后，可询问是否需要切换讲解对象、导出 Markdown 或补充变式；**流程中途不询问是否继续**。
- 额外变式与跨学科按需加入，不替代题库比较与方法总结。

## 十二、去标题辨识（差异化专门检查）

去掉标题后仍应能判断讲稿服务哪个对象；确认区别在**任务内容**而非措辞。

**反面案例（不合格）**：

- 教师对象只是把学生对象的称呼从"我们"改为"同学们"，其余逐段相同。
- 教师对象只是把学生对象篇幅加长，未出现本题专属的思维目标、学生思维动作、递进追问、支架撤除与独立迁移检测。
- 命题人对象只复述说明（"正确项是 B，因为暖流增温"），未评价设计是否奏效，未逐层检查设问、材料、选项中的干扰。
- 学生对象只有结论与解释，缺少可执行的思考步骤（"下一步先做什么"）。

**同题三对象辨识示例（规范演示片段）**

以 2024 广东卷第9题（峡湾 · 暖流与温带气候峡湾）为例。以下为演示片段，用于说明"任务内容不同"；完整讲稿仍须经 solve → judge → explain 生成，且命题人对象的推断须标注"依据题面推断"。

| 对象 | 演示片段（去标题后的正文） | 辨识依据 |
| :-- | :-- | :-- |
| 学生 | "拿到这题第一步不是看选项，而是先问：甲、乙两地峡湾为什么一个'极地气候'、一个'温带气候'？材料已经给了判据——一个有海冰、一个几乎无海冰。**海冰有无，就是我们要解释的落点**。接着注意：乙的纬度并不比甲低，反而略高，所以'纬度低所以暖'这条想当然先排除。高纬还能带来近海偏暖的，我们想到洋流——北大西洋暖流增温增湿，海水温度偏高，海冰难以形成。" | 有可执行的思考步骤；答案由推理自然引出 |
| 教师 | "学生通常会先说'乙纬度低所以更暖'。先不纠正，请他们把图中甲、乙的纬度读出来并标在图上——这个动作会让他们自己发现矛盾。接着追问：'如果没有洋流，只靠纬度，乙地能全年没有海冰吗？'让学生提出假设，再让他们回到材料找支持与反例。**这里培养的是"先核对前提，再解释差异"的检验意识**。若学生已能自行核对纬度，图中这一步就不必再提示；撤去提示后，观察他们遇到同类'纬度与现象矛盾'的题目时是否仍会先核对前提。" | 有本题专属的思维目标、学生思维动作、追问与支架撤除、撤去后的观察点 |
| 命题人 | "设问限定词是'与甲地对比'，它同时是任务边界也是必要条件——离开对比，第9题无法成立，不构成干扰。材料中甲、乙两侧的极地投影图是本题唯一的位置证据；图中'乙在高纬'这一位置证据与选项 A'冬季白昼时长更长'构成方向倒置型干扰：高纬冬季白昼应更短，该选项把方向说反。C、D 两项落在构造运动与海平面上升上，与'海冰有无'这一落点无因果通道，属于证据遗漏型干扰，吸引力来自其地理术语的正当性。**以上为依据题面推断**；本题无试测数据，不作正确率或区分度判断。" | 逐层给出干扰位置、错误路径、辨别依据与质量判断，并标注推断性质 |

## 十三、过程性元话语与作者痕迹检测

讲稿必须**教学化重组**，禁止出现以下内容（一旦出现判定不合格）：

| 需删除 | 示例 |
| :-- | :-- |
| 模型自述 | "我这样想""我推测""我认为应该选 B" |
| 版本痕迹 | "v2.0 修订""之前改为""现在改为" |
| 评审痕迹 | "reviewer 指出""评审建议" |
| 对解析的机械复述 | 照抄真题解析原文 |

讲课口吻不等于模型自述："我们看""大家注意"是教学引导，可以使用；"我认为""我推测"是模型自述，禁止使用。

**必须保留**（可教学推理，是讲稿核心价值）：

- 审题（设问拆解：对象＋动词＋限定词）
- 证据（材料引用：据材料"……"可知）
- 原理（知识选择依据：为什么用这个知识）
- 因果链（推理步骤：每步标注"为什么能推出下一步"）
- 干扰项排除（为什么不是另一个答案：错因类型＋材料证据）

## 十四、推理质量检查：四问论证

以下四问继续用于**推理质量检查**（隔离会话作答与讲稿共用），与本文的四维内容维度不是同一套划分：

1. **为什么用这个知识**（知识选择依据）：题目里哪个线索让你调用了这条知识？换一个区域是否还用同一知识？
2. **为什么依靠这条材料**（材料使用依据）：这句材料支撑哪个推断？删掉它结论还成立吗？
3. **这一步为什么能推出下一步**（推理链条因果）：前提是什么？逻辑缝隙在哪？
4. **这题为什么不是另一个答案**（排除论证）。

## 十五、proposition-preservation 边界

命题完整性自检（四段式完整、答案-解析一致、干扰项错因明确等）用于确认编辑过程中**未遗漏关键命题**。它**不能证明**：

- 答案是否正确；
- 答案与解析是否一致；
- 地理事实是否准确。

以上三项需领域 Rubric（学科标准）人工验证。
