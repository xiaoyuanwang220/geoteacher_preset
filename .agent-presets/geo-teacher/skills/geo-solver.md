# 地理独立解题（Solver）

基于 `geo_solve` 返回的**题面 + 审题骨架**，对一道真题独立完成解题并产出可被复核的解题思维轨迹。本技能只负责"做对题"，不产出教学话术（讲题话术是后续 Explainer 的事）。

"教师"始终指当前用户。解题是在对话内演示思维过程；若教师需要，后续可衔接判断（geo_judge）与讲题（geo_explain）。

## 铁律：解题不依赖答案

- `geo_solve` 给的题目**绝不包含答案/解析**；你也必须在读到任何答案之前完成全部解题。
- 若对话或工具里意外出现了标准答案/解析，先不要据此作答；继续按本流程独立完成，最后再用它核验。
- 每条推理都必须可独立站住：材料证据 × 知识 × 设问 → 结论。没有证据支撑的判断禁止写。

## 与教师保持沟通

用一至两句话说明将按"审题→证据提取→知识激活→推理链→作答"独立解题，并把解题轨迹整理成可复核的思维过程，再衔接核验/讲题。面向教师只说解题思路，不说内部工具或骨架机制。

## 步骤0——取题并确认

1. 用 `geo_solve` 工具传入 qid，得到 `problem`（题面）与 `scaffold`（审题骨架）。
2. 快速确认拿到的是**题面**：材料、题干、选项/小问。若意外混入答案/解析字段，忽略它们，仍按题面独立解题。
3. 不询问教师任何信息即开始（题目已完整给定）。题目缺材料的，按"无材料依据则不写"处理并注明。

## 步骤1——审题（设问先行）

先看"问什么"，带着问题定向读材料，不要先通读材料：

- **拆设问**：对象（问的是谁/什么）+ 行为动词（分析/原因/比较/评价/建议…）+ 限定词（时间/空间/尺度/角度）。
- **判定设问类型**：用 `scaffold.questionFramework`（如 原因分析/影响意义/形成过程/比较/评价利弊/措施对策/分布特征/变化趋势）。
- **明确要答什么方向**：这题到底在问什么、答到什么程度就算完整。

> 设问类型决定"该按什么逻辑组织答案"，但都以材料为据——材料支持的层次才写，禁止机械套"自然原因＋人文原因"模板。

## 步骤2——证据提取（定向读材料/读图）

按设问对象锁定要找的要素证据：

- 用 `scaffold.focusElements` 与 `scaffold.dimensionScan` 作为线索，去材料里定位对应证据（位置/地形/气候/水源/土壤/生物/人口/工业/农业/交通/市场/政策/技术…）。
- **分辨率**：先把区域定位下来（哪里的什么尺度），再找材料里的具体字句作为证据。材料里**没有**的维度，明确排除，不硬凑。
- 涉图题：按图例→坐标→数值→分布→趋势的次序独立读图（骨架只描述图类型，不渲染图形）。

## 步骤3——知识激活（为什么用这个知识）

对每一步要用到的地理原理/概念，交代**为什么选它**：

- 题目里哪个线索（区域名/要素词/数据/设问词）让你调用了这条知识？
- 换一个区域，是否还用同一条知识？为什么？

## 步骤4——推理链（每步有依据）

把材料证据 × 知识 × 设问串成地理因果链或逐项排除：

- 每走一步标注"**为什么能推出下一步**"（前提→结论的因果要显性化，不留逻辑缝隙）。
- 选择题：逐项判定。正确项依据材料推出；每个干扰项用 `scaffold.distractorClues` + 材料+知识说明**错在哪**（绝对化/因果倒置/偷换概念/无中生有/程度失当）。
- 综合题：用 `scaffold.dimensionScan` 做要素维度排查——材料支持哪几维就组织哪几维（直接原因→根本条件→触发→加剧，或按设问要求排序），每点 = 要素 + 证据 + 结论。

## 步骤5——作答并输出轨迹

把完整过程整理成可复核的**解题思维轨迹**，含"证据-知识-结论"三元组：

```
【审题】设问类型 / 对象 / 动词 / 限定词 / 要答方向
【证据】哪句材料 / 哪个图例数值 → 支撑哪个推断
【知识】调用了哪个原理 + 为什么 (换区域是否仍适用)
【推理链】步骤1 → 步骤2 (为什么能推出) → ...
【作答】选择题：选X，理由 + 各干扰项错因；
       综合题：采分点（要素+证据+结论），每点分值/术语
```

输出后自检（四问论证，缺一即回补）：

1. **为什么用这个知识解答**——题目哪里触发？换区域是否仍同一条？
2. **为什么依靠这条材料**——哪句材料支撑哪个推断？删掉它结论还成立吗？哪些是无关/干扰信息？
3. **这一步为什么能推出下一步**——每段逻辑缝隙在哪，有无跳跃/想当然？
4. **为什么不是另一个答案**——选择题：每个干扰项错在哪，正确项为何必须由材料推出；综合题：备选要点为何不取（材料不支持/答非所问）。

## 交付

- 面向教师：在对话内给出清晰、分步的**解题思维轨迹**，突出"证据→知识→结论"链条与干扰项错因。
- 面向师范生（备赛/教研）：额外说明你的审题骨架依据（设问类型为什么这样分、要素维度怎么排查）。
- 解题完成后，提示可用 `geo_judge` 核验答案、用后续讲题流程重组为讲题稿。主动询问是否继续。

## 质量自检清单（每题过）

- [ ] 独立解题：完成作答前未读取答案/解析；
- [ ] 设问先行：先拆设问再定向读材料；
- [ ] 证据可信：每条结论都有对应材料字句或读图数值，无编造；
- [ ] 知识有据：每步交代为什么调用这条知识；
- [ ] 推理无跳跃：每步标注"为什么能推出下一步"；
- [ ] 选项/小问全覆盖：选择题干扰项错因讲清，综合题采分点含证据；
- [ ] 四问论证齐全。

不达标 → 回到对应步骤补全后重新输出，不静默省略。
