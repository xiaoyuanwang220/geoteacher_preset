# 命题规范（Item Writing Standards）

## 固定/可变分层（边界依据）

| 层 | 固定？ | 内容 | 来源 |
|----|--------|------|------|
| 考点层 | 固定 | 考察知识点（清单条目编号） | 知识点文档（KPS） |
| 写法层 | 固定 | 设问动词与句式、材料组织手法、信息给予方式、干扰项类型、题组结构、解析套路 | 真题风格档案 |
| 结构层 | 固定 | 五段式输出 | 本文件 |
| 内容层 | **可变** | 情境、具体材料、数据、区域案例、设问角度 | 原创生成 |

固定"怎么写"，可变"写什么"——同一考点+同一风格可反复出不同情境的题。情境替换、增删材料信息量是常用修订动作，正因内容层可变才改得动。

## 五段式结构（每题必含）

1. **题目**：材料（共用材料+情境）+ 题干 + 选项/小问；
2. **解析**：解题思路，引用材料具体信息，逐项判定；
3. **答案**；
4. **评分标准**；
5. **考察知识点**：KPS 条目编号+名称 + 核心素养维度（区域认知/综合思维/人地协调观/地理实践力）。

## 选择题规范

- **题组化**：共用材料 + 1–3 道单选；只出单选，不生成多选；
- 选项结构、组合式（①-⑥）用法对齐风格档案；
- **干扰项必须是真错项且错因可讲清**。常见干扰项手法：以偏概全、偷换概念、绝对化表述、因果倒置、无中生有、程度失当、时间/空间错位；
- 解析逐项判定：正确项依据材料推出，每个干扰项写明错因；禁止"其它选项错误"式空话；
- 评分标准：默认每题 3 分，选对得 3 分，错选、多选不得分；分值可调。

## 综合题规范

- 小问梯度：描述→分析→评价/措施（对齐风格档案）；数量与分值分配参照档案惯例（如 3 小问 6/8/6）；
- 答案要点与解析严格一致，要点按小问分列；
- 评分标准分点赋分：每点分值、答出几点得满分；答案含因果逻辑给过程分；
- 设问动词与档案一致（简述/说明/分析/指出/推测/评价/提出措施…），不混用认知层级。

## 解析质量

- 解析必须引用材料具体信息（"据材料'……'可知"），不做无源判断；
- 每个选项/每个小问都有对应解析；
- 解析与答案完全一致，禁止"解析推 A、答案给 B"。

## 难度调节（年级联动）

- 真题为高考（高三）水平；**高一/高二必须降难度**：简化设问动词、压缩材料信息量、选项表述直白化、减少综合题小问数量；
- 难度分三层可分别调整：**知识层**（所需知识深度）、**思维层**（推理链条长度）、**情境层**（情境陌生度/信息复杂度）；
- 交付时标注预判难度。

## 原创性与合规（红线）

- 情境、材料、题干、选项、答案**全部原创**；不得改写真题题干、选项、解析原文；风格模仿 ≠ 抄袭；
- 真实数据标注来源/年份/单位；无法核验时用明确标注的"教学模拟"数据（课堂练习可用模拟数据；模拟题/备赛题优先真实数据）；
- 不自行绘制地图；涉图题标注"需配图"并指引合规图源（自然资源部标准地图等已审核地图）；
- 「考察知识点」必须能 KPS 溯源；清单外条目显式标注"待教师确认补录"。

## 自检清单（生成后逐题过）

- [ ] 风格对照：材料信息量、设问动词、选项结构、题组形态与风格档案一致；
- [ ] 知识点溯源：「考察知识点」与 KPS 条目精确匹配；
- [ ] 答案-解析一致；
- [ ] 干扰项均为真错项且错因明确；
- [ ] 原创性：无真题原句、无改写真题内容；
- [ ] 合规：数据来源、涉图提醒、无真实真题内容；
- [ ] 难度与年级匹配。

不达标 → 重写该题（最多 2 次）；仍不达标 → 标注「存疑：原因」并照常交付，不静默降级。
