# 风格档案 Schema 与抽取指引（Style Profile）

## 定位

风格档案是从「真题库」范例中抽取的、用于约束命题的**写法模式清单**。它是"约束清单"而非"填空模板"——约束**怎么写**（考点层与写法层），不限定**写什么**（内容层原创）。

风格档案必须**现场抽取**：每次命题按当前检索结果重抽，不以本文件或任何既有描述代替检索。

## 风格库两档

| 档位 | 采样范围 | 说明 |
|------|---------|------|
| 各省融合（默认） | 跨 23/24/25 三个年份均衡采样 2–4 份**不同省份**试卷 | 取各份并集归纳，代表全国卷主流命题特征 |
| 广东卷独立 | 仅广东卷（23/24/25 三年份各 1 份，共 3 份，已实测确认） | 其余省份不参与 |

## 检索方法

1. 按年份文件夹 `get_knowledge_list` 列出试卷 → 标题过滤省份关键词。标题格式固定为「精品解析：20XX年XX省/市高考地理真题（解析版）.docx」，含省份，可精确过滤，无需全文盲搜；
2. 命中后 `fetch_media_content` 取全文；
3. 按「要求.md」题组契约切分题组：**题组 = 共用材料 + 一道或多道题 + 答案 + 解析**，以材料边界划分，不按切片或页码；无法确认归属时继续检索相邻内容，仍无法确认则标记，不猜测合并。

## 七维度 Schema

| 维度 | 抽取内容 | 记录方式 |
|------|---------|---------|
| 题组结构 | 每题组几道题、共用材料形态（情境段/数据表/图+题） | 描述 + 1 个范例题组题号 |
| 材料特征 | 篇幅（句数）、情境来源类型（产业/自然/区域案例/生活场景）、数据密度 | 描述 + 1 句真实句式样例 |
| 图表特征 | 图/表类型、图例有无、信息载体 | 类型清单（柱状图/剖面图/区域图/统计表…） |
| 设问特征 | 设问动词频率（说明/分析/指出/推测/简述…）、提问句式、过渡句 | 动词清单 + 句式模式 |
| 选项特征 | 组合式选项（①-⑥）占比、干扰项手法类型 | 手法清单（以偏概全/绝对化/偷换概念/因果倒置…） |
| 解析特征 | 是否带【点睛】知识拓展、解析引用材料的方式 | 描述 + 结构模式 |
| 综合题特征 | 小问数量、设问梯度、分值分布 | 结构模式（如 3 小问：描述→分析→措施） |

## 抽取指引

- 每个维度从范例摘录 1–2 个**真实短句**作为"句式样例"，用于约束设问口吻——只作约束，禁止直接用于题目（原创红线）；
- 干扰项手法必须从真题中**归纳类型**，不能凭空设定；
- 风格档案带溯源字段：**省份 + 年份 + media_id**；
- 声明样本量：广东卷 = 3 份（23/24/25）；各省融合 = 实际采样的省份清单。

## 广东卷风格起点特征（必须检索核验后使用）

以下为从库内样本归纳的起点，**每次命题仍须现场重抽档案**：

- 选择题：题组化，多为 1–2 题共用情境材料；材料 2–4 句 + 图或数据表；组合式选项（①-⑥）在人文地理题中常见；
- 综合题：以 3 小问为主，设问梯度"描述→分析→措施/评价"；
- 解析：逐题详解 + 【点睛】背景知识拓展。

> 起点特征只作检索时的注意力引导，不构成档案本身。
