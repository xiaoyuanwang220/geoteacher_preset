# 知识点清单（KPS）解析规则

## 定位

教师提供的知识点文档（会持续更新）是「考察知识点」字段的**唯一权威来源**。KPS 是"活文档引用"而非蒸馏——只解析、索引、对照、校验，**不提炼、不改写、不产生新资产**。

## 活文档策略（文档持续更新）

- **不静态固化**：KPS 解析结果不复制进本技能 references，不固化为长期缓存；每次出题会话读取知识库/本地中的**最新版**文档；
- **更新检测**：会话开始时检测文档更新时间，有更新则重新解析清单，旧解析结果作废；
- **增量兼容**：条目**新增**不影响已生成题目；条目编号/名称**修订**时，相关旧题在教师发起修订时按最新清单重新对齐；
- 文档即标准——教师的文档本身是权威，本技能不做任何内容修改。

## 文档形态（建议，以实际文档为准）

- 条目化：**编号**（如 1.1、2.3）+ **知识点名称** +（可选）可考题型 / 难度建议 / 考查方式说明；
- 存放：ima 知识库或本地上传文档，两种通道都支持；
- 文档到位后按**实际结构**解析，不假设格式。

## 解析流程

1. 读取文档：ima 文档用检索取全文；本地文档直接读取；
2. 解析为结构化清单：`[编号, 名称, 可选属性]`；
3. 会话内维护清单，供参数选取、命题标注、溯源校验、修订换点使用。

## 使用规则

| 情形 | 处理 |
|------|------|
| 教师指定知识点（如"大气环流"） | 命中清单对应条目，输出字段写「编号 + 名称」 |
| 教师未指定 | 按年级/模块自动选 1–3 条（或教师给定范围） |
| 指定知识点不在清单中 | 优先映射到最接近条目；无法映射时标注「清单外知识点，待教师确认补录」，不擅自并入 |
| 清单未到位（过渡期） | 回退为自由标注（知识点 + 素养维度），交付时注明「知识点待与清单对齐」 |

## 溯源校验（门禁检查项）

- 每题「考察知识点」必须在清单中精确匹配（编号 + 名称）；
- 修订换知识点时同样走清单映射，改后重过门禁。

## 与课例蒸馏的区别（防止混淆）

| | 课例蒸馏 | KPS |
|---|---------|-----|
| 对象 | 原始素材（课例） | 权威标准（清单文档） |
| 动作 | 提炼模式、生成新资产 | 解析、索引、对照、校验 |
| 产物 | 新知识资产（沉淀回流） | 无新资产，只有对齐动作 |
| 更新 | 蒸馏后资产固定 | 文档是活的，按最新版执行 |

真正需要"蒸馏"（素材→模式）的是**风格档案**（style-profile-schema.md）；KPS 只做引用。
