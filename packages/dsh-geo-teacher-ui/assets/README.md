# assets/ —— 插件自带静态资源

宿主半边（`../index.js`）只从本目录按文件名取图，经 `/geo-teacher-ui/assets/<name>` 提供，且只发栅格图（png/jpg/jpeg/webp/gif），文件名须匹配 `^[A-Za-z0-9][A-Za-z0-9._-]*$`。

放入任意栅格图即可生效，无需改代码。页面约定的名字是 `globe.png`（主视觉「地球仪与书本」）。

当前客户端半边（`../client.js`）尚未引用任何图片：品牌位文案是文本替换，图标是内联 SVG。本目录为该插图保留入口。

未放入时该路由恒 404，客户端界面不受影响。
