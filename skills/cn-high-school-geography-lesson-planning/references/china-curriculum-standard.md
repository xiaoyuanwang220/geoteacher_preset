# 中国普通高中地理课程标准定位规则

## 权威依据

以教育部印发的《普通高中地理课程标准（2017年版2025年修订）》为现行课程依据。

不要使用2003年实验版替代现行课程标准。发现更新版本时，以教育部现行文件为准，并在修改本参考文件前核验发布日期与适用范围。

## 课程结构

现行高中地理课程通常按以下模块组织：

- 必修课程：地理1、地理2。
- 选择性必修课程：自然地理基础、区域发展、资源环境与国家安全。
- 选修课程：由学校根据课程方案、师资和学生发展需要开设。

不同地区、学校和教材版本的年级安排、章节顺序和案例不同。不要把“高一”等同于某个固定模块，也不要把出版社目录当作全国统一教学顺序。

按教师提供的信息定位到下列层级：

1. 年级与学期。
2. 必修、选择性必修或选修模块。
3. 内容主题或课标内容要求。
4. 本课承担的行为要求。
5. 对应的学业质量表现。

不得根据出版社教材章节号反推唯一课标条目。教材章节是教学组织方式，课标内容要求才是对齐依据。

## 模块路由提示

| 模块 | 优先识别的内容类型 | 常见主课型 |
|---|---|---|
| 地理1 | 地球环境、自然地理过程、自然灾害与地理实践基础 | 自然地理过程与机制；地理实践 |
| 地理2 | 人口、乡村与城镇、产业区位、交通、人地协调发展 | 人文地理过程与区位 |
| 自然地理基础 | 自然地理过程、自然环境整体性和地域分异 | 自然地理过程与机制 |
| 区域发展 | 区域特征、区域联系、区域发展问题与治理 | 区域认知与区域发展 |
| 资源环境与国家安全 | 资源、环境、生态、国土和国家安全问题 | 资源、环境与国家安全 |

本表只用于初步路由。最终仍以教师提供的模块信息和经核验的课标条目为准。

## 核心素养

高中地理核心素养包括：

- 人地协调观
- 综合思维
- 区域认知
- 地理实践力

四项素养相互联系，但一节课不必平均覆盖。选择承担核心认知工作的1至2项，写出可观察表现。

## 定位步骤

### 有明确课标条目

核对版本、模块、条目和原文。将原文逐字保存为 `standard_text`，只在教学设计的目标课标提示框完整呈现一次。

### 只有课题或教材章节

从课题中的对象、过程、区域、问题和行为动词提取检索词。先检索官方课标中的相关内容要求，再核对年级和模块。不要只因主题相同就选择认知要求较低的条目。

### 一个课题对应多个条目

选择本课实际完成的一个主要条目。其他条目只作为前置或后续连接，避免一课承担过多标准。

### 找不到可核验原文

最多尝试3次官方检索。仍无结果时：

1. 不得使用引号或“课标原文”标签呈现记忆内容。
2. 在草案中写“课标条目待核对”。
3. 请教师提供条目或授权继续制作非最终草案。
4. 原文未核验前，不交付声称完全课标对齐的最终材料。

## 行为动词核对

让学生任务覆盖课标行为，而不只覆盖主题：

| 课标行为 | 学生任务应体现 |
|---|---|
| 描述 | 从材料中准确说出空间分布、变化或特征 |
| 说明 | 用证据阐明关系或影响 |
| 分析 | 拆分要素并建立相互作用关系 |
| 解释 | 建立过程、机制或因果链 |
| 比较 | 使用一致指标识别共性与差异 |
| 评价 | 基于标准权衡收益、成本和风险 |
| 调查 | 设计并实施可执行的数据采集方案 |
| 设计 | 提出满足约束、回应证据的方案 |

课堂检测至少保持目标条目中的最高认知要求。

## 课标引用格式

教学设计中只完整出现一次：

```text
课程模块／内容要求编号（如可核验）
原文：……
来源：《普通高中地理课程标准（2017年版2025年修订）》
```

其余位置写“模块或编号＋十余字概述”，不重复整段原文。
