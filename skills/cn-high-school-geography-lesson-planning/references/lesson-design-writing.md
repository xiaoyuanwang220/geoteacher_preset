# 高中地理教学设计写法

生成完整教学设计前读取本文件。各板块共同解释同一课程设计：

```text
课标与教材 → 学情差距 → 目标与评价 → 重难点 → 方法、资源与活动 → 学习证据
```

## 表达

- 分析维度只用于内部检查，不机械转成标题或表格行。
- 课标、教材、学情和重难点按“依据或现状—解释—教学决策”写成连贯判断。
- 需要比较或对应时可以使用表格；单元格写完整句，表格前后给出综合判断。
- 只呈现真正影响本课设计的内容，不为覆盖栏目堆砌文字。

## 板块要求

### 课程基本信息

记录课程名称、学时、年级或模块和教材目次。版本、章节无法确认时标注“未指定”，不要猜测。

### 课标分析

拆解最匹配内容要求的行为动词、内容对象、条件和程度，说明它们如何约束目标、任务和评价。选择真正承担本课认知工作的1至2项核心素养；政策背景不能代替课标解读。输出连贯分析，不默认生成维度表。

### 教材分析

说明内容位置、知识逻辑和前后联系，再交代本课保留、重组、补充或替换什么及其理由。不要复述教材，也不要为显示创新而强行跨章节整合。

### 学情分析

连接“已有基础—目标差距—具体困难—教学响应”，并标明依据来自前测、作业、观察还是教师经验。没有实证时写“教师经验预判”；多个具体困难可用表格展开。

### 教学目标与评价目标

目标使用可观察行为，尽量写明证据或条件、成果和质量要求；核心素养转化为具体地理表现。每项目标配置对应的评价证据和判断标准，不机械覆盖四项素养或套用固定量规。

### 教学重点与难点

重点和难点默认各写成一个带标签的完整段落，不按内容、依据、策略、证据等维度拆成表格。重点说明关键内容、确定依据、落实任务和达成表现；难点说明认知障碍、形成原因、突破支架和验证表现。只有多课时或多项重难点确需比较时才使用表格。

### 教学方法与资源

选择一个主要方法和必要的辅助方法，说明其如何影响任务、支持或评价。写明每项资源的认知作用和使用环节；方法与资源的数量、新颖程度不是质量标准。

### 教学过程

根据课程逻辑呈现核心问题或主要任务，围绕同一认知主线组织阶段，不套固定课序，也不使用教学过程表格。每个阶段以“环节名称＋时间”为标题，用完整语句写明必要的关键问题、教师活动、学生活动、学习成果、评价与反馈、设计理由；材料与情境、问题或任务、学生活动、学习成果、评价与反馈相互对应，但不要求按固定顺序或分别设栏。

教师活动必须引发对应的学生认知行为。情境的认知作用、问题之间的依赖以及模型的使用方式应在叙述中自然呈现，不要求单设栏目或环节；没有认知依赖时，不强行组织成问题链。课堂检测根据目标选择合适方式。材料本身确需呈现比较数据时可以使用数据表，但不得把整个教学过程或问题链排成表格。

### 板书设计建议

默认只给2至4条建议，围绕核心问题、关键关系和呈现顺序，不强制生成完整板书图，也不把教学思路图、学习单或实验记录表当作板书。教师明确要求时再展开。

## 检查

- 目标的认知深度与课标一致，并有活动和评价证据承接。
- 教材处理能够解释材料选择，关键学情困难都有教学响应。
- 重点有落实任务，难点有突破与验证。
- 方法、资源、教师活动和学生活动在教学过程中实际对应。
