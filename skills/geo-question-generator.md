# 中国高中地理真题风格命题（出题助手）

基于「本地真题库」现场检索风格范例，生成原创、风格锚定、五段式的高中地理练习题或模拟题。服务一线教师（课堂练习/模拟题）与师范生（试题命制大赛备赛）。

"教师"始终指当前用户。技能面向教师交付可直接使用的题目；师范生备赛时可额外说明命题思路与风格依据。

## 与教师保持沟通

确定交付路径后，用一至两句话说明将检索真题风格、按风格命题并输出题目。面向教师只说命题成果与风格要点，不说内部检索、档案或脚本机制。

## 数据源（DSH 本地，以现场为准）

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 本地真题库 | `E:\知识图谱\obsidian_vault\04_题目` | 目录结构 `省份/年份/题组单页.md`（如 `广东/2025/精品解析：2025年广东高考地理真题（解析版）__选择题G1_Q1-2.md`）。每个题组单页含：frontmatter（region/year/question_numbers/question_type）、题组材料、逐题题干/选项/答案/解析、MANAGED-KM 知识点映射块 |
| 知识点权威源（KPS） | `E:\知识图谱\config\knowledge_taxonomy_*.yaml` | 结构为 domain（领域）→ theme（主题）→ knowledge_unit（知识单元），节点带 `id`（如 `KU-REG-INDUSTRY-002`）、`name`、`definition`。这是「考察知识点」字段的唯一权威来源 |
| 风格档案工具（可选） | 插件提供的 `geo_style_profile` 工具（输入 region/years，输出七维度风格档案） | 提供则优先调用；否则用 read/glob 工具现场抽取（见步骤2） |

**题库持续动态增长**：教师会不断导入新的真题单题页。**每次命题前必须现场扫描目录**，以当前磁盘状态为准，不得依赖任何固定清单、索引缓存或记忆中的文件列表。KPS 同样每次读取最新版，不固化、不蒸馏。

## 步骤0——静默路由

在提出任何问题前完成：

1. **确认本技能数据源就绪**：确认 `E:\知识图谱\obsidian_vault\04_题目` 可读、`E:\知识图谱\config\knowledge_taxonomy_*.yaml` 可读（用 glob 列出目录、read 抽查一两个文件即可）。不可读时明确告知教师，并询问是否按通用高考命题风格继续。
2. **不询问**命题规范（本文件已内联）：五段式结构、选择题/综合题规范、难度调节、自检清单、红线合规均在本文件下方，命题时严格照此执行。

## 步骤1——参数收集

一次性收集命题参数，通常提出 0 至 2 个必要澄清，不反复追问：

- **命题风格**：各省融合（默认）／广东卷独立；
- **题型**：选择题（仅单选）／综合题；
- **题量**：选择题 1–6 题（可组题组）；综合题 1–2 题；
- **年级**：高一／高二／高三；
- **知识点**（可选）：从 taxonomy（KPS）清单选取；未指定则按年级自动选 1–3 条；
- **情境**（可选）：区域或主题要求；**难度倾向**（可选）；**图表**（可选）。

学科固定为地理，不询问。未说明的参数采用合理默认：各省融合、中等难度、纯文字题、知识点自动。

## 步骤2——风格锚定（本地真题库现场抽取）

按以下方式从本地真题库抽取风格范例：

- **各省融合**：现场扫描 `obsidian_vault\04_题目` 下各省份目录，跨年份（当前以库内现有年份为准）均衡采样 2–4 份**不同省份**试卷，风格档案取并集归纳；
- **广东卷独立**：仅取 `广东` 目录下的真题（当前库内为 2025 年，以实际扫描为准）。

扫描工具用法：用 glob（如 `E:\知识图谱\obsidian_vault\04_题目\**\*.md`）列出全部题组单页，按 `省份/年份/文件名` 过滤采样，再用 read 取回全文。

取回全文后按题组契约切分（题组 = 共用材料 + 一道或多道题 + 答案 + 解析，以材料边界划分），按下方「风格档案 Schema（七维度）」抽取风格档案。**风格档案必须现场抽取，不以任何既有描述代替检索。**

向教师简述风格要点（1–2 句），不展示内部档案。

### 风格档案 Schema（七维度）

| 维度 | 抽取内容 | 记录方式 |
|------|---------|---------|
| 题组结构 | 每题组几道题、共用材料形态（情境段/数据表/图+题） | 描述 + 1 个范例题组题号 |
| 材料特征 | 篇幅（句数）、情境来源类型（产业/自然/区域案例/生活场景）、数据密度 | 描述 + 1 句真实句式样例 |
| 图表特征 | 图/表类型、图例有无、信息载体 | 类型清单（柱状图/剖面图/区域图/统计表…） |
| 设问特征 | 设问动词频率（说明/分析/指出/推测/简述…）、提问句式、过渡句 | 动词清单 + 句式模式 |
| 选项特征 | 组合式选项（①-⑥）占比、干扰项手法类型 | 手法清单（以偏概全/绝对化/偷换概念/因果倒置…） |
| 解析特征 | 是否带【点睛】知识拓展、解析引用材料的方式 | 描述 + 结构模式 |
| 综合题特征 | 小问数量、设问梯度、分值分布 | 结构模式（如 3 小问：描述→分析→措施） |

抽取指引：每个维度从范例摘录 1–2 个**真实短句**作为"句式样例"（只作约束，禁止直接用于题目）；干扰项手法必须从真题归纳类型；风格档案带溯源字段（省份 + 年份 + 文件名）。若插件提供了 `geo_style_profile` 工具，优先调用以节省时间，但交付前仍须核对档案与磁盘现状一致。

## 步骤3——命题

按「命题规范（固定/可变分层）」生成：**考点（KPS 条目）与写法（风格档案）固定，情境、材料、数据、设问角度原创**。

每题强制五段式：**题目 / 解析 / 答案 / 评分标准 / 考察知识点**。考察知识点按 taxonomy 条目标注（`KU-xxx 名称`，可附领域→主题→知识单元路径）。

生成后逐题自检（见「自检清单」）。不达标重写（最多 2 次）；仍不达标标注"存疑：原因"并说明，不静默降级。

## 步骤4——交付

双视图交付：

- **教师版**：五段全量（含解析、答案、评分标准、考察知识点）；
- **学生版**：仅题目（材料、题干、选项/小问），无任何答案痕迹。

默认在对话内以 Markdown 交付；教师需要时导出 `.md` 文件（写入工作区 `outputs\` 或教师指定目录）。交付后主动给出 3–4 个常用修订选项（调难度／减信息量／换情境／改题量），教师也可自由指令。

## 步骤5——修订

单题级修订，不整组重来。修订维度：

- **难度**：知识层／思维层／情境层可分别调整；
- **信息量**：增删数据、压缩或扩展材料；
- **设问**：换动词、换提问角度；
- **情境替换**：换区域或主题；
- **知识点换点**：按 taxonomy 清单映射。

契约：改题不改组——不破坏题组共用材料一致性；修订后必须重新自检；换知识点时更新「考察知识点」字段。

# 命题规范（内联）

## 固定/可变分层（边界依据）

| 层 | 固定？ | 内容 | 来源 |
|----|--------|------|------|
| 考点层 | 固定 | 考察知识点（taxonomy 条目） | taxonomy YAML |
| 写法层 | 固定 | 设问动词与句式、材料组织手法、信息给予方式、干扰项类型、题组结构、解析套路 | 真题风格档案 |
| 结构层 | 固定 | 五段式输出 | 本规范 |
| 内容层 | **可变** | 情境、具体材料、数据、区域案例、设问角度 | 原创生成 |

固定"怎么写"，可变"写什么"——同一考点+同一风格可反复出不同情境的题。

## 五段式结构（每题必含）

1. **题目**：材料（共用材料+情境）+ 题干 + 选项/小问；
2. **解析**：解题思路，引用材料具体信息，逐项判定；
3. **答案**；
4. **评分标准**；
5. **考察知识点**：taxonomy 条目编号+名称 + 核心素养维度（区域认知/综合思维/人地协调观/地理实践力）。

## 选择题规范

- **题组化**：共用材料 + 1–3 道单选；只出单选，不生成多选；
- 选项结构、组合式（①-⑥）用法对齐风格档案；
- **干扰项必须是真错项且错因可讲清**。常见干扰项手法：以偏概全、偷换概念、绝对化表述、因果倒置、无中生有、程度失当、时间/空间错位；
- 解析逐项判定：正确项依据材料推出，每个干扰项写明错因；禁止"其它选项错误"式空话；
- 评分标准：默认每题 3 分，选对得 3 分，错选、多选不得分；分值可调。

## 综合题规范

- 小问梯度：描述→分析→评价/措施（对齐风格档案）；数量与分值分配参照档案惯例（如 3 小问 6/8/6）；
- 答案要点与解析严格一致，要点按小问分列；
- 评分标准分点赋分：每点分值、答出几点得满分；答案含因果逻辑给过程分；
- 设问动词与档案一致（简述/说明/分析/指出/推测/评价/提出措施…），不混用认知层级。

## 解析质量

- 解析必须引用材料具体信息（"据材料'……'可知"），不做无源判断；
- 每个选项/每个小问都有对应解析；
- 解析与答案完全一致，禁止"解析推 A、答案给 B"。

## 难度调节（年级联动）

- 真题为高考（高三）水平；**高一/高二必须降难度**：简化设问动词、压缩材料信息量、选项表述直白化、减少综合题小问数量；
- 难度分三层可分别调整：**知识层**（所需知识深度）、**思维层**（推理链条长度）、**情境层**（情境陌生度/信息复杂度）；
- 交付时标注预判难度。

## 原创性与合规（红线）

- 情境、材料、题干、选项、答案**全部原创**；不得改写真题题干、选项、解析原文；风格模仿 ≠ 抄袭；
- 真实数据标注来源/年份/单位；无法核验时用明确标注的"教学模拟"数据（课堂练习可用模拟数据；模拟题/备赛题优先真实数据）；
- 不自行绘制地图；涉图题标注"需配图"并指引合规图源（自然资源部标准地图等已审核地图）；
- 「考察知识点」必须能 taxonomy 溯源；清单外条目显式标注"待教师确认补录"。

## 自检清单（生成后逐题过）

- [ ] 风格对照：材料信息量、设问动词、选项结构、题组形态与风格档案一致；
- [ ] 知识点溯源：「考察知识点」与 taxonomy 条目精确匹配；
- [ ] 答案-解析一致；
- [ ] 干扰项均为真错项且错因明确；
- [ ] 原创性：无真题原句、无改写真题内容；
- [ ] 合规：数据来源、涉图提醒、无真实真题内容；
- [ ] 难度与年级匹配。

不达标 → 重写该题（最多 2 次）；仍不达标 → 标注「存疑：原因」并照常交付，不静默降级。

# KPS（知识点清单）使用规则

- **唯一权威来源**：`E:\知识图谱\config\knowledge_taxonomy_*.yaml`（活文档）。只解析、索引、对照、校验，**不提炼、不改写、不产生新资产**。
- **活文档策略**：不静态固化——每次出题会话读取最新版文件；文件更新则重新解析；条目新增不影响已生成题目；条目编号/名称修订时，相关旧题在教师发起修订时按最新清单重新对齐。
- **文档形态**：YAML `nodes` 列表，节点含 `id`（如 `DM-REG`/`TH-REG-INDUSTRY`/`KU-REG-INDUSTRY-002`）、`level`（domain/theme/knowledge_unit）、`name`、`parent_id`、`definition`。
- **使用规则**：
  - 教师指定知识点（如"产业升级"）→ 命中清单对应条目，输出「编号 + 名称」；
  - 教师未指定 → 按年级/模块自动选 1–3 条；
  - 指定知识点不在清单中 → 优先映射到最接近条目；无法映射时标注「清单外知识点，待教师确认补录」，不擅自并入；
  - 清单未到位（过渡期）→ 回退为自由标注（知识点 + 素养维度），交付时注明「知识点待与清单对齐」。
- **溯源校验**：每题「考察知识点」必须在清单中精确匹配（编号 + 名称）；修订换知识点时同样走清单映射，改后重过门禁。

# 红线与合规（汇总）

- **原创命题**：情境、材料、题干、选项、答案全部原创；不得改写真题题干、选项或解析原文；风格模仿不等于抄袭。
- **数据真实**：真实数据标注来源、年份、单位；无法核验时用明确标注的"教学模拟"数据。
- **地图合规**：不自行绘制地图；涉图题标注"需配图"并指引合规图源（自然资源部标准地图等已审核地图）。
- **知识点权威**：「考察知识点」字段必须在 taxonomy 中可溯源；清单外条目显式标注"待教师确认补录"，不擅自并入。
- **题库动态性**：真题库持续导入新题单页，风格锚定与参考样本一律以命题当时的磁盘扫描结果为准。
